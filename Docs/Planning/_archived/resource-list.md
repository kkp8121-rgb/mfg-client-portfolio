## 현재 보유 리소스

- **500 Skill Icons**: 스킬 아이콘 48종 매핑 완료 (Assets/500_skill_icons/)
- **Admurin**: 장비 아이콘 (무기/갑옷/투구/장갑/신발/반지)

- 사운드 없으면: 무음 (AudioClip null 체크)
