### 3. 플레이어 AI 전면 재작성 (3차 수정)
바닥 통과 버그 + 이동/점프 로직 문제를 해결하기 위해 PlayerCharacter를 전면 재작성했다.

**변경 파일:**
- `Assets/Scripts/Combat/PlayerCharacter.cs` - 전면 재작성 (721줄)

  **AI 로직:**
  1. `FindTarget()` - 감지 범위 내 가장 가까운 몬스터, 같은 플랫폼 우선
  2. `DecideNavigation()` - 타겟까지의 경로 결정
     - 같은 플랫폼 → 직접 이동 (네비게이션 불필요)
     - 한번 점프로 도달 가능 → `_nextHopPlatform` 설정
     - 불가능 → `FindBestIntermediatePlatform()` 중간 경유지 탐색
  3. `TryNavigationJump()` - 점프/낙하 실행
     - 위로: 타겟 플랫폼 X범위 근처에서 점프 + 수평 속도 부여
     - 아래로: `DropDown()` - PlatformEffector2D 있는 플랫폼만 통과
     - 같은 높이: 현재 플랫폼 가장자리에서 점프

  **핵심 메서드:**
  - `CanReachWithOneJump(from, to)`: 높이차 ≤ maxJumpHeight(4.5f)
  - `FindBestIntermediatePlatform()`: 점프 가능 + 타겟 방향 가까운 순
  - `SearchForMonsterPlatform()`: 타겟 없을 때 몬스터 있는 플랫폼 탐색
  - `ClampToMapBounds()`: 바닥 아래 빠지면 자동 복귀

### 4. 물리 충돌 수정
플레이어/몬스터 간 물리 충돌 비활성화 + 바닥 통과 방지.

- `Assets/Scripts/Editor/CameraSetupEditor.cs`

## 해결한 버그

| 버그 | 원인 | 해결 |
|------|------|------|
| 몬스터 스폰 안됨 | StageManager.Start()가 MonsterSpawner 풀 초기화 전에 호출 | `yield return null` 1프레임 대기 + `_poolInitialized` 지연 초기화 |
| 플레이어 움직이지 않음 | 몬스터 없어서 타겟 없음 → Idle 유지 | 위 스폰 문제 해결로 같이 해결 |
| 플레이어가 몬스터에 막힘 | Player↔Monster 물리 충돌 | `Physics2D.IgnoreLayerCollision(6, 7, true)` |
| 바닥 통과 (떨어짐) | 바닥 콜라이더 너무 얇음 + Discrete 충돌감지 | 바닥 1유닛 두께 + Continuous 충돌감지 |
| DropDown이 바닥도 통과 | PlatformEffector2D 체크 없음 | `hit.collider.GetComponent<PlatformEffector2D>()` null 체크 |
| StageManager에 stageMap 미연결 | Phase2SetupEditor 누락 | `stageSo.FindProperty("stageMap")` 추가 |

## 아키텍처 다이어그램 (Phase 2)

```
StageManager
  ├─ StartStage(chapter, stageIndex)
  ├─ MonsterSpawner.StartStage() → 플랫폼별 분배 스폰
  ├─ EventBus<MonsterDiedEvent> 구독
  ├─ 100마리 → SpawnMiniBoss() → 30초 타임아웃
  └─ AdvanceToNextStage() → 1-1→1-9→1-BOSS→2-1

MonsterSpawner
  ├─ PoolManager.Spawn() / Despawn()
  ├─ StageMap.DistributeMonsters() → 플랫폼별 배분
  ├─ SpawnMiniBoss() / SpawnChapterBoss()
  └─ RespawnCoroutine() → 2.5초 딜레이

PlayerCharacter (AI)
  ├─ FindTarget() → OverlapCircle(monsterLayer)
  ├─ DecideNavigation()
  │   ├─ 같은 플랫폼 → 직접 이동
  │   ├─ CanReachWithOneJump → 바로 점프
  │   └─ FindBestIntermediatePlatform → 경유 이동
  ├─ TryNavigationJump() → Jump() / DropDown()
  └─ ClampToMapBounds() → 바닥 아래 복귀

StageMap
  ├─ List<PlatformInfo> 관리
  ├─ GetPlatformAt(pos) → Y 기반 판정
  ├─ GetPlatformWithMonsters() → OverlapCircle
  └─ DistributeMonsters(count) → 면적 비례

Phase2SetupEditor
  ├─ SetupLayers() → Physics2D.IgnoreLayerCollision
  ├─ CreateMonsterPrefab() → Continuous 충돌감지
  ├─ CreatePlayerInScene() → Continuous 충돌감지
  └─ SetupPhase2Managers() → 모든 참조 자동 연결
```
