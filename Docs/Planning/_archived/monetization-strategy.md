## 1. 수익화 철학

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **편의성 과금** | 시간 단축, 편의 기능 제공. 과금 없이도 모든 콘텐츠 도달 가능 |
| **영구 성장 가속** | 로그라이크가 아닌 영구 육성 게임이므로, 과금은 "속도"를 사는 것 |
| **감정 과금 설계** | 성취감/기대감/불안감의 자연스러운 흐름에 과금 포인트 배치 |
| **천장 보장** | 모든 확률형 시스템에 천장(pity) 존재. 무한 과금 유도 금지 |
| **투명한 확률 공개** | 한국 게임산업법 준수, 모든 가챠/강화 확률 인게임 공개 |

### 유저 세그먼트별 타겟

| 세그먼트 | 비율 | 월 예상 지출 | 주요 과금 포인트 |
|----------|------|-------------|-----------------|
| **무과금 (F2P)** | 70% | ₩0 | 광고 리워드로 참여, 게임 생태계 유지 |
| **소과금 (Minnow)** | 20% | ₩5,000~₩30,000 | 월정액, 배틀패스, 스타터팩 |
| **중과금 (Dolphin)** | 8% | ₩30,000~₩100,000 | 한정팩, 프리미엄 배틀패스, 재화 패키지 |
| **고과금 (Whale)** | 2% | ₩100,000+ | 블루다이아 상점, 고급 한정팩, 특별 번들 |

### 과금 노출 타이밍 원칙

- **첫 10분**: 과금 요소 노출 금지. 게임의 재미에 집중
- **첫 30분**: 스타터팩 1회 노출 (닫기 가능, 재접근 가능)
- **1시간 이후**: 배틀패스, 월정액 등 자연스럽게 노출
- **첫 벽(wall) 도달 시**: 성장 정체 시점에 맞춤 오퍼 제안

> 레퍼런스: AFK Journey Regal Rewards, Firestone Battle Pass, 메이플 키우기 배틀패스

### 시즌 구조

| 항목 | 값 |
|------|-----|
| **시즌 기간** | 28일 (4주) |
| **총 레벨** | 40레벨 |
| **레벨업 방식** | 일일/주간 미션 완료 시 시즌 EXP 획득 |
| **일일 미션** | 5개, 각 20 EXP (일 100 EXP) |
| **주간 미션** | 7개, 각 50 EXP (주 350 EXP) |
| **최대 주간 EXP** | 1,050 (일일 700 + 주간 350) → 4주 = 4,200 EXP |
| **레벨당 필요 EXP** | 100 (40레벨 = 4,000 EXP) → 무과금도 완주 가능 |

## 4. 광고 리워드 통합

> 방치형 RPG 광고 수익은 전체 수익의 60~70%를 차지하는 핵심 수익원 (무과금 유저 대상)
> 핵심: 모든 광고는 100% 선택적(opt-in). 강제 광고 없음.

### 광고 슬롯 설계

| 슬롯 | 트리거 | 보상 | 일일 제한 | eCPM 예상 |
|------|--------|------|-----------|-----------|
| **오프라인 보상 2배** | 오프라인 보상 수령 시 | 수령 보상 ×2 | 3회 | $12~15 |
| **던전 추가 입장** | 던전 열쇠 소진 시 | 열쇠 +1 | 2회 | $10~12 |
| **골드 부스트** | 사냥 중 골드 부스트 아이콘 | 5분간 골드 ×2 | 5회 | $8~10 |
| **무료 소환** | 상점 소환 탭 | 무료 단일 소환 1회 | 2회 | $12~15 |
| **부활** | 보스전 사망 시 | 즉시 부활 (HP 100%) | 1회/보스 | $15~20 |
| **경험치 부스트** | 사냥 화면 부스트 아이콘 | 10분간 EXP ×1.5 | 3회 | $8~10 |
| **강화 보호** | 13성+ 성급 강화 실패 시 | 하락/파괴 방지 | 1회/강화 | $15~20 |
| **일일 보너스 상자** | 일일 미션 전부 완료 시 | 추가 보상 상자 | 1회 | $10~12 |

### 광고 통합 원칙

1. **감정적 최적 타이밍**: 보상을 받을 때(기쁨), 실패했을 때(아쉬움), 부족할 때(필요) — 이 3가지 감정에 광고 배치
2. **시각적 비침습성**: 광고 버튼은 작은 아이콘으로, 메인 UI를 가리지 않음
3. **과금 유저 배려**: 마스터 헌터 패스 구독자는 광고 없이 동일 보상 자동 적용
4. **쿨다운 간격**: 같은 슬롯의 광고는 최소 5분 간격
5. **네트워크 실패 대응**: 광고 로드 실패 시 "나중에 다시 시도" 메시지, 보상 손실 없음

### 스타터팩 유저 플로우

```
[레벨 5] → ₩1,200 팩 팝업
   ├─ 구매 → "첫 구매 감사 보너스" 루비 ×100 추가 지급
   │         → 레벨 10 도달 시 ₩6,500 팩 자연 노출 (상점 배너)
   └─ 미구매 → 24시간 후 상점에 "한정 할인" 배지로 상시 노출
                → 레벨 10 도달 시 ₩1,200 팩 재노출 + ₩6,500 팩 동시 노출

[레벨 10] → ₩6,500 팩 노출
   ├─ 구매 → 즉시 성장 부스트 체감 → 정예 헌터 패스 관심 유도
   └─ 미구매 → 48시간 한정 표시, 이후 상점에서 구매 가능

[레벨 20] → ₩15,000 팩 노출 (72시간 한정)
   ├─ 구매 → 유니크 장비 체험 → 고과금 전환 가능성
   └─ 미구매 → 만료 후 소멸 (FOMO)
```

## 6. 한정 팩/번들 설계

## 8. F2P vs P2W 밸런스

### 핵심 밸런스 원칙

| 원칙 | 구현 방법 |
|------|----------|
| **모든 콘텐츠 F2P 도달 가능** | 과금은 속도만 가속, 과금 전용 콘텐츠 없음 |
| **능력치 과금 상한** | 블루다이아 상점은 외형/편의만. 직접 능력치 판매 없음 |
| **천장 시스템 의무** | 모든 확률형에 천장 존재 (가챠, 잠재, 강화) |
| **시간 = 돈** | 무과금이 2주 걸리는 것을 과금이 3일에 달성 (동일 결과) |
| **PvP 제한** | PvP는 랭킹 보상 차이를 최소화 (코스튬/칭호 위주) |

### 무과금 vs 과금 성장 속도 비교

| 마일스톤 | 무과금 예상 | 소과금 (₩30K/월) | 중과금 (₩100K/월) |
|----------|-----------|-----------------|-------------------|
| 1차 전직 (Lv.10) | 1일 | 4시간 | 2시간 |
| 2차 전직 (Lv.30) | 5일 | 2일 | 1일 |
| 3차 전직 (Lv.60) | 3주 | 10일 | 5일 |
| 챕터 10 도달 | 2개월 | 1개월 | 2주 |
| 유니크 풀셋 | 4개월 | 2개월 | 3주 |

### P2W 방지 가드레일

1. **직접 능력치 판매 금지**: 블루다이아로 공격력/HP를 직접 사는 상품 없음
2. **강화 확률 과금 조작 금지**: 과금 유무와 관계없이 동일 확률 적용
3. **PvP 매칭 보정**: 전투력 기반 매칭 + 과금 구간별 리그 분리 검토
4. **무과금 천장 현실적 설정**: 무과금도 2~3개월 내 주요 천장 도달 가능하도록 재화 공급량 설계
5. **광고 리워드로 격차 완화**: 무과금도 광고 시청으로 소과금 수준의 보상 획득 가능

### F2P 일일 루비 수급 분석

| 출처 | 일일 루비 |
|------|----------|
| 일일 미션 완료 | 100 |
| 광고 리워드 (최대) | ~200 |
| 자동 충전 (분당 5, 상한 10,000) | 지속 충전 |
| 주간 미션 (일 환산) | ~50 |
| 업적/이벤트 (일 환산) | ~50 |
| **일일 합계 (자동충전 제외)** | **~400** |

→ 10연차 1회 (루비 2,700) = 무과금 약 7일, 소과금 약 2~3일

## 9. 이탈 방지 과금 포인트
