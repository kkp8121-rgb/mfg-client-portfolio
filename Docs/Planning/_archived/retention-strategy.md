# mkLike 유저 리텐션 전략

> 방치형 RPG 유저 이탈 원인 분석 및 mkLike 맞춤 리텐션 시스템 설계
> 작성일: 2026-03-15

---

## 1. D1/D7/D30 리텐션 벤치마크

### 업계 벤치마크 (2025-2026 모바일 게임)

| 지표 | 전체 모바일 중앙값 | 상위 25% | 상위 10% | **mkLike 목표** |
|------|-------------------|----------|----------|-----------------|
| D1 리텐션 | 22% | 31~33% | 40% | **35%** |
| D7 리텐션 | 4% | 8~10% | 12% | **15%** |
| D30 리텐션 | 0.7~1% | 3% | 5% | **8%** |

> 출처: GameAnalytics 2025/2026 Mobile Gaming Benchmarks

### 방치형 RPG 장르 특성
- **D1이 높은 편**: 즉각적인 성장 쾌감과 오프라인 보상으로 첫날 경험이 좋음
- **D7에서 큰 이탈**: 초기 콘텐츠 소진 + 성장 속도 둔화 시점
- **D30 핵심 분기**: 길드/소셜/주간 콘텐츠가 있으면 유지, 없으면 급락
- **방치형 장점**: "접속하면 반드시 보상이 있다" → 복귀 동기 자연 형성

### mkLike 리텐션 퍼널 목표

```
설치 100%
  → D1: 35% (튜토리얼 완료 + 첫 전직 체험)
  → D3: 25% (일일미션 루틴 정착)
  → D7: 15% (첫 챕터 보스 돌파 + 주간 보상 사이클)
  → D14: 12% (장비/무기 강화 중독 + 동료 수집)
  → D30: 8% (길드 합류 + 월드보스 참여 + 장기 목표)
```

## 2. 초반 30분 온보딩 플로우

### 핵심 원칙
- **5분 안에 핵심 재미** 전달 (자동 전투 + 대량 처치)
- **15분 안에 첫 성장 마일스톤** (레벨업 + 스킬 해금 + 첫 전직)
- **30분 안에 모든 핵심 시스템 맛보기** 완료
- **강제 튜토리얼 최소화**: 팝업 설명 대신 "해보면서 배우기"

- **리셋 주기**: 매월 1일 자동 리셋

## 5. 소셜 요소

> 길드 소속 유저는 비소속 유저 대비 리텐션이 25% 높음 (학술 연구 기반)
> RPG 상위 앱의 88%가 소셜 기능 보유

### 5.1 길드 시스템

#### 기본 구조

| 항목 | 설정 |
|------|------|
| 길드 인원 | 최대 30명 |
| 가입 조건 | Lv.20 이상 |
| 길드 레벨 | 1~20 (기부 + 활동으로 경험치) |
| 길드 재화 | 길드 포인트 (기부/활동으로 획득) |
| 길드 상점 | 길드 포인트로 전용 아이템 구매 |

#### 길드 콘텐츠

| 콘텐츠 | 주기 | 설명 | 보상 |
|--------|------|------|------|
| 길드 기부 | 매일 | 골드/루비 기부 → 길드 EXP + 개인 포인트 | 길드 포인트 |
| 길드 출석 | 매일 | 접속 시 자동 체크 | 길드 포인트 10 |
| 길드 던전 | 주 3회 | 길드원 전원 데미지 합산, 보스 체력 공유 | 등급별 보상 |

| 친구 방문 | 친구 아레나 구경 | "나도 저렇게 되고 싶다" |
| 친구 보스 | 친구 소환 보스 참여 (1일 3회) | 협동 경험 |
| 친구 CP 비교 | 친구 목록에서 CP 비교 | 경쟁심 자극 |

## 7. 알림/푸시 전략

### 7.1 핵심 원칙
- **주 2~3회 이하**: 과도한 푸시는 앱 삭제 유발
- **개인화**: 유저 진행 상태/행동 기반 맞춤 메시지
- **가치 전달**: "보상이 기다리고 있다"는 메시지만 전송
- **옵트아웃 존중**: 설정에서 카테고리별 알림 on/off

### 7.2 푸시 알림 시나리오

| 트리거 | 발송 시점 | 메시지 예시 | 빈도 |
|--------|-----------|-------------|------|
| 오프라인 보상 가득 | 12시간 미접속 | "12시간치 보상이 쌓였어요! 골드 XX, EXP XX 수령하세요" | 1일 1회 |
| 던전 열쇠 가득 | 열쇠 10개 도달 | "던전 열쇠가 가득 찼어요! 낭비 전에 사용하세요" | 1일 1회 |
| 무료 뽑기 가능 | 24시간 경과 | "무료 뽑기가 준비됐어요! 어떤 동료가 나올까?" | 1일 1회 |
| 점심/저녁 보너스 | 이벤트 시작 10분 전 | "12시부터 1시간 동안 골드 2배! 놓치지 마세요" | 1일 2회 |
| 주간 리셋 임박 | 일요일 20:00 | "주간 미션 보상을 아직 수령하지 않았어요!" | 주 1회 |
| 길드 레이드 시작 | 레이드 30분 전 | "길드 레이드가 곧 시작됩니다! 팀원이 기다려요" | 주 1회 |
| 이탈 위험 (3일) | 미접속 72시간 | "[캐릭터명]이(가) 기다리고 있어요. 보상도 쌓여 있답니다" | 1회 |
| 이탈 위험 (7일) | 미접속 7일 | "돌아오면 특별 선물이 있어요! 복귀 보상을 확인하세요" | 1회 |
| 신규 업데이트 | 업데이트 직후 | "새 챕터/이벤트가 열렸어요! 지금 확인하세요" | 수시 |

### 7.3 알림 카테고리 (설정)

| 카테고리 | 기본값 | 설명 |
|----------|--------|------|
| 보상 알림 | ON | 오프라인 보상, 무료 뽑기 |
| 이벤트 알림 | ON | 시간제한 보너스, 신규 이벤트 |
| 소셜 알림 | ON | 길드 활동, 친구 하트 |
| 미션 알림 | OFF | 미션 리셋, 주간 마감 |
| 마케팅 알림 | OFF | 상점 할인, 패키지 |

### 7.4 비접속 시간대별 메시지 톤

| 미접속 기간 | 톤 | 예시 |
|-------------|-----|------|
| 4~12시간 | 정보 전달 | "보상이 쌓이고 있어요" |
| 1~3일 | 친근한 리마인드 | "오늘 무료 뽑기 아직이에요!" |
| 4~7일 | 감정적 호소 | "[캐릭터]가 보고 싶어해요" |
| 8~14일 | 인센티브 강조 | "복귀하면 루비 1,000 + 특별 버프!" |
| 15일+ | 대형 인센티브 | "복귀 헌터 패키지: 유니크 동료 + 루비 3,000" |

## 8. 성장 정체 해소 시스템

### 8.1 성장 정체 감지 포인트

| 정체 구간 | 발생 시점 | 원인 | 해소 시스템 |
|-----------|-----------|------|-------------|
| 초반 벽 | 챕터 2~3 | CP 부족 | 일일미션 + 성장 던전 안내 |
| 중반 벽 | 챕터 5~7 | 장비 등급 부족 | 정예 몬스터 + 가챠 확률업 이벤트 |
| 전직 벽 | 2차 전직 전후 | 레벨링 속도 둔화 | 경험치 던전 + 오프라인 보상 강화 |
| 장비 벽 | 성급 13성+ | 파괴 공포 | 파괴 방지권 이벤트 지급 |
| 후반 벽 | 챕터 10+ | 모든 시스템 한계 | 프레스티지 시스템 해금 |

### 8.2 프레스티지 시스템: "탑의 윤회"

> 챕터 10 보스 최초 클리어 시 해금

#### 개요
- **리셋 대상**: 챕터 진행도, 캐릭터 레벨 (Lv.1로)
- **유지 대상**: 장비, 무기, 동료, 유물, 재화 전부 유지
- **획득 보상**: "윤회의 별" (프레스티지 전용 재화)
- **영구 보너스**: 윤회 횟수에 비례하여 영구 스탯 증가

#### 윤회의 별 보상 테이블

| 윤회 횟수 | 획득 별 | 누적 영구 보너스 |
|-----------|---------|-----------------|
| 1회 | 100 | 전 스탯 +5% |
| 2회 | 150 | 전 스탯 +12% |
| 3회 | 200 | 전 스탯 +21% |
| 5회 | 300 | 전 스탯 +45% |
| 10회 | 500 | 전 스탯 +100% |

#### 윤회의 별 상점

| 아이템 | 비용 | 효과 |
|--------|------|------|
| 영구 공격력 +1% | 10별 | 누적 가능 |
| 영구 HP +1% | 10별 | 누적 가능 |
| 영구 EXP 획득 +5% | 25별 | 누적 가능 |
| 영구 골드 획득 +5% | 25별 | 누적 가능 |
| 영구 드롭률 +2% | 50별 | 누적 가능 |
| 시작 레벨 +10 | 100별 | 윤회 시 Lv.10에서 시작 |
| 시작 레벨 +20 | 200별 | 윤회 시 Lv.20에서 시작 |
| 전용 칭호 "윤회자" | 500별 | 1회 구매 |
| 전용 스킨 | 1,000별 | 1회 구매 |

#### 프레스티지 설계 원칙
- **리셋이 아닌 가속**: 장비/동료 유지로 "다시 처음부터" 느낌 최소화
- **매 윤회가 더 빠름**: 영구 보너스 + 시작 레벨 상승으로 2회차는 1회차의 절반 시간
- **시각적 보상**: 윤회 횟수를 닉네임/프로필에 표시 (별 아이콘)
- **자발적 선택**: 강제 리셋 없음, 원할 때 윤회 가능
- **사전 안내**: 윤회 버튼에 예상 보상 프리뷰 표시 (리텐션 19% 향상 사례 참고)

### 8.3 새 콘텐츠 해금 타임라인

| 해금 조건 | 콘텐츠 | 리텐션 효과 |
