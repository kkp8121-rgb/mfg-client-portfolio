## 1. 경쟁 게임 분석

### 1.1 메이플 키우기 분석

메이플 키우기는 2025년 11월 정식 출시 후 빠르게 한국 모바일 방치형 RPG 시장의 최상위에 안착했다. 핵심 시스템을 분석하면:

#### 성장 루프
- **레벨 시스템**: 레벨당 능력치 포인트 5개, 25포인트 소비 시 메이플 등급 상승 + 특수 포인트 지급
- **직업/전직**: 10개 직업, Lv.10/30/60/100에서 1~4차 전직
- **mkLike와 비교**: mkLike는 3직업 x 3차 전직(Lv.40/80/120)으로 더 단순하지만, 방치형에는 충분한 깊이

#### 장비 강화 (3단 구조)
- **주문서 강화**: 10회 시도, 5번째/10번째 확률 상승 — mkLike 동일 구조 채택 완료
- **스타포스**: 12성부터 에디셔널 큐브 개방 — mkLike 동일 구조 (13성 하락, 15성 파괴)
- **잠재능력**: 미라클 큐브 기반 등급 승급 — mkLike 천장 시스템으로 차별화 (33~714회 보장)

#### 소환 (가챠) 시스템
- **무기 소환**: 소환권 또는 레드 다이아 20개/회, 소환 레벨 최고 17
- **동료 소환**: 소환 레벨 최고 13, 메인 동료(30초 소환 전투) + 서브 동료(패시브)
- **mkLike와 비교**: mkLike는 천장 40/50회로 메이플 키우기보다 관대한 편

#### 콘텐츠 구조
- **챕터 사냥**: 자동 사냥 구역, 1~10(또는 15) 스테이지
- **성장 던전**: 하루 3회 충전, 최대 10회 누적 — mkLike 동일 채택
- **보스 레이드**: 주 3회, 자쿰 레이드(2025.12 추가) — 신규 장비 슬롯(얼굴장식) 보상
- **아레나 PvP**: 1v1 비동기 PvP, 아레나 코인 + 전용 상점, 직업 상성 중요
- **길드**: 길드원 스킬(개인 연구) + 마스터리 스킬(간부 연구), 토벌전/대항전, 길드 수련장(2026.01)
- **유물**: 에픽~레전드리, 보유 효과 + 장착 효과

#### mkLike에 없는 시스템 (차기 구현 대상)
| 시스템 | 메이플 키우기 | mkLike 현재 |
|--------|-------------|-------------|
| PvP 아레나 | 1v1, 아레나 코인 상점 | **미구현** |
| 길드 | 토벌전/대항전/수련장 | **미구현** |
| 코스튬 | 코디 시스템 | **미구현** |
| 시즌/배틀패스 | 미확인 (추정 예정) | **미구현** |
| 펫 | 미확인 | **미구현** |
| 4차 전직 | Lv.100 4차 전직 | 3차까지만 (Lv.120) |

### 1.2 기타 방치형 RPG 트렌드

#### AFK Arena / AFK Journey
- **위시리스트 가챠**: 유저가 원하는 영웅 확률 증가 — 불만 감소, 목표 설정 유도
- **King's Tower**: 무한 타워 (층수 경쟁) — mkLike 세계관과 직결
- **Voyage of Wonders**: 탐험형 이벤트 콘텐츠 — 일회성 퍼즐 + 보상
- **Temporal Rift**: 시즌 콘텐츠로 주기적 리텐션 유지

#### Legend of Mushroom
- 3,000만 다운로드 달성 (2024.03 출시 후 1년)
- **단순함의 미학**: 복잡한 시스템보다 직관적 성장 + 귀여운 비주얼로 캐주얼 유저 확보
- **교훈**: mkLike도 핵심 루프의 직관성을 유지해야 함

#### Idle Heroes
- **400+ 영웅 로스터**: 장기 운영의 핵심은 수집 콘텐츠의 양
- **팩션 오라**: 같은 진영 조합 시 시너지 — mkLike에서 직업 시너지로 변환 가능
- **멀티 레이어 PvP**: 아레나 + 서버 간 대전 + 길드 레이드

#### Rusty's Retirement / 하단 바 게임
- 2025~2026 트렌드: "화면 하단에 상주하는 미니 방치형 게임"
- PC 방치형의 새로운 폼팩터이나, 모바일에는 직접 적용 어려움
- **인사이트**: 극단적 방치의 수요 확인 — mkLike의 오프라인 보상 시스템 강화 근거

#### Vampire Crawlers (2026 출시 예정)
- 뱀서라이크 후속작이 덱빌더/던전 크롤러로 변형
- **인사이트**: 순수 뱀서라이크는 포화, 하이브리드 방향으로 진화 중
- mkLike는 이미 "뱀서라이크 전투 + 방치형 육성" 하이브리드로 차별화 확보

### 1.3 수익 모델 분석

#### 배틀패스 (가장 효과적인 라이브옵스 도구)
- **구조**: 무료 트랙 + 프리미엄 트랙 (보통 $9.99~$14.99/시즌)
- **핵심 원칙**:
  - 무과금도 무료 트랙으로 유의미한 보상 획득 가능
  - 프리미엄은 "가성비"로 어필 (개별 구매 대비 5~10배 가치)
  - 시즌 기간: 4~6주가 최적 (너무 길면 이탈, 너무 짧으면 압박)
- **Idle Miner Tycoon 사례**: $9.99/월 배틀패스, 이벤트 광산 접근권 포함
- **League of Legends 시즌 시스템**: 테마 기반 시즌 + 배틀패스로 게임플레이 변화와 수익화 동시 달성

#### 지연된 수익화 (Delayed Monetization)
- 방치형 게임 베스트 프랙티스: **처음 10~30분은 과금 요소 노출 최소화**
- 유저가 게임 루프에 몰입하고 "내 캐릭터"에 애착을 가진 후 과금 유도
- mkLike 적용: 챕터 1~2 완료(약 30분) 후 상점/배틀패스 노출

#### 하이브리드 수익 모델
- 2025년 기준 82%의 유저가 "광고 포함 무료 게임"을 선호
- 그러나 46.8%가 광고를 최대 불만으로 지적
- **최적 조합**: IAP(배틀패스, 가챠, 월정액) + 선택적 리워드 광고 (강제 광고 없음)

#### 월정액 / VIP
- 일일 루비/다이아 지급형 월정액: $4.99~$9.99
- VIP 레벨: 누적 과금액에 따른 영구 혜택 (자동 반복, 추가 슬롯 등)

#### mkLike 수익 모델 설계 방향
| 수익원 | 가격대 | 핵심 가치 |
|--------|--------|-----------|
| 배틀패스 (시즌) | $9.99/시즌 | 시즌 한정 스킨 + 재화 + 소환권 |
| 월간 루비 패스 | $4.99/월 | 일일 루비 100 x 30일 = 3,000 (직접 구매 대비 3배 가치) |

| 리워드 광고 | 무료 | 일일 5~10회, 루비/열쇠/강화 재료 보상 |

## 2. 차별화 전략

### 2.1 탑 등반 세계관 활용

mkLike의 최대 차별화 자산은 **"탑 등반"** 세계관이다. 대부분의 방치형 RPG가 월드맵/챕터 진행인 반면, mkLike는 "무한한 탑"이라는 수직적 메타포를 가진다. 이를 극대화하는 전략:

#### 2.1.1 탑의 구조 확장 — "탑의 세계"
```
[1F ~ 100F]   일반 구간: 챕터 1~10 (현재 구현)
[101F ~ 200F] 엘리트 구간: 환경 기믹 추가 (독안개, 용암, 빙결)
[201F ~ 300F] 심연 구간: 몬스터 변이 + 보스 패턴 강화
[301F+]       무한 구간: 매 층마다 난이도 스케일링, 랭킹 경쟁
```

- **층수 = 유저의 "명함"**: 프로필에 "최고 도달 층수" 표시 → 길드 가입, PvP 매칭에 활용
- **구간별 테마 변경**: 배경/BGM/몬스터 변형 → 시각적 진행감
- **층 보상 마일스톤**: 매 10층마다 고정 보상 (소환권, 재화, 코스튬 해금)

#### 2.1.2 탑의 비밀 — 히든 층 & 이벤트 층
- **비밀 방 (Hidden Room)**: 특정 조건 충족 시 출현 (예: 챕터 보스 30초 내 클리어)
  - 유물 확정 드롭 or 희귀 코스튬 해금
  - 발견 알림이 길드 채팅에 공유되어 소셜 효과
- **이벤트 층 (Event Floor)**: 시즌마다 기간 한정 특별 층 추가
  - 시즌 테마 몬스터 + 한정 보상
  - 시즌 종료 후 접근 불가 → FOMO 유발

#### 2.1.3 탑 탐험 일지 — 도감 연동
- **몬스터 도감**: 층별 등장 몬스터 수집, 도감 완성 시 패시브 버프
- **층 도감**: 각 층의 "완전 클리어" (시간 내 클리어, 무피격 클리어 등) 달성 시 별 부여
- **탑의 기록**: 탑 전체 진행 타임라인 (언제 몇 층 돌파했는지) → 회고의 즐거움

### 2.2 독자적 시스템 아이디어

#### 2.2.1 등반 조합 시스템 (Climbing Party)
기존 "동료"를 확장하여, **최대 4인 파티 편성** 시스템 도입:

| 역할 | 설명 | 효과 |
|------|------|------|
| **선봉 (Vanguard)** | 플레이어 캐릭터 | 메인 딜러/탱커 |
| **정찰 (Scout)** | 동료 1 (자동 소환) | 원거리 견제, 아이템 자동 수집 |
| **지원 (Support)** | 동료 2 (패시브) | 힐/버프/디버프 |
| **비장 (Ace)** | 동료 3 (궁극기) | 60초 쿨타임, 강력한 단일 스킬 |

- 현재 "메인 동료(30초 소환) + 서브 동료(패시브)"를 확장
- 4인 파티의 **조합 보너스**: 같은 직업 2명 → 공격력 10%, 3명 → 20%, 4명 → 30%
- **혼합 조합 보너스**: 전사+궁수+마법사 → "밸런스 조합" 방어력+공격력+쿨감 5%씩

#### 2.2.2 각인 시스템 (Inscription System)
탑 등반 세계관 연동 — "탑의 벽에 새겨진 고대 문양을 해독하여 힘을 얻는다":

```
각인 슬롯: 최대 6개 (50층마다 1슬롯 해금)
각인 획득: 보스 레이드/월드보스/비밀 방 드롭
각인 등급: 일반/희귀/영웅/전설
각인 효과:
  - 공격 각인: 기본 공격 대상 수 +1, 투사체 속도 +20% 등
  - 방어 각인: 피격 시 5% 확률로 무적 1초, 체력 비례 방어력 증가
  - 특수 각인: 처치 시 골드 +30%, 보스 데미지 +15% 등
```

- 유물과 차별화: 유물은 "장착 효과(조건부 발동)", 각인은 "영구 패시브(무조건 적용)"
- 각인 합성: 같은 각인 3개 → 상위 등급 각인 (실패 없음, 안전한 성장)

#### 2.2.3 탑의 축복 시스템 (Daily Blessing)
매일 접속 시 랜덤 축복 1개 부여 (24시간 지속):

| 축복 | 효과 | 확률 |
|------|------|------|
| 행운의 축복 | 드롭률 +50% | 25% |
| 전사의 축복 | 공격력 +30% | 25% |
| 수호의 축복 | 방어력 +30% | 20% |
| 탐험가의 축복 | 경험치 +50% | 20% |
| 축복받은 자 | 전체 +20% | 10% |

- 축복 변경: 루비 50으로 재롤 가능 (1일 3회)
- 프리미엄 축복: 배틀패스 보유 시 축복 2개 동시 적용

#### 2.2.4 층 정복 랭킹 (Floor Conquest)
- **서버 랭킹**: 최고 도달 층수 기준 실시간 랭킹
- **주간 랭킹**: 이번 주에 오른 층수 기준 (진행 속도 경쟁)
- **직업별 랭킹**: 전사/궁수/마법사 각각 Top 100
- **랭킹 보상**: 주간 리셋, 순위 구간별 루비 + 소환권 지급

| 순위 | 루비 | 소환권 |
|------|------|--------|
| 1위 | 3,000 | 무기 10 + 동료 10 |
| 2~10위 | 1,500 | 무기 5 + 동료 5 |
| 11~50위 | 800 | 무기 3 + 동료 3 |
| 51~100위 | 500 | 무기 2 + 동료 2 |
| 101~500위 | 300 | 무기 1 + 동료 1 |

## 3. 차기 콘텐츠 로드맵 (Phase 2)

### 3.1 시즌/배틀패스

#### 개요
- **시즌 주기**: 6주 (42일)
- **시즌 테마**: 탑의 층 테마 연동 (시즌 1: 숲의 탑, 시즌 2: 화산의 탑, ...)
- **배틀패스 레벨**: 총 50레벨
- **경험치 획득**: 일일 미션(300 BXP) + 주간 미션(1,500 BXP) + 자동 전투(시간당 50 BXP)

#### 배틀패스 트랙 설계

| 10 | 룬 조각 x50 | 동료 소환권 x5 |
| 15 | 골드 30,000 | 시즌 한정 코스튬 (상의) |
| 20 | 잠재의 수정 x10 | 루비 300 |
| 25 | 별의 결정 x30 | 시즌 한정 코스튬 (무기) |

#### 일일/주간 미션 (배틀패스 연동)
- **일일**: 몬스터 500마리 처치, 성장 던전 1회, 장비 강화 3회, 접속 30분 (각 100 BXP, 총 400 BXP)
- **주간**: 챕터 보스 3회 클리어, 월드보스 도전, PvP 5회, 무기 소환 10회 (각 500 BXP, 총 2,000 BXP)
- **6주 총 BXP**: (400 x 42) + (2,000 x 6) = 16,800 + 12,000 = 28,800 BXP
- **Lv.50 필요 BXP**: 25,000 (여유분 포함, 80% 이상 미션 달성 시 완주 가능)

#### 시즌 콘텐츠
- **시즌 한정 이벤트 층**: 특별 몬스터 + 시즌 전용 드롭
- **시즌 랭킹**: 시즌 내 최고 층수 경쟁
- **시즌 상점**: 시즌 포인트로 구매 (시즌 종료 시 리셋)

### 3.2 길드 시스템

#### 기본 구조
| 항목 | 내용 |
|------|------|
| 길드 정원 | 최대 30명 |
| 길드 레벨 | Lv.1~20 (경험치 기반) |
| 가입 조건 | 최소 층수 제한 설정 가능 |
| 직책 | 길드장 / 부길드장(2명) / 간부(5명) / 일반 |

#### 길드 콘텐츠

##### 1) 길드 보스 (Guild Boss) — 협동 레이드
- 매주 월/목 20:00~21:00 개최
- 길드원 전원이 같은 보스에게 누적 데미지
- 보스 HP = 길드 레벨 x 10,000,000
- **개인 보상**: 기여도(데미지 비율) 기반 보상 차등
- **길드 보상**: 클리어 시 길드 상점 포인트 지급

##### 2) 길드 토벌전 (Guild Conquest) — 길드 간 경쟁
- 주간 토너먼트: 7개 길드가 한 조
- 매일 21:00~22:00, 조 내 길드별 점수 경쟁
- 점수 = 해당 시간 내 길드원 총 처치 수
- 최종 순위별 보상 차등

##### 3) 길드 연구 (Guild Research)
```
공격 계열: 길드원 전체 공격력 +1~10%
방어 계열: 길드원 전체 방어력 +1~10%
수급 계열: 골드 드롭 +5~20%, EXP +5~20%
특수 계열: 성장 던전 열쇠 +1/일, 보스 레이드 +1회/주
```
- 길드 포인트로 연구 해금/업그레이드
- 연구 완료 시 길드원 전원에게 영구 적용

##### 4) 길드 상점 (Guild Shop)
- 길드 보스/토벌전 보상 포인트로 구매
- 상품: 소환권, 강화 재료, 길드 전용 코스튬, 한정 유물

#### 길드 재화
| 재화 | 획득처 | 용도 |
|------|--------|------|
| 길드 포인트 | 출석, 기부, 토벌전 | 길드 연구, 길드 상점 |
| 기여 포인트 | 길드 보스 기여도 | 개인 길드 상점 |

### 3.3 PvP 아레나

#### 기본 구조
- **비동기 PvP**: 실시간 대전이 아닌, 상대 캐릭터의 AI 클론과 전투
- **1v1 단판**: 60초 타임아웃, 먼저 상대를 처치하면 승리
- **입장 횟수**: 무료 5회/일, 루비 50으로 추가 1회 (최대 일일 10회)

#### 매칭 시스템
```
레이팅 시스템: ELO 기반 (시작 1000점)
매칭 풀: 레이팅 ±200 범위
시즌 리셋: 매 시즌 시작 시 레이팅 소프트 리셋 (현재 레이팅 × 0.75 + 250)
```

#### 등급 체계
| 등급 | 레이팅 | 시즌 보상 |
|------|--------|-----------|
| 브론즈 | 0~1,099 | 루비 100 |
| 실버 | 1,100~1,399 | 루비 300 + 소환권 3 |
| 골드 | 1,400~1,699 | 루비 600 + 소환권 5 |
| 플래티넘 | 1,700~1,999 | 루비 1,000 + 소환권 10 |
| 다이아몬드 | 2,000~2,299 | 루비 1,500 + 선택 유물 상자 |
| 마스터 | 2,300+ | 루비 2,500 + 한정 프로필 프레임 |

#### 아레나 상점
- **아레나 코인**: 승리 시 30, 패배 시 10 획득
- **상품**: 각인 선택 상자(2,000코인), 유물 상자(1,500코인), 코스튬 조각(500코인)

#### PvP 밸런스 원칙
- **직업 상성**: 전사 > 궁수 > 마법사 > 전사 (약 10% 스탯 보정)
- **보스 특화 세팅 ≠ PvP 세팅**: 유저가 프리셋 2개(사냥/PvP)를 관리
- **장비 격차 제한**: PvP에서 스탯 상한선 적용 (초과분은 50% 효율)

### 3.4 이벤트 시스템

#### 이벤트 유형

##### 1) 한정 던전 (Limited Dungeon)
- **주기**: 시즌마다 1~2회, 각 3~5일 운영
- **구조**: 5스테이지 진행형, 한정 보스 포함
- **보상**: 시즌 한정 재화 → 이벤트 상점에서 교환
- **진입 조건**: 이벤트 열쇠 (일일 3개 자동 충전)

##### 2) 특별 보스 레이드 (Special Boss Raid)
- **주기**: 격주 주말 (토~일)
- **구조**: 서버 전체 유저가 하나의 보스에 누적 데미지
- **보스 HP**: 서버 인원수 x 5,000,000
- **보상**: 기여도 순위별 차등 (유물/코스튬/소환권)

##### 3) 탑 침공 이벤트 (Tower Siege)
- **세계관 연동**: "탑에 균열이 생겨 강력한 몬스터가 쏟아진다"
- **구조**: 7일간 매일 등장하는 특수 웨이브 (일반 사냥 중 랜덤 발생)
- **특수 몬스터**: 평소보다 강하지만 한정 재료 드롭
- **누적 보상**: 총 처치 수 마일스톤 달성 시 보상

##### 4) 복귀 유저 이벤트
- **조건**: 7일 이상 미접속 후 복귀
- **기간**: 복귀 후 14일
- **보상**: 일일 미션 보상 2배, 성장 던전 무료 입장 +3회/일, 복귀 전용 소환 10회 무료

#### 이벤트 캘린더 예시 (시즌 1, 6주)
| 주차 | 이벤트 |
|------|--------|
| 1주 | 시즌 개막 + 접속 보상 7일 |
| 2주 | 한정 던전 "숲의 심연" (3일) |
| 3주 | 특별 보스 레이드 "고대 트레인트" (주말) |
| 4주 | 탑 침공 이벤트 (7일) |
| 5주 | 한정 던전 "잊혀진 정원" (3일) |
| 6주 | 시즌 마감 + 최종 보상 + 다음 시즌 예고 |

### 3.5 펫 시스템

#### 기본 구조
- **펫 역할**: 자동 아이템 수집 + 패시브 버프 + 도감 수집
- **펫 슬롯**: 메인 펫 1마리 + 도감 버프 (전부)
- **펫 획득**: 펫 알(챕터 사냥 확률 드롭) + 펫 상점(루비 구매)

#### 펫 등급 및 진화
| 등급 | 수집 범위 | 패시브 효과 | 진화 재료 |
|------|-----------|-------------|-----------|
| 일반 (Normal) | 반경 2 | 골드 +5% | - |
| 희귀 (Rare) | 반경 3 | 골드 +10%, EXP +5% | 일반 x3 |
| 영웅 (Epic) | 반경 4 | 골드 +15%, EXP +10%, 드롭률 +5% | 희귀 x3 |
| 전설 (Legend) | 반경 5 | 골드 +25%, EXP +15%, 드롭률 +10% | 영웅 x3 |
| 신화 (Mythic) | 반경 6 | 골드 +40%, EXP +25%, 드롭률 +15%, 특수 능력 | 전설 x3 |

#### 펫 종류 (초기 출시 8종)
| 이름 | 타입 | 특수 능력 (신화) |
|------|------|-----------------|
| 구름이 | 비행 | 이동속도 +15% |
| 돌덩이 | 지상 | 방어력 +20% |
| 불씨 | 화염 | 공격력 +15% |
| 이슬이 | 물 | HP 회복 +20% |
| 번개 | 전기 | 공격속도 +15% |
| 그림자 | 암흑 | 치명타율 +10% |
| 빛나리 | 빛 | 경험치 +30% |
| 별똥이 | 우주 | 전 스탯 +8% |

#### 펫 도감
- 펫 수집 시 도감 등록
- 도감 달성 보상: 2종 → HP +100, 4종 → 공격력 +50, 6종 → 방어력 +30, 8종 → 전체 +3%
- 버려지는 펫 없이 모든 펫이 도감 기여

#### 자동 수집 메커니즘
- 메인 펫이 플레이어 주변에서 자동으로 드롭 아이템 수집
- 수집 범위 = 펫 등급에 비례
- 수집 속도: 0.3초/아이템 (등급 무관)
- 오프라인 시: 자동 수집 100% 적용 (펫 미장착 시 50%)

### 3.6 코스튬/스킨 시스템

#### 구조
- **순수 외형 변경**: 스탯 영향 없음 (과금 공정성)
- **부위**: 머리/상의/하의/무기 스킨, 전신 세트
- **획득 경로**: 배틀패스, 이벤트 상점, 길드 상점, PvP 시즌 보상, 루비 상점

#### 코스튬 등급
| 등급 | 획득 방법 | 비고 |
|------|-----------|------|
| 일반 | 게임 진행 (층 마일스톤) | 기본 색상 변경 |
| 희귀 | 이벤트/길드 상점 | 디자인 변경 |
| 전설 | 배틀패스 Lv.40+ / PvP 시즌 | 특수 이펙트 포함 |
| 한정 | 시즌 한정, 재판매 없음 | 수집 가치 극대화 |

#### 전신 세트 보너스
- 같은 세트의 머리+상의+하의+무기 착용 시 **특수 이펙트** 발동 (공격 시 파티클 변경 등)
- 스탯 보너스는 없지만, 시각적 차별화로 과시 욕구 충족

### 3.7 엔드게임 콘텐츠

#### 3.7.1 무한 탑 (Endless Tower)
- **해금 조건**: 메인 스토리 100층 클리어
- **구조**: 1층부터 시작, 층마다 난이도 지수적 상승
- **리셋**: 없음 — 진행한 층수가 영구 기록
- **층별 보상**: 매 5층마다 소량 보상, 매 50층마다 대형 보상 (유물/각인/코스튬)
- **랭킹**: 서버 랭킹 + 직업별 랭킹 + 주간 진행 랭킹

#### 3.7.2 챌린지 모드 (Challenge Mode)
- **해금 조건**: 메인 스토리 50층 클리어
- **구조**: 특수 조건 제한 하에 스테이지 클리어
- **챌린지 예시**:

| 챌린지 | 조건 | 보상 |
|--------|------|------|
| 속도전 | 30초 내 클리어 | 루비 100 |
| 무피격 | 피격 0회로 클리어 | 각인 상자 |
| 저레벨 | 레벨 -20 디버프 | 코스튬 조각 |
| 보스 러시 | 보스 5연속 처치 | 유물 상자 |
| 생존 | 5분간 생존 (무한 웨이브) | 소환권 x5 |

- **주간 리셋**: 매주 새로운 챌린지 조합 (3개)
- **누적 별 보상**: 챌린지 클리어 시 별 1~3개, 누적 별 마일스톤 보상

#### 3.7.3 프레스티지 시스템 (Prestige System) — "탑의 윤회"
- **해금 조건**: 200층 도달
- **구조**: 현재 진행을 리셋하고 "윤회 보너스"를 획득
- **리셋 범위**: 층수, 레벨, 장비 강화 → 초기화
- **유지 항목**: 직업/전직, 동료, 유물, 각인, 코스튬, 도감
- **윤회 보너스**:

| 윤회 횟수 | 보너스 |
|-----------|--------|
| 1회 | 전 스탯 +5%, EXP 획득 +10% |
| 2회 | 전 스탯 +12%, EXP +20%, 골드 +15% |
| 3회 | 전 스탯 +20%, EXP +30%, 골드 +25%, 드롭률 +10% |
| 5회 | 전 스탯 +35%, 전 보너스 +40%, 윤회 전용 스킬 해금 |
| 10회 | 전 스탯 +60%, 윤회 전용 코스튬 |

- **윤회 상점**: 윤회 시 획득하는 "윤회의 결정"으로 전용 아이템 구매
- **핵심 설계**: 윤회할수록 빠르게 원래 진행도를 따라잡고, 더 높은 층에 도달 가능
