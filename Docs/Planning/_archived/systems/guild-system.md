# 길드 시스템 기획서

> Phase 13 신규 컨텐츠. 소셜 요소 + 길드 보스 + 기부 시스템.

---

## 개요

| 항목 | 내용 |
|------|------|
| 해금 | 스테이지 150 클리어 |
| 인원 | 최대 30명 |
| 기부 | 골드/루비 기부 → 길드 레벨 상승 |
| 길드 보스 | 주간 1회, 길드원 공동 데미지 누적 |
| UI 위치 | 퀵메뉴 → 길드 버튼 |

---

## 시스템 설계

### 1. 길드 생성/가입
- 생성: 루비 500 소모
- 가입: 공개/비공개 설정
- 길드명, 소개, 아이콘 설정

### 2. 기부 시스템
| 기부 종류 | 일일 한도 | 길드 경험치 |
|----------|----------|------------|
| 골드 10만 | 3회 | +100 |
| 루비 50 | 1회 | +300 |
| 소탕권 5 | 2회 | +150 |

### 3. 길드 레벨 & 버프
| 레벨 | 필요 EXP | 버프 |
|------|---------|------|
| 1 | 0 | 없음 |
| 2 | 5,000 | 경험치 +5% |
| 3 | 15,000 | 골드 +5% |
| 4 | 30,000 | ATK +3% |
| 5 | 60,000 | 드롭률 +5% |
| 6~10 | 누적 증가 | 복합 버프 |

### 4. 길드 보스
- 주간 1회 개방 (월요일 리셋)
- 길드원 각자 3회 도전 → 데미지 누적
- HP 소진 시 보상 메일 발송
- 보스 HP = 길드 레벨 × 100만

### 5. 길드 랭킹
- 주간 기부량 기준 개인 랭킹
- 길드 보스 데미지 기준 길드 랭킹

---

## 구현 범위 (Phase 13)

| 태스크 | 내용 |
|--------|------|
| GuildManager | 생성/가입/기부/레벨/버프 |
| GuildBossManager | 보스 전투 (기존 보스 시스템 재활용) |
| GuildUI | 길드 정보 + 기부 + 멤버 리스트 |
| SaveData | GuildSaveData (로컬, 서버 미연동) |
| 가이드 퀘스트 | GuildJoin 실제 연결 |
