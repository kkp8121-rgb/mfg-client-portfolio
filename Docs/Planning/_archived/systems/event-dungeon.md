# 이벤트 던전 기획서

> Phase 13 신규 컨텐츠. 주간 로테이션 특수 던전 — 특정 재화 집중 획득.

---

## 개요

| 항목 | 내용 |
|------|------|
| 해금 | 스테이지 75 클리어 (기존 던전과 동일) |
| 입장 | 무료 1회/일 + 소탕권으로 추가 |
| 로테이션 | 요일별 다른 던전 개방 |
| UI 위치 | 던전 탭 내 서브탭 "이벤트" |

---

## 요일별 던전

| 요일 | 던전 | 보상 집중 |
|------|------|----------|
| 월/목 | 골드 폭풍 | 골드 × 10배 |
| 화/금 | 경험치 숲 | EXP × 10배 |
| 수/토 | 강화석 광산 | 주문서 + 스타포스 재료 |
| 일 | 소환의 전당 | 소환권 + 무기 소환권 |

---

## 시스템 설계

### 1. 던전 구조
- 웨이브 3개 (일반 → 엘리트 → 미니보스)
- 제한 시간: 90초
- 클리어 등급: S/A/B/C (처치 속도 기준)
- 등급별 보상 배율: S=×3, A=×2, B=×1.5, C=×1

### 2. 난이도
- 기본/고급/지옥 3단계
- 고급: 스테이지 150+ 해금, 몬스터 ×2배 스탯
- 지옥: 스테이지 300+ 해금, 몬스터 ×5배 스탯, 보상 ×3

### 3. 소탕 (Quick Hunt 연동)
- 최고 등급 S 달성한 던전은 소탕 가능
- 소탕권 1장 소모 → 즉시 S등급 보상
