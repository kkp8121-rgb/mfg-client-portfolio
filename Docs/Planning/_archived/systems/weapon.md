## 개요

무기 = 소환(뽑기)으로 획득. 1개만 장착 가능.
**장착 효과** + **보유 효과** (인벤에 있기만 해도 스탯↑) 이중 구조.
각성(중복 합성) + 레벨업 + 승급으로 성장.

## 무기 성장 경로

### 1. 레벨업 (무기 강화석)
- 무기 강화석 + 골드 소모
- 레벨 상승 → 장착 효과 + 보유 효과 모두 상승
- 레벨캡 = 기본 100 + 각성당 +20

### 2. 각성 (중복 무기 합성)
- 같은 무기 ID로 합성 (0~5성)
- 각성 시 레벨캡 상승 (100→120→140→160→180→200)
- 일괄 각성: 모든 중복 무기 한 번에 각성

### 3. 승급
- 최대 레벨 도달 시 승급 가능
- 승급 재료 필요 (같은 등급 무기 N개)
- 승급 → 등급 내 티어 상승 (하급→중급→상급→최상급)

### 4. 보유 효과
- 무기를 장착하지 않아도 인벤토리에 있으면 스탯 적용
- 모든 무기의 보유 효과 합산 → 영구 패시브
- **핵심 성장 동기**: 무기를 많이 모을수록 강해짐

## 소환 레벨 연동

무기 소환 레벨이 오를수록 고등급 무기 확률 증가.
소환 레벨은 누적 소환 횟수로 자동 상승.
