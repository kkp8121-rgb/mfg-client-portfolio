# PvP 아레나 기획서

> Phase 13 신규 컨텐츠. 비동기 PvP — 실시간 대전이 아닌 AI 대리 전투.

---

## 개요

| 항목 | 내용 |
|------|------|
| 해금 | 스테이지 100 클리어 |
| 방식 | 비동기 PvP (상대방 AI가 전투) |
| 입장 | 무료 5회/일 + 티켓 추가 입장 |
| 보상 | 랭킹 등급별 주간 보상 |
| UI 위치 | 퀵메뉴 → 아레나 버튼 |

---

## 시스템 설계

### 1. 매칭
- 유사 전투력 ±20% 범위에서 3명 후보 표시
- 각 후보: 닉네임 + 전투력 + 대표 장비/직업 표시
- 선택 후 전투 시작

### 2. 전투
- 기존 자동 전투 시스템 재활용
- 상대방 캐릭터는 AI 제어 (MonsterController 파생)
- 제한 시간: 60초
- HP 0이 되면 패배, 시간 초과 시 HP 비율 비교

### 3. 랭킹 & 보상
| 등급 | 조건 | 주간 보상 |
|------|------|----------|
| 브론즈 | 기본 | 루비 50 + 골드 10만 |
| 실버 | 승률 50%+ | 루비 100 + 골드 30만 |
| 골드 | 승률 70%+ | 루비 200 + 골드 50만 + 소환권 3 |
| 다이아 | 상위 10% | 루비 500 + 골드 100만 + 소환권 10 |

### 4. 시즌
- 1시즌 = 2주
- 시즌 종료 시 등급 리셋 (1단계 하락)
- 시즌 보상 메일 발송

---

## 구현 범위 (Phase 13)

| 태스크 | 내용 |
|--------|------|
| ArenaManager | 매칭/전투/결과/랭킹 로직 |
| ArenaBattleScene | 전투 씬 (기존 전투 시스템 재활용) |
| ArenaUI | 매칭 화면 + 전투 결과 팝업 |
| 랭킹 데이터 | 로컬 저장 (서버 미연동) |
| 가이드 퀘스트 | ArenaTierReach 실제 연결 |

---

## 의존성
- MonsterController → PvP AI 컨트롤러 파생
- CombatStats → 상대방 스탯 복제
- SaveData → 아레나 시즌/등급 저장
