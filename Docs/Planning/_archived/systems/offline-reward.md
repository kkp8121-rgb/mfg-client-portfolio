# 방치 보상 강화 기획서

> Phase 13 신규 컨텐츠. 오프라인 보상 배율 + 광고 2배 + 최대 시간 확장.

---

## 개요

| 항목 | 내용 |
|------|------|
| 현재 | OfflineRewardManager에서 접속 시 시간 기반 골드/EXP 지급 |
| 목표 | 보상 배율 강화 + 광고 연동 + VIP 특전 |

---

## 시스템 설계

### 1. 현재 오프라인 보상 구조
- 최대 축적 시간: 8시간
- 분당 골드: (현재 스테이지 × 10)
- 분당 EXP: (현재 스테이지 × 5)
- 접속 시 팝업으로 수령

### 2. 강화 항목

| 항목 | 현재 | 개선 |
|------|------|------|
| 최대 축적 시간 | 8시간 | 12시간 (VIP: 24시간) |
| 기본 배율 | ×1 | ×1.5 (레벨 100+) |
| 광고 2배 | 없음 | 광고 시청 시 ×2 (1일 3회) |
| 장비 드롭 | 없음 | 시간당 확률 드롭 (10%/시간) |
| 소탕권 보너스 | 없음 | 소탕권 사용 시 오프라인 보상 +30분 추가 |

### 3. 오프라인 보상 팝업 개선
```
┌──────────────────────────┐
│   🌙 방치 보상           │
│   3시간 24분 동안 모았습니다  │
│                          │
│   💰 골드: 125,000       │
│   ⭐ 경험치: 62,500      │
│   🗡️ 장비: 희귀 투구     │
│                          │
│  ┌──────┐  ┌──────────┐  │
│  │ 수령 │  │ 광고 ×2배│  │
│  └──────┘  └──────────┘  │
└──────────────────────────┘
```

### 4. 부스터 연동
- 부스터(경험치/골드) 활성 중 접속 종료 → 남은 시간만큼 오프라인 보상에 배율 적용
- 예: 골드 부스터 ×2 남은 시간 30분 → 처음 30분간 골드 ×2

## 구현 범위 (Phase 13)

| 태스크 | 내용 |
|--------|------|
| OfflineRewardManager 확장 | 배율/광고/장비드롭/부스터 연동 |
| OfflineRewardPopup 개선 | 광고 버튼 + 장비 드롭 표시 |
| OfflineRewardConfigSO | 레벨별 배율/시간 테이블 |
| AdRewardManager 연동 | 광고 시청 → ×2 콜백 |

## 의존성
- OfflineRewardManager (기존)
- LoginFlowManager → 접속 시 팝업 플로우
- BoosterManager → 부스터 잔여 시간 연동
- AdRewardManager → 광고 SDK (추후)
