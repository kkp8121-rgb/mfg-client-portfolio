# 소환(뽑기) 시스템 기획서 v2

> 메이플 키우기 #33~36, #85~87 참조. **세로 뷰(9:16) 전환**.

---

## 개요

소환 = 재화(하트/다이아)를 소모하여 무기를 획득.
소환 레벨이 오를수록 고등급 확률 증가.

---

## 소환 카테고리

| 카테고리 | 획득 아이템 | 해금 시점 |
|---------|-----------|----------|
| 무기 소환 | 무기 | 메이플 등급 2 |
| 동료&펫 소환 | 펫 | (추후) |

- 장비는 소환 아님 → 사냥 드롭
- 유물은 별도 시스템 (소환 아님)

---

## UI 레이아웃 (세로 9:16)

```
┌───────────────────┐
│ ← 소환    💎N ❤N ✕│ 헤더 + 재화
├───────────────────┤
│                   │
│  [캐릭터 일러스트]  │ 직업별 전신 이미지
│                   │
│  현재 직업의 무기를  │
│  소환할 수 있습니다  │
│                   │
│  소환 레벨 ████░░  │
│  Lv.2   0/250    │
│                   │
│  [획득 정보 ⓘ]    │ 확률표 보기
├───────────────────┤
│ [카테고리 선택]     │
│ [무기소환] [펫소환]  │ 가로 탭 (2개)
├───────────────────┤
│[티켓][광고][1회][일괄]│ 하단 버튼 4개
│      [❤1] [❤200]  │
├──┬──┬──┬──┬──┬──┤
│소│캐│장│스│무│동│
└──┴──┴──┴──┴──┴──┘
```

**세로 전환 포인트:**
- 메이플은 좌측 세로 카테고리 → 세로에서는 상단 가로 탭
- 캐릭터 일러스트가 화면 상반부 차지 (시각적 임팩트)
- 소환 레벨 프로그레스바가 중앙
- 버튼은 최하단 (엄지 접근)

## 소환 방식

| 방식 | 비용 | 비고 |
|------|------|------|
| 티켓 1회 | 소환권 1장 | 사냥/퀘스트로 획득 |
| 광고 1회 | 무료 (1일 N회) | 광고 시청 |
| 하트 1회 | ❤1 | 기본 소환 |
| 일괄 소환 | ❤N (슬라이더) | 10~Max 선택 |

## 소환 결과 연출

1. 일괄 소환 시 빛 이펙트 애니메이션
2. 결과 화면: 무기 카드 나열 (NEW 뱃지)
3. 고등급(Epic+) 출현 시 특별 연출 (화면 깨짐, 골드 빛)
4. 소환 레벨 업 시 레벨업 연출 ("소환 레벨 N / 높은 등급 확률 증가")
