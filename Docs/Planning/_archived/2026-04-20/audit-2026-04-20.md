## 🤖 봇(AutoPlayBot) 블라인드 스팟 분석

### 현재 검증 항목 (얕음)
- 매니저 싱글턴 존재 여부
- `progress.completedIndex` 증가
- `TabBarUI.SelectTab(n)` 호출 성공
- `LearnedSkills.Count > 0`

### 검증 누락 (실제 버그 원천)
- 동일 이름 GameObject 개수 제한
- 컴포넌트 타입별 중복 검출
- UI 문서 내부 렌더 상태 (아이콘 텍스처 null)
- 패널 Activate 후 자식 visual element 존재
- 몬스터 스폰 직후 `MaxHp > 0 && !IsDead`
- 데이터 SO 에셋 개수 > 0
- `RequiredExp` 정상 범위 (Lv1=25)
- 세이브↔로드 왕복 후 상태 잔재

### 추가할 invariant (P0, 15종)

1. 씬 루트에서 `[UITK]*`, `Monster_*` 동명 GameObject 개수 ≤ 1
2. Player는 `PlayerCharacter`/`CombatStats`/`CharacterCombat` 각 정확히 1개
3. 모든 몬스터 프리팹 에셋에 `MonsterController` 정확히 1개
4. 스폰 직후 몬스터 `MaxHp > 0 && IsDead==false`
5. `LevelSystem.CurrentLevel ∈ [1,159] && RequiredExp`가 기대 범위
6. `QuestManager.CompletedGuideIndex ∈ [-1,350]`
7. 각 UITK 패널 `Q<T>()` null 없음 (필수 요소 존재)
8. 각 `[UITK]` GameObject 당 `UIDocument` 1개
9. `CharacterVisual.DesignId` == `JobSystem.CurrentJob.ToLower()`
10. `SkillSystem.CurrentActiveSkill.jobTier ≤ SaveData.player.jobTier`
11. `BattlePassSystem.GetReward(lv) != null for lv ∈ [1,50]`
12. `CollectionBookManager` 카테고리별 `total > 0`
13. 퀵메뉴 버튼 모두 `Q<Button>()` null 아님 (UXML 누락 검출)
14. `UpdateManager.Instance != null` (Play 직후)
15. 세이브 리로드 왕복 후 `CurrentActiveSkill` 정상 재구성
