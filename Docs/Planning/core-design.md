## 코어 루프

```
[자동 전투] → [재화+장비 획득] → [성장 투자] → [전투력↑] → [다음 스테이지] → 반복
                                    │
                                    ├── 장비 장착/교체
                                    ├── 무기 소환/각성/레벨업
                                    ├── 스탯 배분
                                    ├── 스킬 배우기/강화
                                    └── 슬롯 강화 (주문서/스타포스)
```

**핵심 원칙:**
1. 전투는 항상 자동 (Full Auto 기본)
2. 성장 경로는 명확하게 4~5개
3. "벽" → "스펙업 탐색" → "돌파" 루프가 자연스럽게 발생
4. 모든 성장이 **전투력** 하나의 숫자로 합산

- 팝업/탭 열면 전투 위에 오버레이

## 해금 순서 (가이드 퀘스트 기반)

메이플 키우기 분석 결과 해금 순서:
```
1. 전투 (즉시) — 자동 전투 시작, 스킬 하이라이트
2. 스탯 배분 (Lv2) — 캐릭터 탭 유도
3. 물약 (Lv6) — 자동 회복 설정
4. 스테이지 도전 (Stage 2) — [도전] 버튼 활성화
5. 무기 소환 (등급2) — 소환 탭 유도 → 무기 장착
6. 엘리트 몬스터 (Lv8) — 강화 드롭
7. 보스전 (챕터 끝) — 패턴 피하기 → 실패/재도전
8. 장비 (보스 클리어) — 장비 탭 해금
9. 스킬 (챕터2) — 스킬 탭 해금
10. (이후 분석 필요)
```

**mkLike 적용:**
- 동일 순서 따름. 가이드 퀘스트로 하나씩 해금.
- 해금 전 탭은 잠금(자물쇠) 표시.
- 해금 시 "신규 개방" 연출 + NPC 안내.

## 세로 뷰 UI 설계 원칙

1. **탭 콘텐츠는 세로 스크롤** — 가로 3분할(메이플)은 세로에서 상하 분할로 전환
2. **장비 탭**: 상단=장착슬롯(가로 4x2), 하단=인벤토리 스크롤
3. **무기 탭**: 상단=무기 그리드(4열), 하단=선택 무기 상세
4. **소환 탭**: 상단=캐릭터 일러스트+소환레벨, 하단=버튼
5. **폰트 크기**: 최소 14px (엄지 터치 대응)
6. **버튼**: 최소 44x44px (터치 영역)
7. **팝업**: 화면 80% 차지, 딤 배경
