- [ ] 무기 Promotion 시스템 도입 검토 (5각성 5복사본 → 상위 등급)

### 1-2. 데미지 공식 보강 (P0)

**메이플 키우기 데미지 관련 스탯**:

| 스탯 | 계산 방식 | mkLike 대응 |
|------|----------|-------------|
| Attack Speed | 곱연산 체감: `150*(1-(1-a/150)*(1-b/150)*...)` 최대 150% | 단순 합산 |
| Defense Penetration | 곱연산 체감: `100*(1-(1-a/100)*(1-b/100)*...)` | 미구현 |
| Final Damage | 각 소스 곱연산 (multiplicative) | 미구현 |
| Skill Cooldown Decrease | % 곱연산 먼저 → 고정값 → 7초 미만 시 0.5초 단위, 최소 4초 | 미구현 |
| Damage Taken Decrease | 곱연산 체감, 최대 95% | 미구현 |
| Stat Prop. Damage | 메인스탯 1% + 서브스탯 0.25% | 미구현 |

**mkLike 현재 공식**:
```
baseDmg = ATK * (100 / (100 + targetDEF))
finalDmg = baseDmg * skillMultiplier * critMultiplier * variance(±5%)
```

**권장 개선**:
- [ ] Final Damage 스탯 추가 (곱연산, 유물/버프 등에서 부여)
- [ ] Defense Penetration 스탯 추가 (보스전 핵심)
- [ ] Attack Speed 곱연산 체감 적용 (현재 합산이면 밸런스 붕괴 위험)
- [ ] 쿨다운 감소 최소값 하드캡 설정 (4초)

### 1-3. 경험치 곡선 조정 (P1)

**메이플 키우기 경험치 테이블 (발췌)**:

| 레벨 | 필요 EXP | 배율 |
|------|---------|------|
| 10 | 13,396 | ~1.4x/레벨 |
| 30 | 8,951,974 | ~1.3x |
| 50 | 4,242,128,285 | ~1.25x |
| 100 | 915,907,513,551,302 (~916조) | x2.0 점프 |
| 139 | 9,525,458,015,843,620,000 (~952경) | |

- **전직 레벨에서 큰 점프** (Lv.60: x1.72, Lv.100: x2.0, Lv.110+: x1.5)
- 구간별 점진적 배율: 1.5x → 1.4x → 1.28x → 1.25x (안정)

**mkLike 현재 공식**:
```
RequiredExp(level) = 20 + (level * level * 5)
// Lv.100→101: 51,045
```

**문제점**: 2차함수는 너무 완만. 키우기류의 "천문학적 수치 + 빠른 초반" 체감 불가.

**권장 개선**:
- [ ] 지수적 경험치 곡선 도입 (기본 배율 1.25x/레벨 + 전직 구간 점프)
- [ ] 큰 수 표시 포맷팅 (만/억/조/경 또는 K/M/B/T)
- [ ] 오프라인 EXP와 연동하여 "잠깐 안 해도 레벨업 체감" 보장

### 1-4. 오프라인 보상 보정 (P1)

**메이플 키우기 오프라인**:
- 킬 속도: **51마리/분 고정** (레벨/스탯 무관)
- 최소 5분 오프라인 필요
- 드롭 계산: 결정론적 (확률 × 몬스터 수 = 기대 드롭)
- 프리미엄 멤버십: x1.5
- 온라인이 유리한 기준: 분당 50킬 이상 (= 온라인 플레이 유인)

**mkLike 현재**:
- `OFFLINE_REWARD_MULTIPLIER = 10` (분당 골드/EXP = 몬스터 × 10배)
- 최대 12시간 (720분)

**문제점**: "10배"라는 배율의 근거가 불명확. 온라인 대비 밸런스 미정의.

**권장 개선**:
- [ ] 오프라인 킬 속도를 고정값으로 설정 (예: 40~60마리/분)
- [ ] 온라인 플레이가 항상 유리하도록 설계 (온라인 분당 킬 > 오프라인 킬)
- [ ] 아이템 드롭도 오프라인에 포함 (결정론적 기대값 계산)
- [ ] VIP/멤버십 배율 훅 준비 (x1.5)

### 2-2. 장비 강화 수치 (메이플 키우기)

**주문서 강화**: 슬롯당 10회, 5번째/10번째에 성공률 보너스
**스타포스**: 슬롯 기반 (장비 교체해도 유지)
- 13→14성: 하락 가능
- 15→16성: 파괴 가능
- 19성+: 완화 옵션

**잠재능력 등급**: Rare → Epic → Unique → Legendary → Mystic
- 부위별 고유옵션 (장갑: 크리뎀, 망토: 최종뎀 등)

**mkLike 현재 잠재능력 확률 (CombatFormula)**:

| 등급 변경 | 확률 | Pity 천장 |
|----------|------|----------|
| None→Rare | 6% | 33회 |
| Rare→Epic | 3.33% | 60회 |
| Epic→Unique | 1.67% | 120회 |
| Unique→Legendary | 0.6% | 333회 |
| Legendary→Mythic | 0.21% | 714회 |

→ 잠재능력 천장은 유지해도 됨 (메이플 키우기도 큐브 리롤은 확률 기반이지만 천장 개념은 약하게 존재)
