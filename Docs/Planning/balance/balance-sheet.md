## 3. 전투 공식

### 3-1. 데미지 공식 (v2 — 메이플 키우기 참고 보강)

```
effectiveDef = DEF × (1 - DefensePenetration)     // 곱연산 체감
baseDmg      = ATK × (100 / (100 + effectiveDef))
finalDmg     = baseDmg × skillMul × critMul × variance × (1 + FinalDamage) × (1 + BossDamage)
receivedDmg  = finalDmg × (1 - DamageTakenDecrease)
```

| 요소 | 값 / 방식 |
|------|-----------|
| critMul | 1.5 (기본, CritDmg 스탯으로 증가) |
| variance | 0.95 ~ 1.05 (균등분포) |
| 최소 데미지 | 1 |
| FinalDamage | **곱연산** — (1+a)×(1+b)×... |
| DefensePenetration | **곱연산 체감** — 1-(1-a)(1-b)... (최대 100%) |
| BossDamage | 합산 (보스 상대 시만 적용) |
| DamageTakenDecrease | **곱연산 체감** — 1-(1-a)(1-b)... (최대 95%) |

### 3-2. CP (전투력) 공식

```
CP = (ATK * 4) + (DEF * 3) + (HP / 5) + (CritRate * 500)
```

| 레벨 | 전사 CP |
|------|---------|
| 1 | 12*4 + 8*3 + 150/5 + 0.05*500 = 48+24+30+25 = **127** |
| 10 | 42*4 + 38*3 + 360/5 + 0.05*500 = 168+114+72+25 = **379** |
| 50 | 112*4 + 108*3 + 960/5 + 0.05*500 = 448+324+192+25 = **989** |
| 100 | 212*4 + 208*3 + 1635/5 + 0.05*500 = 848+624+327+25 = **1,824** |
| 150 | 312*4 + 308*3 + 2385/5 + 0.05*500 = 1248+924+477+25 = **2,674** |

| 75 | 110.7 | 110.7 | 10.4 | 5.8 | 8,440 | 506,371 |
| 100 | 123.8 | 123.8 | 12.4 | 4.8 | 36,960 | 2,217,629 |

### 8-4. 시뮬레이션 해석

- **TTK 곡선**: 1층 3.3초 -> 100층 12.4초로 완만하게 증가. 방치형 게임에 적합한 곡선.
- **골드 인플레이션**: 지수적 골드 드롭(1.07^floor)이 강화 비용(1.12^lv)보다 느리게 상승하므로, 고층으로 갈수록 강화 병목이 생긴다. 이는 의도된 설계로, 과금/가챠로 보충하는 구조.
- **생존성**: 몬스터 ATK 대비 전사 HP/DEF가 충분히 높아 자동 전투에서 즉사하지 않는다. 50층 이후 보스전에서 힐/버프 스킬이 핵심이 된다.
- **DPS 대비 몬스터 HP**: 방어력 감소 공식(100/(100+DEF))으로 인해 고층에서도 유효 데미지가 크게 꺾이지 않는다. DEF 152 기준 약 40% 감소로 수렴.

## 9. 밸런스 체크포인트

### 9-1. 핵심 비율

| 항목 | 목표 | 현재 |
|------|------|------|
| 일반몹 TTK (중반) | 5~10초 | 6~9초 (적절) |
| 보스 TTK (동레벨) | 30~60초 | HP x8 기준 약 50~100초 |
| 레벨업 주기 (중반) | 3~5분 | 층수/레벨 비례 조정 필요 |
| 가챠 천장 도달 | 10연차 4~5회 | 동료 4회(40회), 장비 5회(50회) (적절) |
| 오프라인 12시간 = 능동 플레이 N시간 | 2~3시간 | 10배율 기준 약 2시간 (적절) |

### 9-2. 알려진 주의사항

1. **궁극기 DPS 기여 < 1%**: 의도된 설계. 궁극기는 범위 CC + 생존 유틸리티 역할.
2. **골드 인플레이션 < 강화 비용 인플레이션**: 자연스러운 병목으로 과금 유도. 너무 가파르면 이탈 우려.
3. **크리티컬 미반영**: 시뮬레이션은 크리티컬 미적용 기준. 전사 5% CritRate 시 평균 DPS +2.5%.
4. **스킬 배율 미반영**: 기본 공격(배율 100%) 기준. 강타(200%) 등 스킬 사용 시 실질 DPS 2배 이상.
