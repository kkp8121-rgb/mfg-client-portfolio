# 전투 공식 레퍼런스

## CombatFormula.cs 공식 정리

### 몬스터 스탯 스케일링 (층수 기반)
- HP: `30 + floor × 15`
- ATK: `3 + floor × 2`
- DEF: `2 + floor × 1.5`

### 보스 배율
- 미니보스: HP ×8, ATK ×1.5, DEF ×1.2, 골드 ×10, 경험치 ×10
- 챕터보스: 골드 ×50, 경험치 ×50

### 전투력(CP) 공식
`CP = (ATK × 4) + (DEF × 3) + (HP / 5) + (CritRate × 500)`

### 데미지 계산 (DamageCalculator)
`최종데미지 = ATK × 스킬배율 × (1 - DEF방어율) × 크리배율`
- 방어율: `DEF / (DEF + 100)` (수확체감)
- 크리배율: CritRate 확률로 ×1.5 (기본)

### 무기 등급 배율
| 등급 | 배율 |
|------|------|
| Normal | 1.0× |
| Rare | 1.5× |
| Epic | 2.5× |
| Unique | 4.0× |
| Legendary | 7.0× |
| Mythic | 12.0× |

### 동료 레벨 스케일링
- ATK 비율: `baseRatio × (1 + (level-1) × 0.1)`
- 장착 효과: `baseValue × (1 + (level-1) × 0.05)`

### 유물 각성 스케일링
- 패시브: `baseValue × (1 + awakeningLevel × 0.2)`
- 액티브: `baseValue × (1 + awakeningLevel × 0.15)`

### 오프라인 보상 상수

- 최대 누적: 24시간 (1,440분)
- `OfflineExpPerMin(floor) = MonsterExp(floor) × 50 × 0.6`
- `OfflineGoldPerMin(floor) = MonsterGold(floor) × 50 × 0.6`

### 무기 스케일링
- ATK: `baseAtk × gradeMultiplier × (1 + (level-1) × 0.05)`
- 각성: `+10% per star`
- 최종: `ATK × gradeMultiplier × levelMultiplier × awakeningMultiplier`
