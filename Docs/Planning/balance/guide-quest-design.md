# 가이드 퀘스트 설계 원칙

> 레퍼런스: 메이플 키우기 (MapleStory Idle RPG)
> 데이터: `reference/guide-quest-data.json`

---

## 핵심 공식: 방치형 RPG 성장 사이클

```
가이드 퀘스트 완료 → 보상(재화/장비) → 캐릭터 성장 → 다음 퀘스트 도전
       ↑                                              ↓
   (과금으로 가속) ←── 진행 벽 (스테이지 돌파 실패) ←──┘
```

---

## 1. 순환 구조 (14종 사이클)

메이플 키우기의 가이드 퀘스트는 14종이 정해진 순서로 **무한 반복**:

| 순서 | 타입 | mkLike 대응 | 소요 시간 (목표) |
|------|------|------------|----------------|
| 1 | 지도 돌파 | ClearStage | 즉시~수분 (진행 벽) |
| 2 | 적 처치 | KillMonsters | 10~30초 |
| 3 | 엘리트 몬스터 소환 | (EliteSummon) | 즉시 |
| 4 | 무기 소환 | WeaponGacha | 즉시 |
| 5 | 동료 소환 | GachaPull | 즉시 |
| 6 | 월드보스 입장 | (BossRaid) | 즉시 |
| 7 | 빠른 사냥 | QuickHunt | 즉시 |
| 8 | 무기 던전 | ClearDungeon | 즉시~10초 |
| 9 | 강화 던전 | ClearDungeon | 즉시~10초 |
| 10 | 경험치 던전 | ClearDungeon | 즉시~10초 |
| 11 | 장비 던전 | ClearDungeon | 즉시~10초 |
| 12 | 아레나 입장 | ArenaMatch | 즉시 |
| 13 | 무기 소환 레벨 달성 | (SummonLevel) | 누적 |
| 14 | 엘리트 소환 레벨 달성 | (SummonLevel) | 누적 |

**핵심**: 1사이클에서 "지도 돌파"(#1)만 진행 벽이 될 수 있고, 나머지 13개는 즉시~수초.
유저는 13개를 빠르게 클리어하며 보상을 받고, #1에서 잠시 멈추고, 성장 후 돌파.

## 2. 구간별 페이싱 (지수적 상승)

### 초반 (사이클 1~4, 퀘스트 1~56)
- **1사이클 = 3~5분**
- 시스템 해금 퀘스트가 사이에 삽입 (스킬, 무기, 던전 등)
- 진행 벽 거의 없음 → 빠른 도파민, 시스템 교육
- 과금 유도: 없음 (리텐션 집중)

### 중반 (사이클 5~10, 퀘스트 57~140)
- **1사이클 = 10~30분**
- "지도 돌파"에서 진행 벽 본격 발생
- 벽 → 가챠/강화로 돌파 시도 → **"보상이 아까우니 좀 더 과금"**
- 오프라인 보상이 핵심 성장 수단 (접속 유도)
- 과금 유도: 패스, 핫딜 장비, 소환권 패키지

### 후반 (사이클 11+, 퀘스트 141~)
- **1사이클 = 1시간~**
- 아레나/길드 해금 → PvP 랭킹 = 전투력 경쟁
- 벽이 크지만 순환 보상이 풍부해 동기 유지
- 과금 유도: 랭킹 경쟁, 시즌 패스, 프리미엄 소환

## 3. 컨텐츠 해금 삽입 (메이플 키우기 기준)

순환 사이클 중간에 "특수 퀘스트"가 삽입되어 새 시스템을 해금:

| ~34 | 무기 던전, 성장 던전 | DungeonManager |
| ~45 | 경험치 던전 | EventDungeon |
| ~58 | 월드보스 | BossRaid |
| ~67 | 장비 던전 | EventDungeon |
| ~75 | 빠른 사냥 (소탕) | QuickHunt |
| ~79 | 영웅의 힘 | HeroPower |
| ~89 | 부스터 | Booster |
| ~96 | 동료 | Companion |
| ~113 | 어빌리티 | Ability |
| ~131 | 강화 던전, 장비 강화 슬롯 | StarForce |

**원칙**: 해금 퀘스트는 순환 사이클을 일시 중단하고, 새 시스템을 소개한 뒤 다시 순환에 합류.

## 4. 요구량 설계 (지수적)

각 사이클의 "지도 돌파" 요구 스테이지:
```
사이클 1: 스테이지 5
사이클 2: 스테이지 10
사이클 3: 스테이지 15
사이클 4: 스테이지 25
사이클 5: 스테이지 40
사이클 6: 스테이지 60
사이클 7: 스테이지 85
사이클 8: 스테이지 115
...
```

"적 처치" 요구량:
```
사이클 1: 50마리
사이클 2: 100마리
사이클 3: 200마리
사이클 4: 500마리
...
```

**원칙**: 요구량은 지수적으로 증가하되, 현재 전투력으로 1~3분 이내 달성 가능한 범위.
진행 벽은 오직 "지도 돌파"에서만 발생하도록 설계.

## 5. 보상 설계

| 퀘스트 타입 | 주 보상 | 부 보상 |
|------------|--------|--------|
| 지도 돌파 | 루비 (대량) | 장비/무기 소환권 |
| 적 처치 | 골드 | — |
| 소환 계열 | 소환 재화 | — |

**원칙**: 보상은 다음 사이클을 준비하는 재화. 자급자족 사이클.

## 6. 과금 유도 포인트

1. **진행 벽 (지도 돌파)**: "장비가 부족해서 못 넘어감" → 핫딜/소환 패키지 노출
2. **오프라인 보상**: "더 많이 받으려면 프리미엄 패스" → 2배 오프라인 보상
3. **아레나 랭킹**: "TOP 100에 들려면 전투력이 부족" → 경쟁 과금
4. **시즌 패스**: 사이클 완료 시 추가 보상 → 패스 구매 유도
5. **편의 과금**: 소탕권, 던전 열쇠, 부스터 → 시간 단축

## 7. mkLike 적용 계획

### 현재 상태
- 가이드 퀘스트 100개 (Quest_Guide_01~100): 비순환, 장기 목표 위주
- 순환 퀘스트 17개 (Quest_Cycling_01~17): G-50 이후 활성화

### 목표
- 가이드 퀘스트를 14종 순환 기반으로 **전면 재생성**
- 초반 50개: 순환 + 시스템 해금 삽입
- 50개 이후: 순환만 (현재 Cycling Quest와 통합)
- 요구량: 지수적 상승, 진행 벽은 ClearStage에서만

### 구현
- `GuideQuestGenerator` 에디터 도구로 SO 자동 생성
- 순환 순서 + 해금 테이블 + 요구량 커브를 코드에 정의
- AutoPlayBot으로 전체 플로우 검증
