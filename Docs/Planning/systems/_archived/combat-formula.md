# 전투 공식 기획서 (P2-05)

## 개요
- **목적**: 자동 전투에서 적절한 긴장감과 성장 실감을 제공하는 데미지 시스템
- **핵심 경험**: "강해졌다"를 수치로 체감할 수 있어야 한다. 동시에 상위 층에서는 약간의 도전감이 있어야 한다.

## 데미지 공식

### 기본 공식
```
finalDamage = baseDamage * skillMultiplier * critMultiplier * randomVariance

baseDamage = ATK * (100 / (100 + targetDEF))
```

### 각 항목 설명
| 항목 | 공식 | 설명 |
|------|------|------|
| baseDamage | `ATK * (100 / (100 + DEF))` | 방어력 감쇄. DEF=100이면 50% 감쇄 |
| skillMultiplier | 스킬SO의 `damageMultiplier` | 일반공격=1.0, 스킬=1.5~3.0 |
| critMultiplier | 치명타 시 `1.5` (기본) | critRate 확률로 발동 |
| randomVariance | `Random(0.95, 1.05)` | ±5% 랜덤 변동 |

### 방어력 감쇄 곡선
| 방어력(DEF) | 감쇄율 | 실질 데미지 비율 |
|-------------|--------|------------------|
| 0 | 0% | 100% |
| 50 | 33% | 67% |
| 100 | 50% | 50% |
| 200 | 67% | 33% |
| 500 | 83% | 17% |

> `100 / (100 + DEF)` 공식은 방어력이 올라갈수록 효율이 감소하는 수확 체감 구조. 방어력 스택이 무한히 강해지는 것을 방지한다.

## 전투력(CP) 공식

```
CP = (ATK * 4) + (DEF * 3) + (HP / 5) + (CritRate * 500) + (SkillBonus)
```

- CP는 표시용 지표. 실제 전투 결과와 정확히 비례하지 않아도 됨
- 플레이어에게 "강해졌다"는 직관적 피드백 제공

## 밸런스 시트: 캐릭터 기본 스탯

### 직업별 기본 스탯 (레벨 1)
| 스탯 | 전사 | 궁수 | 마법사 |
|------|------|------|--------|
| HP | 150 | 100 | 80 |
| ATK | 12 | 15 | 18 |
| DEF | 8 | 5 | 3 |
| CritRate | 5% | 10% | 5% |
| AttackSpeed | 1.0 | 1.3 | 0.8 |
| MoveSpeed | 3.0 | 3.5 | 3.0 |

### 레벨당 성장
| 스탯 | 전사 | 궁수 | 마법사 |
|------|------|------|--------|
| HP/Lv | 15 | 8 | 6 |
| ATK/Lv | 2 | 3 | 4 |
| DEF/Lv | 2 | 1 | 0.5 |

### 직업 설계 의도
- **전사**: 높은 생존력(HP+DEF), 낮은 화력. 안정적 자동 사냥
- **궁수**: 밸런스형. 빠른 공속으로 DPS 보완
- **마법사**: 유리 대포. 최고 ATK지만 가장 낮은 생존력

## 밸런스 시트: 몬스터

### 일반 몬스터 (층수 기반 스케일링)
```
monsterHP  = 30 + (floor * 15)
monsterATK = 3 + (floor * 2)
monsterDEF = 2 + Round(floor * 1.5)
goldReward = 10 * 1.07^(floor - 1)   ← 지수적 성장
expReward  = 5 * 1.06^(floor - 1)    ← 지수적 성장
```

### 미니보스 (100마리 처치 후 출현)
```
miniBossHP  = monsterHP * 10
miniBossATK = Round(monsterATK * 1.3)
miniBossDEF = monsterDEF
miniBossGold = goldReward * 10
miniBossExp  = expReward * 10
```

### 챕터 보스 (X-BOSS 스테이지)
```
bossHP  = monsterHP * 8
bossATK = Round(monsterATK * 1.5)
bossDEF = Round(monsterDEF * 1.2)
bossGold = goldReward * 50
bossExp  = expReward * 50
```

## 시뮬레이션 결과

### 전사 레벨 1 vs 1층 일반 몬스터
- 몬스터: HP=45, ATK=5, DEF=4
- 전사: HP=150, ATK=12, DEF=8, 공속=1.0
- 전사 → 몬스터: 12 * (100/104) = 11.5 dmg/hit → TTK ≈ **3.9초**
- 몬스터 → 전사: 5 * (100/108) = 4.6 dmg/s
- 전사 생존시간: 150 / 4.6 ≈ **32초** → 안전
- 동시 몬스터 5마리 기준: 생존 ≈ **6.5초** → 적절

### 전사 레벨 1 vs 1층 미니보스
- 미니보스: HP=450 (x10), ATK=6.5 (x1.3), DEF=4
- 전사 → 미니보스: 11.5 dmg/s → TTK ≈ **39초**
- 미니보스 → 전사: 6.5 * (100/108) = 6.0 dmg/s → 생존 ≈ **25초**
- → **레벨 2~3에서 잡을 수 있는 난이도** (의도된 벽)

### 전사 레벨 1 vs 1층 챕터 보스
- 보스: HP=360 (x8), ATK=7.5 (x1.5), DEF=4.8 (x1.2)
- 전사 → 보스: 12 * (100/104.8) = 11.4 dmg/s → TTK ≈ **31초**
- 보스 → 전사: 7.5 * (100/108) = 6.9 dmg/s → 생존 ≈ **21초**
- → **위험! 레벨업 또는 장비 필요**

### 전사 레벨 5 vs 5층 챕터 보스
- 전사: HP=210, ATK=20, DEF=16
- 보스: HP=840 (x8), ATK=19.5 (x1.5), DEF=12 (x1.2)
- 전사 → 보스: 20 * (100/112) = 17.9 dmg/s → TTK ≈ **47초**
- 보스 → 전사: 19.5 * (100/116) = 16.8 dmg/s → 생존 ≈ **12.5초**
- → 장비/스킬 없이는 클리어 불가. **성장 시스템 투자가 필요한 구간**

## 경험치/레벨업 공식

### 필요 경험치
```
requiredExp = 20 + (level * level * 5)
```

| 레벨 | 필요 EXP | 누적 EXP |
|------|----------|----------|
| 1→2 | 25 | 25 |
| 2→3 | 40 | 65 |
| 3→4 | 65 | 130 |
| 5→6 | 145 | 495 |
| 10→11 | 520 | 2,895 |
| 20→21 | 2,020 | 21,770 |

### 레벨업 보상
- 스탯 자동 증가 (직업별 성장치)
- 스탯 포인트 +3 (자유 분배)
- 특정 레벨: 스킬 슬롯 해금, 전직 자격

## 스테이지 진행 규칙

### 구조
- 1층 = 1스테이지
- 일반 몬스터 10마리 처치 → 보스 출현 (5층마다)
- 보스 없는 층: 10마리 처치 시 자동으로 다음 층 이동

### 맵 테마 변경
| 층수 | 테마 | 배경 |
|------|------|------|
| 1~10 | 초원/숲 | forest |
| 11~20 | 동굴 | cave |
| 21~30 | 화산 | volcano |
| 31~40 | 하늘 | sky |
| 41~50 | 심연 | abyss |

### 층수 스케일링 철학
- 10층 단위로 난이도 점프 (테마 변경 + 몬스터 스탯 추가 보정)
- 보스가 벽 역할 → 성장 투자 후 돌파하는 구조
- 방치하면 현재 층에서 반복 사냥 (골드/EXP 획득)

## 자동 전투 규칙

### 캐릭터 행동 우선순위
1. 사망 시 → 부활 타이머 (3초 후 부활, 같은 층 재시작)
2. 적이 사거리 내 → 공격 (일반 공격)
3. 스킬 쿨다운 완료 → 스킬 사용 (슬롯 순서)
4. 적이 없음 → 오른쪽으로 자동 이동
5. 맵 끝 도달 → 대기 (보스 스폰 대기)

### 공격 사거리
| 직업 | 사거리 | 설명 |
|------|--------|------|
| 전사 | 1.5 유닛 | 근접 |
| 궁수 | 6.0 유닛 | 원거리 |
| 마법사 | 5.0 유닛 | 원거리 |

## 엣지 케이스

| 상황 | 처리 |
|------|------|
| 플레이어 사망 | 3초 후 같은 층 시작 지점에서 부활 |
| 보스 처치 실패 (사망) | 부활 후 일반 몬스터부터 다시 시작 |
| 동시 사망 (플레이어+몬스터) | 플레이어 사망 우선 처리, 몬스터 처치는 인정 |
| HP 0 이하 오버킬 | HP는 0 미만으로 내려가지 않음 (clamp) |
| 층수 이탈 (음수/0) | 최소 1층으로 clamp |
