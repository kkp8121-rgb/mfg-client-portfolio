## 0. 설계 원칙

> 경쟁작 분석(AFK Arena, 메이플 키우기, Idle Heroes, 세븐나이츠 키우기)에서 도출한 핵심 원칙.

| # | 원칙 | 근거 |
|---|------|------|
| 1 | **60초 보상 체인** | AFK Arena: 첫 30분 동안 행동→보상 간격이 60초를 넘지 않음. 보상이 끊기는 순간 이탈 발생. |
| 2 | **Before/After 필수** | AFK Journey: 모든 성장 행위에 전후 수치 비교. 변화를 못 느끼면 행위의 가치가 0. |
| 3 | **가이드+체크리스트 이중 구조** | 메이플 키우기(가이드 퀘스트) + Idle Heroes(일일 11항목). 장기 방향 + 단기 루틴 동시 제공. |
| 4 | **추천 버튼으로 오류 방지** | 신규 유저가 잘못된 선택을 하지 않도록 "추천" 하이라이트. 장비 비교, 스탯 분배, 동료 편성에 적용. |
| 5 | **복귀 유저 캐치업** | 3일+ 미접속 복귀 시 "복귀 가이드"로 현재 상태 요약 + 즉시 할 일 안내. |
| 6 | **즉시 전투, 설명 최소화** | 30초 안에 첫 전투 시작. 텍스트 튜토리얼 대신 행동으로 학습. |

## 1. 신규 유저 첫 30분 (분 단위 상세)

> 온보딩 튜토리얼(`onboarding-tutorial.md`)과 연계하되, 여기서는 **유저 심리 흐름**에 초점을 맞춘다.
> **핵심 규칙: 행동→보상 간격 60초 이내.** 아래 타임라인에서 보상 열이 비는 구간이 없도록 설계.

### 0~2분: 첫 로그인 → 직업 선택

| 시간 | 유저 행동 | 시스템 | 심리 상태 |
|------|-----------|--------|-----------|
| 0:00 | 앱 실행 | 스플래시 (2초) | 기대감 |
| 0:02 | 인트로 컷신 (스킵 가능) | TutorialManager | "탑을 오른다고?" |
| 0:15 | 직업 선택 화면 | JobSystem | 선택의 즐거움 |
| 0:30 | 직업 확정 → 아레나 진입 | StageManager | "시작이다!" |

**체감 포인트:**
- 직업 선택 화면에서 각 직업의 **전투 미리보기 애니메이션** 재생 (SPUM Idle + 스킬 1개 시연)
- 전직 경로 미리보기: "견습 전사 → 나이트 → 워로드 → 타이탄 → 드래곤 슬레이어"
- 선택 후 "당신의 여정이 시작됩니다" + 화면 전환 연출 (SceneTransitionManager Circle)

### 2~5분: 첫 전투 → 첫 레벨업 → 스킬 체감

| 시간 | 유저 행동 | 시스템 | 심리 상태 |
|------|-----------|--------|-----------|
| 0:30 | 자동 전투 관전 (1-1) | CharacterCombat, MonsterController | "알아서 싸우네?" |
| 1:00 | 첫 몬스터 처치, 골드/EXP 드롭 | LootDrop, FloatingTextManager | "보상이 쏟아진다!" |
| 2:00 | Lv.2 달성 → 스탯 분배 | LevelSystem, StatAllocationSystem | "내가 직접 키우는구나" |
| 2:30 | 공격력 +1 투자 → 데미지 증가 확인 | CombatStats, DamageText | **"강해졌다!"** |
| 3:00 | 미니보스 등장 → 처치 | StageManager (튜토리얼 약화 보스) | 긴장 → 성취 |
| 3:30 | 1-1 클리어! 보상 폭발 | StageTransitionEffect | 도파민 |

**핵심 연출:**
- 첫 레벨업 시 `LevelUpEffect` 전체 화면 팡파레 + 전투력(CP) 수치 변화 애니메이션
- 스탯 투자 전후 **데미지 비교**: "이전: 12 → 현재: 15 (+25%)" 텍스트
- 미니보스 처치 시 `DeathEffect` + 골드 분수 연출 + `ScreenShakeManager`

### 5~10분: 첫 장비 → 장착 → 전투력 변화 확인

| 시간 | 유저 행동 | 시스템 | 심리 상태 |
|------|-----------|--------|-----------|
| 4:00 | 장비 3종 지급 (노말 투구/상의/무기) | TutorialManager | "공짜 장비!" |
| 4:30 | 무기 장착 (강제 가이드) | EquipmentManager, TutorialHighlight | "이걸 끼면..." |
| 5:00 | **CP 150 → 230 상승 연출** | HudAnimator, ProgressBarAnimator | **"확 강해졌다!!"** |
| 5:30 | 하단 탭 소개 (캐릭터/던전/상점) | TutorialManager | 시스템 인지 |
| 6:00 | 1-3 진행, 몹 처치 속도 체감 증가 | CharacterCombat | 장비 효과 실감 |
| 8:00 | Lv.10 → Passive 스킬 해금 | SkillSystem | "스킬이 늘었다!" |

**체감 포인트:**
- 장비 장착 시 **전후 비교 팝업** 필수:
  ```
  ┌─────────────────────────────┐
  │     전투력 변화              │
  │  150 ──────→ 230  (+53%)   │
  │                             │
  │  공격력  +15                │
  │  방어력  +8                 │
  │  최대HP  +120               │
  └─────────────────────────────┘
  ```
- CP 수치가 올라갈 때 숫자 카운트업 애니메이션 (DOTween `DOCounter`)
- 스킬 해금 시 스킬 아이콘이 HUD 슬롯에 **팝인** 연출 + 첫 발동 시 슬로모션 0.3초

### 10~15분: 첫 가챠 → 동료 획득 → 편성

| 시간 | 유저 행동 | 시스템 | 심리 상태 |
|------|-----------|--------|-----------|
| 10:00 | Lv.15 달성 → 무료 10연차 해금 | GachaManager | "무료 뽑기!" |
| 10:30 | 10연차 연출 (카드 뒤집기) | GachaEffect | 기대감 → 흥분 |
| 11:00 | 동료 10명 결과 화면 | GachaManager | "레어 나왔다!" |
| 11:30 | 메인 동료 장착 (강제) | ClimbingPartyManager | "같이 싸우네!" |
| 12:00 | 동료 소환 → 전투 참여 확인 | CompanionCombat | 든든함 |
| 13:00 | 서브 동료 배치 → 패시브 버프 | CompanionEffectApplier | CP 추가 상승 |

**핵심 연출:**
- 가챠 10연차 연출: `GachaEffect`로 카드 순차 뒤집기, 마지막 카드는 Rare 확정
- 획득 결과에서 **현재 파티와 비교**: "이 동료를 배치하면 CP +80!"
- 동료 첫 소환 시 화면 중앙에 등장 연출 + 이름/등급 배너

### 15~20분: 첫 던전 → 보상 → 강화 시도

| 시간 | 유저 행동 | 시스템 | 심리 상태 |
|------|-----------|--------|-----------|
| 15:00 | 챕터 1 보스 클리어 → 던전 해금 | StageManager, DungeonManager | "새 콘텐츠!" |
| 15:30 | 경험치 던전 첫 도전 (무료 1회) | DungeonManager | "열쇠 시스템 이해" |
| 16:00 | 던전 클리어 → 대량 EXP 획득 | DungeonManager | "한 번에 이만큼!" |
| 17:00 | 강화 던전 도전 → 룬 조각 획득 | DungeonManager | 재료 모으기 |
| 18:00 | 주문서 강화 1회 (튜토리얼 100% 성공) | EquipmentEnhanceSystem | **"강화 성공!!"** |
| 18:30 | CP 상승 확인 | HudAnimator | 성취감 |

**체감 포인트:**
- 던전 클리어 보상은 **한 번에 쏟아지는 연출** (골드/EXP 아이콘이 비처럼 내림)
- 강화 성공 시 `EnhanceResultEffect` (성공 폭죽 + 장비 아이콘 빛남)
- 강화 전후 비교: "투구 +1 → 공격력 +3, 방어력 +2"

### 20~30분: 첫 스테이지 보스 → 자유 플레이 전환

| 시간 | 유저 행동 | 시스템 | 심리 상태 |
|------|-----------|--------|-----------|
| 20:00 | 챕터 2 진행, Lv.20 도달 | StageManager | 자신감 |
| 22:00 | Buff 스킬 해금 + 등반 조합 소개 | SkillSystem, ClimbingPartyManager | "파티 편성!" |
| 25:00 | 일일 퀘스트 목록 확인 | QuestManager | 목표 인지 |
| 27:00 | 아레나 첫 도전 (해금 시) | ArenaManager | 경쟁 자극 |
| 30:00 | **튜토리얼 완료 → 자유 플레이** | TutorialManager | "이제 뭘 할까?" |

**30분 시점 유저 상태 목표:**
- Lv. 20~25
- CP 500~800
- 장비 5~7개 장착
- 동료 10명 보유 (메인 1 + 서브 1~2)
- 스킬 5~6개 습득
- 던전 2~3회 클리어
- **"다음 목표" 위젯이 활성화되어 길을 안내**

### "추천" 버튼 적용 지점

> 신규 유저의 오류를 방지하는 "추천" 하이라이트.

| 시점 | 적용 위치 | 추천 로직 |
|------|-----------|-----------|
| 스탯 분배 | 공격력 버튼 하이라이트 | 직업별 주 스탯 추천 (전사:HP/방어, 궁수:공격/크리, 마법사:공격/MP) |
| 장비 장착 | "추천 장착" 버튼 | CP 기여가 가장 높은 장비 자동 선택 |
| 동료 편성 | "추천 편성" 버튼 | CP 기여가 가장 높은 동료 조합 자동 선택 |
| 스킬 레벨업 | 최고 DPS 스킬 하이라이트 | 레벨 구간별 추천 스킬 테이블 참조 |
| 가챠 결과 | "자동 장착" 버튼 | 현재보다 CP 기여 높은 아이템만 제안 |
| 던전 선택 | "추천 던전" 표시 | 현재 가장 부족한 재화에 해당하는 던전 |

## 2. 일간 사이클 (접속 후 15~30분 루틴)

### 2.1 접속 즉시 (0~3분): 보상 수령

```
[앱 시작]
    │
    ▼
[오프라인 보상 팝업] ──── OfflineRewardSystem
  "12시간 동안 골드 45,000 + EXP 12,000 획득!"
  → OfflineRewardPopup 표시
  → "광고 시청 시 2배!" (AdRewardManager)
    │
    ▼
[출석 체크] ──── AttendanceSystem
  → 연속 출석 보상 수령
  → AttendanceEffect 연출 (스탬프 쾅)
    │
    ▼
[일일 축복 선택] ──── DailyBlessingSystem
  → 3가지 축복 중 1개 선택 (또는 탑의 휘장으로 재롤)
  → "오늘의 축복: 공격력 +15%"
    │
    ▼
[전투 화면 복귀] ──── 자동 전투 재개
```

**설계 의도:** 접속 즉시 보상이 쏟아지는 경험 → "접속하면 좋은 일이 있다" 각인

### 2.2 핵심 루틴 (3~15분): 소진 콘텐츠

```
[일일 퀘스트 목록 확인] ──── QuestManager (매일 리셋)
    │
    ├── [던전 3회] ──── DungeonManager (열쇠 소비)
    │     ├── 경험치 던전 1회
    │     ├── 무기/강화 던전 1회
    │     └── 등반자의 시련 1회
    │
    ├── [아레나 3회] ──── ArenaManager (일일 제한)
    │     → 승리 시 아레나 코인 + ELO 상승
    │     → ArenaResultPopup 표시
    │
```

```
          → 등반의 증표 소비 → 능력치 상승
```

**핵심 원칙:** 모든 재화 소비 후 **CP 변화를 즉시 표시**. "골드 50,000 소비 → CP +45" 형태.

## 4. 성장 체감 포인트 (핵심)

> **모든 획득/장착/강화 시 유저가 "강해졌다"를 느끼지 못하면 시스템이 무의미하다.**
> 경쟁작 분석: AFK Journey가 이 부분을 가장 잘 해결 — 장비 변경 시 전투력 수치 즉시 반영.

### 4.1 전투력(CP) = PowerScore 상시 표시

**현재 구현 상태:** HudPanel에 CP 표시 있음 (`HudAnimator` 연동)

**강화 필요 사항:**
- CombatStats에 `PowerScore` 통합 계산 메서드 추가: 공격력/방어력/HP/크리티컬 등을 가중 합산한 단일 수치
- CP 변화 시 **카운트업 애니메이션** (현재값 → 새값, 0.5초간 숫자 롤링)
- CP 1,000 단위 돌파 시 **팡파레 연출** (ScreenShakeManager 미세 진동 + 숫자 PunchScale)
- CP 변화 원인 표시: "장비 강화로 CP +45!" (FloatingTextManager)
- **Before/After 비교는 모든 성장 행위에 적용** (4.2절 참조)

### 4.2 전후 비교 UI (모든 성장 행위에 적용)

| 행위 | 비교 대상 | 표시 방식 |
|------|-----------|-----------|
| 장비 장착 | 기존 장비 vs 새 장비 | 스탯별 초록(상승)/빨강(하락) 화살표 |
| 장비 강화 | 강화 전 vs 강화 후 | CP 변화량 + 개별 스탯 변화 |
| 스킬 레벨업 | 현재 Lv vs 다음 Lv | 데미지/쿨타임/범위 비교 |
| 동료 장착 | 현재 파티 vs 변경 후 | CP 변화 + 시너지 보너스 표시 |
| 가챠 결과 | 현재 최강 vs 획득 아이템 | "현재보다 ATK +150!" 강조 |
| 코스튬 장착 | 이전 외형 vs 새 외형 | 미리보기 + 세트 효과 진행도 |
| 전직 | 이전 직업 vs 새 직업 | 스탯 총 변화 + 신규 스킬 목록 |
| 환생 | 현재 보너스 vs 환생 후 보너스 | 영구 보너스 증가량 |

### 4.3 가챠 후 즉시 체감 흐름

현재 문제: "가챠 후 뭐가 바뀌는지 모르겠다"

**해결 흐름:**
```
[가챠 10연차 실행]
    │
    ▼
[결과 화면] ──── 10개 카드 뒤집기 연출 (GachaEffect)
    │
    ▼
[자동 비교 팝업] ──── 핵심 신규 시스템
  ┌────────────────────────────────────┐
  │  ★ 추천 장착 ★                     │
  │                                    │
  │  [Rare] 화염의 궁수 (동료)          │
  │  → 메인 동료로 장착하면:            │
  │    공격력 +120, 크리티컬 +5%        │
  │    CP 680 → 820 (+20.6%)           │
  │                                    │
  │  [Epic] 바람의 검 (무기)            │
  │  → 현재 무기보다:                   │
  │    공격력 +85 ▲                     │

  │                                    │
```

**자동 비교 로직:**
1. 가챠 결과에서 현재 장비/동료보다 **CP 기여가 높은 아이템**을 자동 탐지
2. 상위 3개까지 "추천 장착" 팝업에 표시
3. "자동 장착" 버튼으로 원클릭 적용 → CP 상승 연출

### 4.4 강화 실패도 체감 있게

- 주문서 강화 실패: "다음 도전에서 5번째 강화 확률이 올라갑니다!" (희망)
- 성급 강화 실패(하락): 화면 살짝 흔들림 + 빨간 이펙트, 하지만 "복구 비용: 다이아 5,000" 안내
- 잠재 재롤 실패: 현재 옵션과 새 옵션 나란히 표시 → "현재 유지 / 변경" 선택
- **천장 게이지 표시**: 잠재 천장까지 남은 횟수를 프로그레스 바로 표시 → 기대감 유지

## 5. "다음 뭐 하지?" 해결 — 가이드 퀘스트 + 목표 위젯 + 일일 체크리스트

> **유저가 게임 내에서 길을 잃지 않도록 항상 "다음 목표"를 제시한다.**
> 경쟁작 분석: 메이플 키우기는 항상 "다음에 할 일"이 화면에 노출. AFK Arena는 캠페인/탑/봉우리 3축 영구 진행 + 일일/주간 퀘스트. Idle Heroes는 11개 일일 퀘스트 전부 클리어 시 보너스 크리스탈.
>
> mkLike는 이 3가지를 모두 결합한다: **가이드 퀘스트 체인**(영구 진행) + **목표 위젯**(HUD) + **일일 체크리스트**(소진 콘텐츠 가시화)

### 5.0 가이드 퀘스트 체인 (GuideQuest) — 핵심 신규 시스템

> 메이플 키우기의 "항상 다음 할 일이 보이는" 구조를 차용한다.
> QuestManager에 `QuestType.Guide` 타입을 추가하여 **영구 진행 체인 퀘스트**를 구현한다.

**구조:**
- 가이드 퀘스트는 **체인 형태**: 하나를 완료하면 다음이 자동 활성화
- 각 퀘스트는 현재 유저 진행도에 맞는 **가장 유익한 행동**을 안내
- 스킵 불가능하지만, 다른 콘텐츠를 하다가 자연스럽게 달성될 수 있음

**가이드 퀘스트 체인 목록 (총 50+ 단계):**

| 단계 | 퀘스트 내용 | 보상 | 다음 퀘스트로의 연결 |
|------|-------------|------|---------------------|
| G-01 | 첫 전투 승리 | 골드 200 | → G-02 |
| G-02 | 레벨 5 달성 | 골드 1,000 | → G-03 |
| G-03 | 장비 1개 장착 | 노말 장비 1개 | → G-04 |

### 5.1 목표 가이드 위젯 (NextGoalWidget)

**위치:** 화면 우측 상단, HUD 영역 (전투 화면에서 항상 표시)
**가이드 퀘스트와 연동:** 현재 활성 가이드 퀘스트를 위젯에 표시

```
┌──────────────────┐
│ 📌 다음 목표      │
│                  │
│ Lv.40 달성       │
│ → 1차 전직!      │

│                  │
│ 탭하여 상세 보기  │
└──────────────────┘
```

**위젯 동작:**
- 현재 유저 상태에 따라 **가장 가까운 달성 가능 목표**를 자동 선택

### 5.3 목표 선택 알고리즘

```
1. 튜토리얼 미완료 → 무조건 튜토리얼 목표
2. 일일 소진 콘텐츠 남음 → 소진 콘텐츠 우선
3. 나머지 → "달성까지 남은 비율"이 가장 높은(=가장 가까운) 목표 선택
4. 동률 시 → 보상 가치가 높은 것 우선
5. 모든 목표 달성됨 → "자유 파밍" 모드 (탑 도전 권장)
```

## 6. 시스템 간 연결 고리 (순환 설계)

> 각 시스템이 독립적으로 존재하면 유저는 "왜 이걸 해야 하지?"를 느낀다.
> **모든 시스템은 다른 시스템의 입력/출력으로 연결되어야 한다.**

### 6.1 성장 순환도

```
                    ┌──────────────┐
                    │   자동 전투   │
                    │ (스테이지 진행)│
                    └──────┬───────┘
                           │ 골드/EXP/사냥포인트/드롭
                           ▼
              ┌────────────────────────┐
              │     재화 획득           │
              │  (골드, 소환권, 재료)    │
              └────────┬───────────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
    ┌──────────┐ ┌──────────┐ ┌──────────┐
    │ 장비 강화  │ │ 가챠 소환  │ │ 스탯 투자  │
    │ (룬/별결정)│ │ (소환권)   │ │ (레벨업)   │
    └────┬─────┘ └────┬─────┘ └────┬─────┘
         │            │            │
         └────────────┼────────────┘
                      │ CP 상승
                      ▼
              ┌──────────────────┐
              │   더 높은 층 돌파   │
              │   (탑/던전/보스)   │

```

### 6.2 재화 순환 매트릭스

| 재화 | 획득처 | 소비처 | 부족 시 유도 |
|------|--------|--------|-------------|
| 골드 | 스테이지, 던전, 오프라인 | 강화, 합성, 상점 | "골드 던전 추천!" |
| 루비 | 업적, 퀘스트, 배틀패스 | 가챠, 프리미엄 상점 | "일일 퀘스트 완료하세요" |
| 소환권 (동료) | 던전, 퀘스트, 상점 | 동료 가챠 | "무기 던전 추천!" |
| 소환권 (무기) | 던전, 퀘스트, 상점 | 무기 가챠 | "무기 던전 추천!" |
| 룬 조각 | 강화 던전 | 주문서 강화 | "강화 던전 추천!" |
| 별의 결정 | 스테이지 보스, 상점 | 성급 강화 | "챕터 보스 도전!" |
| 등반의 증표 | 등반자의 시련 | 등반자의 힘 | "시련 던전 추천!" |
| 아레나 코인 | 아레나 승리 | 아레나 상점 | "아레나 도전!" |
| 길드 포인트 | 길드 보스, 기여 | 길드 상점 | "길드 보스 참여!" |
| 코스튬 실 | 분해, 스테이지 드롭 | 코스튬 합성 | "불필요 코스튬 분해!" |

### 6.3 재화 부족 → 콘텐츠 유도 시스템

유저가 강화/소환 시 재화가 부족하면:

```
┌────────────────────────────────┐
│  룬 조각이 부족합니다!           │
│  현재: 5개 / 필요: 20개         │
│                                │
│  [강화 던전으로] ← 바로가기      │
│  남은 열쇠: 2개                 │
│                                │
│  [상점에서 구매]                 │
│  룬 조각 x50 = 루비 200         │
└────────────────────────────────┘
```

이 팝업으로 **재화 부족 → 던전/상점 → 재화 획득 → 강화 → CP 상승** 순환이 자연스럽게 형성된다.
