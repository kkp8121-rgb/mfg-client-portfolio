# mkLike 시스템 피드백 + 유저 사이클 보고서

> 작성일: 2026-03-17
> 목적: 사용자 피드백 기반 — UI/연출 부족, 끊긴 시스템 연결, 유저 사이클 설계

---

## 1. 현재 상태 진단

### 1.1 숫자로 보는 현황
- **197개 태스크 완료** (카테고리 1~22 + 25)
- **69+ 싱글톤 매니저**, **30+ 비주얼 시스템**
- **하지만**: 사용자 체감 = "가챠 후 할 수 있는 게 없다", "뭐가 바뀌었는지 모르겠다"

### 1.2 근본 원인
| 문제 | 원인 | 심각도 줘
|------|------|--------|
| "가챠 후 할 게 없다" | 자동 장착/편성 흐름 없음, 수동으로 패널 열어야 함 | **치명적** |
| "뭐가 바뀌었는지 모르겠다" | Before/After CP 비교 UI 없음, 인과관계 불명확 | **치명적** |
| "다음에 뭘 하지?" | 가이드 퀘스트 데이터 50+개 미구성, 목표 제시 없음 | **치명적** |
| UI가 게임답지 않다 | GUI Kit 미적용, 비주얼 폴리싱 미진행 | **높음** |
| 연출이 밋밋하다 | 강화/장착/레벨업 연출 부족, 텍스트 기반 결과 | **높음** |

## 2. 끊긴 시스템 파이프라인 분석

### 2.1 가챠 → 전투 체감 파이프라인

```
[가챠 실행] ─✅─→ [결과 연출(GachaEffect)] ─✅─→ [획득 팝업]
     │                                              │
     │  ✅ 카드 플립, 등급별 이펙트 구현됨            │
     │                                              ▼
     │                                    [바로가기 팝업(AcquisitionShortcut)]
     │                                    "장착하기" / "파티에 추가" 버튼 ✅
     │                                              │
     │                                              ▼
     │                                    [패널 열림] ← ❌ 여기서 끊김!
     │                                    - 자동 장착 없음
     │                                    - CP 비교 없음
     │                                    - "이 장비가 더 좋은가?" 판단 불가
     │                                              │
     │                                              ▼ (수동 장착 시)
     │                                    [CP 변화] ─⚠️─→ [CpCounterWidget]
     │                                    - 숫자는 올라가지만
     │                                    - "왜 올랐는지" 불명확
     │                                    - 전투에서 체감 없음
     │                                              │
     │                                              ▼
     │                                    [전투] ← ❌ 체감 연결 없음
     │                                    - 킬 속도 변화 시각화 없음
     │                                    - "강해졌다" 느낌 없음
```

### 2.2 끊긴 고리 상세

| # | 끊긴 지점 | 현재 상태 | 필요한 것 |
|---|-----------|-----------|-----------|
| 1 | **가챠 → 자동 비교** | 팝업에서 패널 열기만 | "현재 장비 vs 새 장비" CP 비교 팝업 |
| 2 | **비교 → 자동 장착** | 수동으로 슬롯 선택 | "장착하면 CP +500" → 원터치 장착 |
| 3 | **장착 → CP 변화 인과** | 숫자만 올라감 | "장비 장착으로 CP 1,200 → 1,700 (+500)" 명시 |
| 4 | **CP 변화 → 전투 체감** | 연결 없음 | 킬 속도 변화 표시, "데미지 +30%" 등 |
| 5 | **동료 획득 → 편성** | 수동으로 파티 패널 | 자동 최적 편성 제안 |
| 6 | **강화 → 결과 피드백** | EnhanceResultEffect 있음 | 강화 전후 스탯 비교 팝업 추가 |
| 7 | **레벨업 → 다음 목표** | 레벨업 이벤트만 발행 | "다음 전직까지 Lv.X" 가이드 |

### 2.3 이미 구현된 것 (활용 가능)

놀랍게도, **백엔드 로직은 대부분 구현되어 있다**:
- `GachaCompareSystem.cs` — CP 변화 추정 로직 존재 (UI 미연결)
- `RecommendationManager.cs` — 장비/동료/스탯/던전 추천 로직 완성 (UI 버튼 미연결)
- `AcquisitionShortcutPopup.cs` — 바로가기 팝업 존재 (흐름이 끊김)
- `StatCompareView.cs` — 전후 비교 컴포넌트 존재 (배치 미완)
- `CpCounterWidget.cs` — CP 변동 연출 완성 (발행 로직 불완전)
- `EquipComparePopup.cs` — 장비 비교 팝업 존재 (가챠 흐름에 미연결)

**결론: 코드는 있는데 "연결"이 안 되어 있다. 신규 구현보다 연결 작업이 핵심.**

## 3. UI/연출 피드백

### 3.1 연출이 있는 것 vs 없는 것

| 액션 | 연출 상태 | 수준 |
|------|-----------|------|
| 가챠 카드 플립 | ✅ GachaEffect | 화려함 (등급별 글로우, NEW 뱃지) |
| 강화 성공/실패 | ✅ EnhanceResultEffect | 보통 (색상 플래시, 펀치) |
| CP 변동 | ✅ CpCounterWidget | 좋음 (카운트업, 마일스톤 팡파레) |
| 비밀 방 발견 | ✅ SecretRoomPopup | 좋음 (등급별 글리치) |
| **장비 장착** | ❌ 없음 | — |
| **동료 편성** | ❌ 없음 | — |
| **레벨업** | ❌ 없음 | 이벤트만 발행, 화면 연출 없음 |
| **전직** | ❌ 없음 | 텍스트 변경만 |
| **직업 선택** | ❌ 없음 | 미리보기 없음 |
| **스킬 해금** | ❌ 없음 | — |
| **업적 달성** | ❌ 없음 | — |
| **출석 보상** | ❌ 없음 | — |
| **배틀패스 보상** | ❌ 없음 | — |

### 3.2 UI 리소스 현황

`Assets/Folder_Assets/UI_Packs/` 에 RPG_UI 폴더가 존재하나, **실제 에셋(이미지/프리팹)은 미확인**. 폴더 구조만 있을 수 있음.

### 3.3 UI 폴리싱 필요 항목

| 패널 | 현재 상태 | 필요한 것 |
|------|-----------|-----------|
| HUD (상단) | 기능만 있음 | 배경/테두리/아이콘 비주얼 |
| 장비 패널 | 슬롯 나열 | 등급별 테두리 색상, 장착 이펙트 |
| 동료 패널 | 텍스트 기반 | 초상화, 등급 프레임, 시너지 표시 |
| 가챠 화면 | GachaEffect 있음 | 배경, 버튼, 확률 표시 UI 폴리싱 |
| 던전 선택 | 텍스트 목록 | 던전 아이콘, 난이도 표시, 보상 미리보기 |
| 설정 | 기능만 있음 | 디자인 없음 |

## 4. 유저 사이클 설계

### 4.1 일간 사이클 (Daily Cycle)

> **목표: 접속 → 5~10분 "숙제" → 보상 체감 → 다음 접속 동기**

```
┌──────────────────────────────────────────────────────────────┐
│  [접속]                                                       │
│    ↓                                                          │
│  [출석 보상 수령] (0:00~0:15)                                 │
│    ├── 7일 사이클 스탬프                                      │
│    ├── "쾅" 연출 + 골드/루비 획득                             │
│    └── 연속 출석 보너스 표시                                  │
│    ↓                                                          │
│  [오프라인 보상 수령] (0:15~0:30)                             │
│    ├── 미접속 시간 x 분당 처치 수 기반                        │
│    ├── 골드/EXP 카운트업 연출                                 │
│    └── "광고 시청으로 2배!" 버튼                              │
│    ↓                                                          │
│  [일일 체크리스트 확인] (0:30~1:00)                           │
│    ├── 11개 항목 한눈에 보기                                  │
│    ├── 랜덤 2배 보상 항목 확인                                │
│    └── "오늘 할 일" 동선 파악                                 │
│    ↓                                                          │
│  [자동 사냥 확인 + 보스 도전] (1:00~3:00)                    │
│    ├── 현재 스테이지 진행 확인                                │
│    ├── 보스 도전 (실패하면 강화 유도)                         │
│    └── 처치 수 마일스톤 보상 수령                             │
│    ↓                                                          │
│  [던전 소화] (3:00~5:00)                                     │
│    ├── 열쇠 소모 (일일 충전)                                  │
│    ├── 경험치/무기/장비/강화 던전 3회씩                       │
│    └── 던전 보상 → 즉시 사용처 안내                           │
│    ↓                                                          │
│  [가챠 + 장착] (5:00~7:00)                                   │
│    ├── 소환권으로 동료/무기 뽑기                              │
│    ├── ★ 결과 비교 팝업 → 원터치 장착                        │
│    └── CP 변화 연출                                           │
│    ↓                                                          │
│  [강화] (7:00~8:00)                                          │
│    ├── 장비 주문서/성급 강화                                  │
│    ├── 무기 레벨업/각성                                       │
│    └── ★ 강화 전후 비교 팝업                                 │
│    ↓                                                          │
│  [PvP + 길드] (8:00~10:00)                                   │
│    ├── 아레나 5회 (일일 도전)                                 │
│    ├── 길드 보스 (주 2회 중 도전)                             │
│    └── 아레나 코인/길드 코인 수령                             │
│    ↓                                                          │
│  [일일 체크리스트 완료 보상] (10:00~10:30)                   │
│    ├── 11/11 완료 → 루비 100 + 소환권 2장                    │
│    └── "내일도 접속하면 연속 보너스!" 표시                    │
│    ↓                                                          │
│  [종료 or 추가 사냥]                                         │
│    ├── 오프라인 보상 안내: "이대로 두면 X시간 후 골드 Y 획득" │
│    └── 다음 접속 동기 부여                                    │
└──────────────────────────────────────────────────────────────┘
```

**핵심 원칙:**
1. **5~10분이면 숙제 완료** — 바쁜 유저도 이탈하지 않음
2. **매 단계마다 보상** — 60초 이상 보상 없는 구간 없음
3. **"다음에 뭘 하지?"가 없음** — 체크리스트가 동선을 안내
4. **종료 시에도 동기 부여** — 오프라인 보상 예고

### 4.2 주간 사이클 (Weekly Cycle)

| 요일 | 콘텐츠 | 보상 | 비고 |
|------|--------|------|------|
| **매일** | 일일 체크리스트 11종 | 루비 100 + 소환권 2 | 5~10분 숙제 |
| **매일** | 자동 사냥 + 던전 | 경험치/골드/재화 | 핵심 성장 |
| **매일** | 아레나 5회 | 아레나 코인 | PvP |
| **월~일** | 주간 퀘스트 7종 | 루비 300 + 소환권 5 | 주간 보너스 |
| **월** | 챌린지 리셋 | 별 마일스톤 보상 | 주간 챌린지 |
| **화/금** | 길드 보스 | 길드 코인 + 유물 조각 | 주 2회 |
| **수** | 토벌전 | 길드 코인 + 마일스톤 | 주 1회 |
| **토~일** | 주말 이벤트 던전 | 특별 보상 (2배 드롭) | 주말 동기 |
| **일** | 배틀패스 보상 확인 | 무료/프리미엄 보상 | 시즌 진행 |

**주간 보상 총계 (예상):**
- 루비: 700+ (일일 100x7) + 300 (주간) = 1,000+
- 소환권: 14+ (일일 2x7) + 5 (주간) = 19+
- 아레나 코인: 35+ (일 5회x7)
- 길드 코인: 200+ (보스 2회 + 토벌전 1회)

### 4.3 장기 성장 플랜 (Long-term Progression)

```
[신규 유저 첫 30분]
  ↓
Phase 1: 입문 (Lv.1~40, 0~3일)
  ├── 직업 선택 (전사/궁수/마법사)
  ├── 기본 스킬 4개 해금 + 자동 시전
  ├── 첫 장비 세트 획득 (보상)
  ├── 첫 동료 1명 획득 (보상)
  ├── 탑 1~50층 돌파
  ├── 1차 전직 (Lv.40)
  └── [체감] "스킬이 생겼다!" + "동료가 같이 싸운다!"

Phase 2: 성장 (Lv.40~80, 3~7일)
  ├── 가챠 본격 시작 (소환권 축적)
  ├── 장비 강화 (주문서/성급)
  ├── 동료 3인 편성 완성
  ├── 던전 5종 해금 + 일일 소화
  ├── 탑 50~100층
  ├── 2차 전직 (Lv.80)
  └── [체감] "가챠로 좋은 거 뽑았다!" + "강해졌다!"

Phase 3: 확장 (Lv.80~120, 1~2주)
  ├── 아레나 해금 (PvP 경쟁)
  ├── 길드 가입 → 길드 보스
  ├── 코스튬 수집 시작
  ├── 챌린지 모드 해금
  ├── 탑 100~200층
  ├── 3차 전직 (Lv.120)
  └── [체감] "PvP에서 이겼다!" + "길드와 함께!"

Phase 4: 심화 (Lv.120~160, 2~4주)
  ├── 장비 잠재능력/보조 잠재
  ├── 유물 시스템 본격 활용
  ├── 등반 조합 최적화
  ├── 도감 수집 (마일스톤 보상)
  ├── 탑 200~300층
  ├── 4차 전직 준비 (Lv.160 + 탑 300층)
  └── [체감] "빌드 최적화!" + "도감 채우기!"

Phase 5: 엔드게임 (Lv.160+, 1개월+)
  ├── 4차 전직 + 마스터리 트리
  ├── 탑 비밀 방 탐험
  ├── 아레나 마스터 등급 도전
  ├── 길드 보스 1위 기여
  ├── 윤회 (프레스티지) → 영구 강화
  ├── 코스튬 합성 (전설 세트 완성)
  └── [체감] "최강이 되었다!" + "도감 100%!"
```

### 필요한 것
1. **연결**: 가챠→비교→장착→CP변화 파이프라인 E2E 완성
2. **연출**: 장착/레벨업/전직/강화 시 시각적 피드백
3. **가이드**: 50+개 가이드 퀘스트 + 11개 일일 퀘스트 데이터
4. **UI**: GUI Kit 적용으로 "게임다운" 비주얼

### 핵심 메시지
> **더 많은 시스템을 만드는 것이 아니라, 기존 시스템을 "느끼게" 만들어야 한다.**
> 코드의 95%는 이미 있다. 남은 5%의 "연결"이 게임의 100%를 결정한다.
