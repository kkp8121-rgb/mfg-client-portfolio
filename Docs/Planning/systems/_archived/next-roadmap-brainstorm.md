## 2. 신규 시스템 브레인스토밍 (10종)

### 2.1 4차 전직 시스템

현재 3직업(전사/궁수/마법사) x 3차 전직(Lv.40/80/120) 구조에서, **4차 전직(Lv.160)**을 추가하여 엔드게임 성장 축을 확장한다.

**핵심 설계:**
- 4차 전직 해금 조건: Lv.160 + 특수 퀘스트 (탑 300층 클리어)
- 각 직업의 4차 직업명: 전사→**드래곤 슬레이어**, 궁수→**스톰브링어**, 마법사→**아크메이지**
- 4차 전직 시 해금: 궁극기 강화(2단계), 전용 패시브 4개, 마스터리 트리(3갈래 분기)
- 마스터리 분기는 한 번에 1개만 선택 가능하며, 등반의 증표로 변경 가능 (리스펙)
- **기존 시스템 연동**: JobSystem 확장, SkillDataSO에 4차 스킬 추가, CombatStats modifier 연동

**세계관:** "탑의 300층을 넘어선 자만이 탑의 핵심에 도달하여, 고대의 힘을 각성한다."

### 2.2 도감 시스템 (Collection Book)

몬스터/장비/코스튬/펫/유물/무기를 수집하면 영구 패시브 보상을 제공하는 시스템. 현재 AchievementSystem과 별도로, **수집 자체가 보상인 체계**를 구축한다.

**핵심 설계:**
- 도감 카테고리: 몬스터(층별), 장비(등급별), 무기(등급별), 동료(등급별), 유물(전체), 펫(종류별), 코스튬(세트별)
- 수집 시 영구 패시브: 카테고리별 마일스톤 달성 → 스탯 보너스 (CombatStats modifier)
- 도감 완성도에 따른 칭호 시스템: "초보 수집가" → "탑의 박물관장"
- 도감 열람 시 3D 모델/일러스트 + 설명 텍스트 (세계관 확장)
- **기존 시스템 연동**: EventBus 구독 (MonsterDiedEvent, EquipmentObtainedEvent 등)으로 자동 등록

**리텐션 효과:** 유저가 "빈 칸 채우기" 욕구로 장기 플레이. 도감 보상이 전투력에 직접 기여하므로 무시할 수 없는 콘텐츠.

### 2.3 소셜 기능 (친구/선물/방문)

방치형 RPG에서 소셜은 리텐션의 핵심 동력이다. 길드는 이미 있지만, 1:1 소셜 기능이 없다.

**핵심 설계:**
- 친구 추가: UID 검색 또는 추천 목록 (비슷한 층수/전투력)
- 친구 선물: 하루 5명에게 하트(50골드 상당) 보내기/받기
- 친구 방문: 친구의 "탑 기지"에 방문하여 인테리어 확인 + 방문 보상 (1일 1회, 친구당)
- 친구 랭킹: 친구 간 층수/전투력 경쟁 (자극 유발)
- **인프라 의존**: 서버 통신 필요 (현재 로컬 세이브 기반이므로 서버 인프라 선행 필요)

**수익 잠재력:** 선물 아이템 확장 (프리미엄 선물 = 루비 소비), 방문 시 특별 상점 노출.

### 2.4 코스튬 합성 시스템

현재 코스튬은 획득 후 장착만 가능하다. **하위 등급 코스튬을 합성하여 상위 등급으로 승급**하는 루트를 추가하면, 중복 코스튬에 가치를 부여하고 성장 축을 하나 더 만들 수 있다.

**핵심 설계:**
- 합성 공식: 같은 부위 일반 3개 → 희귀 1개, 희귀 3개 → 전설 1개
- 랜덤 결과: 합성 결과물은 해당 등급 중 랜덤 (위시리스트 1개 확률 상승 가능)
- 합성 재료: 코스튬 + 골드 + "코스튬 실"(신규 재화, 챕터 사냥 드롭)
- 분해: 불필요한 코스튬 분해 → 코스튬 실 획득
- **기존 시스템 연동**: CostumeManager 확장, CurrencyType에 코스튬 실 추가

### 2.5 길드 실전투 (길드 보스 + 토벌전 전투 로직)

현재 GuildManager, GuildBossSystem, GuildResearchSystem 등 매니저는 구현되었지만, **실제 전투 로직은 데이터 레이어만 존재**한다. 길드 보스에게 직접 데미지를 가하고, 토벌전에서 실시간 점수를 쌓는 전투 로직이 필요하다.

**핵심 설계:**
- 길드 보스: 기존 BossRaidSystem의 전투 루프를 재활용하되, 데미지가 길드 전체에 누적되는 구조
- 보스 패턴: 3페이즈 (HP 70%/40%에서 패턴 변경), 전용 스킬 5종
- 토벌전: 1시간 동안 특수 아레나에서 몬스터 처치, 길드별 총 처치 수 집계
- 보상 분배: 개인 기여도 비율 기반 + 길드 전체 클리어 보너스
- **인프라**: 실시간 동기화는 불필요 (각자 플레이 → 결과만 집계)

### 2.6 아레나 실전투 (AI 클론 PvP)

ArenaManager는 구현되었지만, **AI 클론 기반 비동기 PvP 실제 전투 로직**이 없다. 상대 캐릭터의 스냅샷을 로드하여 AI가 조종하는 전투를 구현해야 한다.

**핵심 설계:**
- 스냅샷 저장: 플레이어의 스탯/장비/스킬/동료 정보를 직렬화하여 "아레나 프로필"로 저장
- AI 클론 생성: 스냅샷 기반으로 적 PlayerCharacter를 생성, 자동 전투 AI 적용
- 전투 규칙: 60초 타임아웃, 1v1, 직업 상성 보정 적용
- 결과 처리: 승/패 → ELO 변동, 아레나 코인 지급, 전적 기록
- **기존 시스템 연동**: PlayerCharacter + CombatStats + ArenaManager 연동

### 2.7 월드 이벤트 (서버 전체 협동 보스)

서버 전체 유저가 하나의 거대 보스에게 누적 데미지를 가하는 이벤트. FOMO + 협동감 + 대규모 보상으로 리텐션 극대화.

**핵심 설계:**
- 주기: 격주 주말 (토~일 48시간)
- 보스 HP: 서버 활성 유저 수 x 5,000,000 (동적 스케일링)
- 개인 참여: 하루 3회 도전 가능, 회당 최대 180초
- 보상: 기여도 순위별 차등 (유물/각인/코스튬/소환권) + 서버 클리어 시 전원 보상
- 세계관: "탑의 최상층에서 봉인이 풀린 태고의 존재가 깨어났다"
- **인프라**: 서버 통신 필수 (HP 동기화, 순위 집계)

### 2.8 업적 확장 (신규 시스템 연동)

현재 AchievementSystem이 기본 업적만 다루고 있다. C8~C14 및 신규 시스템과 연동하는 **100개 이상의 신규 업적**을 추가한다.

**핵심 설계:**
- 카테고리별 업적 추가:
  - 시즌: "배틀패스 Lv.50 달성", "시즌 3회 참여"
  - PvP: "아레나 골드 등급 달성", "10연승"
  - 펫: "신화 등급 펫 보유", "펫 도감 100% 완성"
  - 길드: "길드 보스 1위 기여", "길드 연구 전체 완료"
  - 코스튬: "전설 코스튬 세트 완성", "코스튬 50종 수집"
  - 챌린지: "챌린지 별 100개", "무피격 챌린지 클리어"
  - 등반 조합: "4인 파티 완성", "혼합 조합 보너스 발동"
  - 프레스티지: "윤회 10회 달성"
- 업적 보상: 루비, 소환권, 코스튬 조각, 칭호
- **기존 시스템 연동**: EventBus 구독으로 자동 트래킹 (기존 패턴 유지)

### 2.9 펫 전투 참여

현재 펫은 자동 아이템 수집 + 패시브 버프만 제공한다. **펫이 전투에서 보조 공격을 수행**하도록 확장하면 펫의 존재감과 육성 동기가 크게 증가한다.

**핵심 설계:**
- 전투 참여 해금: 펫 영웅(Epic) 등급 이상
- 공격 방식: 3초마다 가장 가까운 적에게 자동 공격 (펫 타입별 상이)
  - 비행(구름이): 넓은 범위 바람 공격
  - 화염(불씨): 단일 대상 고데미지
  - 전기(번개): 3체인 연쇄 번개
  - 등등 타입별 고유 공격
- 데미지: 플레이어 공격력의 5~15% (등급별)
- 진화 시 공격 패턴 강화 (신화: 10초마다 궁극기 발동)
- **기존 시스템 연동**: PetManager + CombatSystem, 풀링으로 펫 투사체 관리

### 2.10 탑 비밀 방 (Hidden Room)

특정 조건을 충족하면 출현하는 히든 층. 발견의 즐거움 + 희귀 보상으로 탐험 동기를 부여한다.

**핵심 설계:**
- 발동 조건 (랜덤 선택, 층 진입 시 판정):
  - 챕터 보스 30초 내 클리어
  - 무피격으로 10층 연속 돌파
  - 특정 장비 세트 착용 상태
  - 프레스티지(윤회) 후 특정 층 도달
  - 특정 동료 조합 파티 편성
- 비밀 방 콘텐츠:
  - 유물 확정 드롭 (1~2개)
  - 희귀 코스튬 해금 기회
  - 특수 NPC (상인, 대장장이) → 한정 거래
  - 도감 전용 "비밀 방 몬스터" 등장
- 발견 알림: 화면 연출 + (향후) 길드 채팅 공유
- 비밀 방 도감: 발견한 비밀 방 목록 + 조건 힌트 (미발견 방은 "???" 표시)
- **기존 시스템 연동**: TowerManager + TowerGimmickSystem 확장, EventBus로 발견 이벤트 발행

## 3. 우선순위 매트릭스

### 평가 기준
- **리텐션 ★**: 유저 잔존율에 미치는 영향 (1~5)
- **수익 ★**: 직접/간접 매출 기여도 (1~5)
- **구현 난이도**: 하/중하/중/중상/상 (기존 시스템 활용도, 서버 의존도, 아트 리소스 필요도 고려)
- **종합 점수**: (리텐션 + 수익) / 난이도 가중치

| 순위 | 시스템 | 리텐션 | 수익 | 난이도 | 서버 필요 | 종합 |
|------|--------|--------|------|--------|-----------|------|
| **1** | **업적 확장** | ★★★☆☆ | ★★☆☆☆ | 하 | X | **A** |
| **2** | **도감 시스템** | ★★★★☆ | ★★☆☆☆ | 중하 | X | **A** |
| **3** | **코스튬 합성** | ★★★☆☆ | ★★★☆☆ | 하 | X | **A** |
| **4** | **4차 전직** | ★★★★☆ | ★★☆☆☆ | 중 | X | **A-** |
| **5** | **펫 전투 참여** | ★★★☆☆ | ★★★☆☆ | 중 | X | **B+** |
| **6** | **탑 비밀 방** | ★★★★☆ | ★★☆☆☆ | 중 | X | **B+** |
| **7** | **아레나 실전투** | ★★★★☆ | ★★★☆☆ | 중상 | △ | **B** |
| **8** | **길드 실전투** | ★★★★★ | ★★★☆☆ | 중상 | △ | **B** |
| **9** | **소셜 기능** | ★★★★★ | ★★★☆☆ | 상 | O | **C+** |
| **10** | **월드 이벤트** | ★★★★☆ | ★★★★☆ | 상 | O | **C** |

> **종합 등급 기준**: A = 즉시 착수 가능 + 효과 높음, B = 효과 높지만 구현 비용 있음, C = 서버 인프라 선행 필요

### 핵심 판단 근거

1. **서버 불필요 시스템 우선**: mkLike는 현재 로컬 세이브 기반. 서버 인프라 없이 구현 가능한 시스템을 먼저 완성한다.
2. **기존 매니저 활용**: C8~C11 매니저가 이미 있으므로, 이를 확장하는 작업(아레나 실전투, 길드 실전투)은 바닥부터 만드는 것보다 효율적.
3. **업적/도감은 ROI 최고**: 기존 EventBus 인프라만으로 구현 가능하고, 모든 신규 시스템의 리텐션을 증폭시키는 메타 시스템.
4. **소셜/월드이벤트는 서버 의존**: 서버 인프라 구축 일정에 맞춰 후반 라운드에 배치.

## 4. 추천 구현 순서 (라운드별)

### 라운드 0: 기존 대기 태스크 소화 (선행 필수)
> C12(코스튬 5건), C13(챌린지 8건), C14(등반 조합 9건) = 총 22건

이 22건을 먼저 완료해야 신규 시스템과의 연동이 가능하다.

```
[라운드 0] — 기존 대기 태스크 소화
  ├── C12: 코스튬 나머지 5건 (CC-05~CC-10)
  ├── C13: 챌린지 나머지 8건 (CH-04~CH-12)
  └── C14: 등반 조합 나머지 9건 (CP-03~CP-13)
  → 3그룹 병렬 진행 가능 (서로 독립)
```

```
[라운드 1-A] — 병렬 가능
  ├── 업적 확장 (100+ 신규 업적)

  ├── 4차 전직 (Lv.160, 마스터리 분기)
  └── 펫 전투 참여 (보조 공격 시스템)
```

### 라운드 2: 전투 콘텐츠 심화 (서버 △, 로컬 시뮬레이션 가능)

```
[라운드 2] — 병렬 가능
  ├── 아레나 실전투 (AI 클론 PvP 전투 로직)

```

### 라운드 3: 소셜 + 라이브옵스 (서버 인프라 필수)

```
[라운드 3] — 서버 구축 후
  ├── 소셜 기능 (친구/선물/방문)
```

## 7. 결론 및 권장 사항

1. **라운드 0을 먼저 소화**: 기존 22건 대기 태스크(코스튬/챌린지/등반 조합)를 완료해야 신규 시스템과의 연동이 깔끔하다.
2. **라운드 1은 서버 없이 가능**: 도감/업적/코스튬 합성/4차 전직/펫 전투는 모두 로컬에서 동작. 5그룹 병렬 에이전트로 동시 진행 가능.
3. **라운드 2는 "가짜 서버"로 시뮬레이션**: 아레나/길드 전투는 로컬에서 AI 시뮬레이션으로 구현하고, 서버 연동은 나중에 추가.
4. **라운드 3은 서버 인프라 결정 후**: 소셜/월드이벤트는 백엔드 선택(Firebase? PlayFab? 자체 서버?)에 따라 설계가 달라지므로 인프라 확정 후 착수.
5. **모든 신규 시스템은 EventBus 패턴 유지**: 기존 아키텍처와 일관성을 위해 시스템 간 통신은 EventBus<T>로 통일.
