# 온보딩 & 튜토리얼 시스템 기획서

> 작성일: 2026-03-15
> 목적: 신규 유저의 첫 경험(FTUE)을 설계하고, 시스템 학습을 자연스럽게 유도하는 튜토리얼 흐름 정의

---

## 1. 설계 원칙

| 원칙 | 설명 |
|------|------|
| **즉시 전투** | 설명 최소화, 30초 안에 첫 전투 시작 |
| **점진적 노출** | 한 번에 하나의 시스템만 소개, 정보 과부하 방지 |
| **보상 즉시 지급** | 튜토리얼 단계마다 눈에 보이는 보상으로 진행 동기 부여 |
| **강제 최소화** | 핵심 플로우만 강제, 나머지는 선택적 가이드 |
| **지연된 수익화** | 첫 30분(챕터 1~2 클리어)까지 과금 요소 노출 최소화 |
| **방치형 DNA** | "자동 전투가 기본"임을 처음부터 각인 |

## 2. 첫 실행 플로우 (0~5분)

### 2-1. 앱 시작 ~ 직업 선택 (0:00 ~ 0:30)

#### 플로우
```
[로고/스플래시] (2초)
    |
[인트로 컷신] (스킵 가능, 15초)
  "끝없는 탑... 그 꼭대기에 도달한 자에게 모든 것이 주어진다."
  "당신은 신입 헌터. 탑의 1층에서 여정이 시작된다."
    |
[직업 선택 화면]
```

#### 직업 선택 UI
```
+-----------------------------------------------+
|          ===  직업을 선택하세요  ===             |
|                                                |
|  [전사 캐릭터]  [궁수 캐릭터]  [마법사 캐릭터]   |
|   근접 광역      원거리 연사     범위 마법       |
|   안정적 생존    높은 화력       강력한 CC       |
|                                                |
|  ────────── 직업 상세 ──────────                |
|  "나이트 > 워로드 > 타이탄으로 전직하여          |
|   최강의 근접 전사가 됩니다."                    |
|                                                |
|           [ 선택 완료 ]                         |
+-----------------------------------------------+
```

- 캐릭터 3D/2D 프리뷰: SPUM 캐릭터가 Idle 애니메이션 재생
- 직업 탭 터치 시 전직 경로 + 한줄 설명 표시
- 직업 선택 후 확인 팝업: "한번 선택하면 변경할 수 없습니다" (추후 직업 변경권 판매 가능)

#### 타이밍
| 단계 | 소요 시간 | 강제 여부 |
|------|-----------|-----------|
| 스플래시 | 2초 | 강제 |
| 인트로 컷신 | 0~15초 (스킵 가능) | 선택 |
| 직업 선택 | 10~30초 | 강제 |

### 2-2. 첫 전투 (0:30 ~ 2:00)

#### 목표
- "자동 전투"의 핵심 루프를 30초 안에 체험
- 조작 없이도 캐릭터가 알아서 싸우는 것을 확인

#### 플로우
```
[아레나 진입 - 스테이지 1-1]
    |
[가이드 대사] "캐릭터가 자동으로 전투합니다. 지켜보세요!"
    |
[약한 몬스터 3마리 스폰] (일반 웨이브보다 적은 수)
  → 캐릭터가 자동으로 접근 + 공격
  → 몬스터 처치 시 골드/EXP 드롭 이펙트 강조
    |
[가이드 대사] "몬스터를 처치하면 골드와 경험치를 얻습니다!"
    |
[처치 수 10마리 도달]
    |
[가이드 대사] "좋습니다! 계속 사냥하면서 강해지세요."
  → 일반 웨이브 패턴으로 전환 (5마리씩, 3초 간격)
    |
[처치 수 30마리 도달 → 첫 레벨업 발생]
```

#### 특수 규칙 (튜토리얼 1-1)
- 몬스터 HP/공격력 50% 감소 (쉬운 체험)
- 스폰 간격 2배 느림 (3초 → 6초)
- 첫 3마리는 플레이어 정면에서만 스폰 (혼란 방지)
- 10마리 이후 360도 스폰으로 전환
- 미니보스 출현 조건: 30마리 (일반 100마리 대신)

### 2-3. 첫 레벨업 + 스탯 분배 (2:00 ~ 3:00)

#### 트리거
- 처치 수 30마리 도달 시 Lv.2 달성 (튜토리얼용 경험치 테이블)

#### 플로우
```
[레벨업 이펙트 + 팡파레]
    |
[전투 일시 정지] (튜토리얼 전용)
    |
[가이드 대사] "레벨업! 능력치 포인트 5개를 획득했습니다."
    |
[캐릭터 탭 자동 열림 → 스탯 분배 서브탭]
    |
[하이라이트 마스크: 공격력 + 버튼만 활성화]
  → "공격력에 포인트를 투자해보세요!" (강제 1회)
    |
[공격력 +1 투자]
    |
[가이드 대사] "나머지 포인트는 자유롭게 분배하세요."
  → 나머지 4포인트 자유 분배 (또는 나중에)
    |
[닫기 → 전투 재개]
```

#### 보상
- 레벨업 기본 보상: 능력치 포인트 5개
- 튜토리얼 추가 보상: 골드 500

### 2-4. 첫 미니보스 + 스테이지 클리어 (3:00 ~ 4:00)

#### 플로우
```
[처치 수 30마리 → 미니보스 등장] (튜토리얼용 약화된 미니보스)
    |
[가이드 대사] "강력한 몬스터가 나타났습니다! 처치하면 다음 스테이지로!"
    |
[미니보스 HP 바 표시 (화면 상단)]
    |
[미니보스 처치]
    |

    |
```

#### 특수 규칙 (튜토리얼 미니보스)

- 타임아웃 없음 (튜토리얼 중에는 미니보스가 퇴장하지 않음)

### 2-5. 첫 장비 획득 (4:00 ~ 5:00)

#### 트리거
- 1-2 스테이지 진입 직후 (또는 1-1 미니보스 처치 보상)

#### 플로우
```
[1-2 진입 즉시]
    |
[가이드 대사] "헌터 지원 물자가 도착했습니다!"
    |
[장비 획득 팝업]
  "노말 투구" + "노말 상의" + "노말 무기" 3종 지급
    |
[캐릭터 탭 자동 열림 → 장비 서브탭]
    |
[하이라이트 마스크: 무기 슬롯]
  → "무기를 장착해보세요!" (강제 1회)
    |
[무기 장착 → CP 상승 연출]
    |
[가이드 대사] "전투력(CP)이 올라갑니다! 나머지 장비도 장착하세요."
  → 나머지 장비 자유 장착
    |
[닫기 → 전투 재개]
```

#### 보상
- 노말 투구 (Lv.1)
- 노말 상의 (Lv.1)
- 노말 무기 (직업에 맞는 기본 무기)

## 3. 단계별 가이드 (5~30분)

### 3-1. 스킬 해금 가이드 (Lv.10 도달, 약 8분)

#### 트리거
- 레벨 10 달성 시 Active 스킬 습득 (이미 Lv.1에서 해금됨)
- 실제 트리거: Lv.10에서 첫 Passive 스킬 해금

#### 플로우
```
[Lv.10 달성]
    |
[스킬 해금 알림] "새로운 스킬을 습득했습니다! — [단련/명사수의 눈/마력 집중]"
    |
[캐릭터 탭 자동 열림 → 스킬 서브탭]
    |
[하이라이트 마스크: Passive 슬롯(1번)]
  → "패시브 스킬은 자동으로 적용됩니다. 레벨을 올려보세요!"
    |
[스킬 레벨업 1회 (자동 소비 or 무료)]
    |
[가이드 대사] "스킬 레벨이 올라가면 효과가 강해집니다."
    |
[HUD 스킬 슬롯 하이라이트]
  → "여기서 스킬 상태를 확인할 수 있습니다."
    |
[닫기]
```

### 3-2. 강화 시스템 소개 (1-5 클리어, 약 12분)

#### 전제
- 1-5 클리어 시점까지 장비 3~5개 보유
- 룬 조각 소량 지급 (튜토리얼 보상)

#### 플로우
```
[1-5 클리어 보상에 룬 조각 x20 포함]
    |
[가이드 대사] "장비를 강화하면 더 강해집니다!"
    |
[캐릭터 탭 → 장비 서브탭 → 강화 탭]
    |
[하이라이트: 주문서 강화 버튼]
  → "주문서 강화를 시도해보세요! (룬 조각 소비)"
    |
[강화 1회 실행 (튜토리얼 중에는 100% 성공)]
    |
[CP 상승 연출]
    |
[가이드 대사] "주문서 강화는 최대 10회! 5번째, 10번째에는 성공 확률이 올라갑니다."
    |
[가이드 대사] "더 강해지면 성급 강화도 할 수 있습니다."
  → 성급 강화 버튼 잠깐 하이라이트 (자세한 안내는 나중에)
```

## 9. 엣지 케이스

| 상황 | 처리 |
|------|------|
| 튜토리얼 중 앱 종료 | completedStep까지 저장, 재시작 시 다음 단계부터 |
| 튜토리얼 중 사망 | 튜토리얼 1-1에서는 사망 불가 (HP 1 이하로 안 내려감) |
| 레벨업이 예상보다 빠름 | 트리거 조건에 AND 사용 (레벨 + 이전 단계 완료) |
| 레벨업이 예상보다 느림 | 튜토리얼용 경험치 보정 (1-1~1-3 EXP x2) |
| 장비 인벤토리 가득 참 | 튜토리얼 장비는 별도 지급 (인벤토리 확인 안 함) |
| 이미 직업 선택한 계정으로 재접속 | completedStep 체크하여 스킵 |
| 선택적 가이드를 모두 스킵 | 시스템은 정상 해금, 가이드만 스킵됨 |
