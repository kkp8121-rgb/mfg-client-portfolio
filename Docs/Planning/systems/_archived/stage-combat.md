# 스테이지 전투 시스템 기획서

> Phase 2 핵심 시스템 - 인게임 자동 전투 루프

## 개요
- **목적**: 자동 전투로 몬스터를 사냥하고, 성장하여 다음 스테이지를 돌파하는 핵심 루프
- **핵심 경험**: "계속 강해져서 막혔던 곳을 뚫는 쾌감" + "몰려오는 몬스터를 쓸어버리는 쾌감"
- **레퍼런스**: 메이플 키우기 (육성 루프), 뱀서라이크 (전투 방식)
- **주의**: 로그라이크/랜덤 스킬 선택 없음. 전투 방식만 차용한 방치형 게임.

## 챕터-스테이지 구조

### 계층
```
챕터 (Chapter)
  └ 스테이지 1-1
  └ 스테이지 1-2
  └ ...
  └ 스테이지 1-9
  └ 보스 스테이지 1-BOSS
```

### 규칙
- 챕터당 9개 일반 스테이지 + 1개 보스 스테이지 (총 10개)
- 각 챕터는 고유 테마/배경을 가짐 (숲, 동굴, 화산, 하늘 등)
- 챕터가 올라갈수록 몬스터 레벨/스탯 상승

### 스테이지 진행 플로우
```
[스테이지 진입]
     |
     v
[몬스터 웨이브 시작 (아레나 가장자리에서 스폰, 플레이어 방향으로 접근)]
     |
     v
[자동 사냥] <------------------------------------+
     |                                            |
     v                                            |
[100마리 처치?] --NO--> [계속 스폰 (웨이브)] -----+
     |
     YES
     v
[미니보스 자동 등장 (아레나 중앙)]
     |
     v
[미니보스 처치?] --NO--> [무한 파밍 모드 (강해질 때까지)] ---> [미니보스 재등장: 다시 100마리]
     |
     YES
     v
[다음 스테이지로 자동 이동]
     |
     v
(X-BOSS 스테이지인 경우)
[챕터 보스 등장]
     |
     v
[챕터 보스 처치?] --NO--> [무한 파밍]
     |
     YES
     v
[다음 챕터 해금]
```

### 무한 파밍 모드
- 미니보스를 못 잡으면 같은 스테이지에서 몬스터가 무한 스폰
- 계속 사냥하여 재화/경험치 축적 → 성장
- 미니보스 재등장 조건: 다시 100마리 처치
- 플레이어가 충분히 강해지면 미니보스를 돌파하고 진행

## 맵 구조

### 탑다운 아레나
```
+--------------------------------------------------+
|                                                    |
|  MOB →         ← MOB            MOB →             |
|         ↘                  ↙                       |
|              [플레이어]                             |
|         ↗                  ↖                       |
|  MOB →         ← MOB            MOB →             |
|                                                    |
+--------------------------------------------------+
         (아레나 경계 = 보이지 않는 벽)
```

### 아레나 규칙
- **단일 평면**: 점프/플랫폼 없음, 2D 탑다운 자유 이동
- **아레나 크기**: 화면보다 약간 큰 직사각형 영역
- **경계**: 보이지 않는 벽 (플레이어/몬스터 이탈 방지)
- **맵 크기**: 챕터/스테이지마다 다를 수 있음 (ScriptableObject로 정의)
- **배경**: 층수별 테마 타일/스프라이트 (숲, 동굴, 화산, 하늘 등)

### 카메라
- 플레이어 추적 (탑다운, 부드러운 따라가기)
- 아레나 경계 클램핑
- 줌 레벨은 고정 (다수 몬스터 가시성 확보)

## 몬스터 스폰

### 스폰 방식 (뱀서라이크 스타일)
- **스폰 위치**: 아레나 가장자리 (화면 밖) 360도 방향에서 랜덤
- **스폰 패턴**: 웨이브 기반, 일정 간격으로 몬스터 그룹 스폰
- **이동 방식**: 스폰 후 플레이어를 향해 지속 접근 (추적 AI)
- **동시 활성 몬스터**: 최대 30~50마리 (성능 제한, 풀링)

### 웨이브 구성
- **일반 웨이브**: 3~5초 간격으로 5~10마리씩 스폰
- **밀집 웨이브**: 특정 방향에서 대량 스폰 (긴장감)
- **포위 웨이브**: 모든 방향에서 동시 스폰
- 웨이브 패턴은 StageDataSO로 정의

### 미니보스
- 100마리 처치 시 자동 등장
- 일반 몬스터보다 크고, HP/공격력 높음
- 등장 위치: 아레나 가장자리에서 등장 → 플레이어 접근
- 처치 실패 판정: 30초 내 HP 0 안 되면 퇴장 → 파밍 재개

### 챕터 보스 (X-BOSS)
- 스테이지 자체가 보스전
- 보스 1마리 + 하수인 소환 패턴
- 타임어택 또는 생존 기반
- 패턴 기반 (Phase 6에서 상세 구현)

## 플레이어 자동 전투 AI

### 이동 AI (탑다운)
- **8방향 자유 이동**: transform.position 기반 (키네마틱)
- **기본 행동**: 가장 가까운 몬스터를 향해 이동
- **회피 로직**: HP가 낮을 때 몬스터 밀집 지역 회피 (선택적)
- **이동 속도**: CombatStats.MoveSpeed 기반

### 행동 우선순위
1. **가까운 몬스터 탐색** (감지 범위 내, OverlapCircleAll)
2. **이동** → 가장 가까운 몬스터 방향으로 접근
3. **공격 사거리 도달** → 공격 (자동)
4. **스킬 쿨다운 완료** → 스킬 자동 시전
5. **몬스터 없음** → 아레나 중앙 근처에서 대기

### 공격 방식 (탑다운)
- **전사**: 근거리 원형 범위 공격 (주변 N마리)
- **궁수**: 가장 가까운 적 방향 투사체 발사 (관통 가능)
- **마법사**: 원형/부채꼴 범위 마법 (다수 적 동시 타격)
- 공격 방향: 가장 가까운 적 방향으로 자동 조준

## 데이터 구조

### StageDataSO (ScriptableObject)
```
- chapterId: int
- stageIndex: int (1~9, 10=BOSS)
- displayName: string ("1-3", "2-BOSS")
- monsterCount: int (기본 100)
- monsterDataList: MonsterDataSO[] (이 스테이지에 등장하는 몬스터 종류)
- miniBossData: MonsterDataSO (미니보스)
- chapterBossData: MonsterDataSO (챕터 보스, BOSS 스테이지만)
- arenaSize: Vector2 (아레나 크기)
- spawnInterval: float (스폰 간격)
- spawnBatchSize: int (한 번에 스폰하는 수)
- backgroundTheme: string (배경 테마)
```

### ArenaDataSO (ScriptableObject) — PlatformLayoutSO 대체
```
- arenaWidth: float
- arenaHeight: float
- playerSpawnPoint: Vector2 (보통 중앙)
- bossSpawnPoint: Vector2
- obstacles: ObstacleData[] (선택적: 아레나 내 장애물)
```

| 항목 | 값 | 비고 |
|------|-----|------|
| 스테이지당 몬스터 수 | 100 | 챕터별 조정 가능 |
| 동시 활성 몬스터 | 30~50 | 성능 제한 (풀링) |
| 스폰 간격 | 3~5초 | 웨이브당 |
| 스폰 배치 크기 | 5~10마리 | 웨이브당 |
| 미니보스 타임아웃 | 30초 | 시간 내 처치 실패 → 퇴장 |
| 챕터당 스테이지 수 | 10 (9 + BOSS) | |
| 미니보스 HP 배율 | x10 (일반 대비) | |
| 챕터 보스 HP 배율 | x50 (일반 대비) | |

## 엣지 케이스
- 미니보스 등장 중 플레이어 사망: 미니보스 퇴장 → 파밍 모드 재개
- 오프라인 중 스테이지 진행: 오프라인 보상은 현재 스테이지 기준 재화만 (자동 돌파 X)
- 챕터 보스 실패: 보스 스테이지에서 무한 파밍 (잡몹 스폰), 재도전
- 대량 몬스터 겹침: 몬스터 간 밀어내기(separation) 로직으로 겹침 방지
