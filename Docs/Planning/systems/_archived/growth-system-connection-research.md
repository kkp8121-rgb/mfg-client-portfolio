# 성장 중심 시스템 연결 — 심층 리서치 보고서

> 작성일: 2026-03-17
> 목적: mkLike의 197개 시스템이 "성장"이라는 단일 목표로 어떻게 연결되어야 하는지 경쟁작 분석, 유저 심리, 실패 사례를 기반으로 제안한다.

---

## 1. 경쟁작 심층 분석

### 1.1 메이플 키우기 (Maple Idle / 메이플스토리 기반)

**출시/성과:** 2025년 11월 출시, 양대 마켓 매출 1위 달성. 다만 확률형 아이템 논란으로 2026년 1월 전액 환불 사태 발생.

**성장 루프:**
```
자동 사냥 → 골드/EXP → 레벨업 → 스탯 분배
    ↓
무기 소환(가챠) → 보유 효과 + 장착 효과 → CP 상승
    ↓
주문서 강화(10회 슬롯) → 5번째/10번째 확률 보너스
    ↓
큐브(잠재능력 재설정) → 공격력/주스탯/크리 옵션
    ↓
용사의 힘(어빌리티) + 유물(영구 패시브) → 장기 성장
```

**가챠 직후 유저 행동 3단계:**
1. 획득 무기의 보유 효과 확인 (컬렉션 보너스)
2. 현재 무기와 비교 → 더 좋으면 즉시 장착
3. 주문서 강화 진행 (장착한 무기에 투자)

**"강해졌다" 체감 방법:**
- 무기 레벨에 따라 보유 효과 + 장착 효과가 동시에 증가
- 스테이지 클리어 속도가 눈에 띄게 빨라짐
- 전투력 수치가 단일 숫자로 표시되어 상승 명확

**일일 사이클:** 자동 사냥 보상 수령 → 던전(재화별 분리) → 강화 → 소환 → 탑 도전

**벽과 해결:** 15지역 이후 전투력 컷이 급상승. 좋은 유물이 있으면 낮은 전투력으로도 돌파 가능 → 유물 가챠 유도(과금 포인트). 주문서 강화의 확률 시스템이 과금 유도의 핵심이었으나, 이것이 결국 환불 사태를 초래.

**mkLike 교훈:**
- 무기의 "보유 효과"는 가챠 중복을 가치 있게 만드는 핵심 장치 → mkLike 동료/무기 도감 보너스와 동일 원리
- 확률형 강화의 함정 주의: 과도한 확률 의존은 유저 이탈/법적 리스크
- 5번째/10번째 보너스 확률은 좋은 UX — "아깝다, 한 번 더" 심리 유도

### 1.2 쿠키런 킹덤

**성장 루프:**
```
필드 탐험 → 크리스탈 수급 → 쿠키/보물 가챠
    ↓
쿠키 레벨업 → 승급(대폭 능력치 상승) → 스킬 레벨업
    ↓
토핑(장비) 장착/강화 → 전투력 상승
    ↓
마법사탕(후기 시스템) + 초월(중첩 강화) → 엔드게임
```

**가챠 직후 유저 행동 3단계:**
1. 쿠키 등급/역할 확인 (티어표 참조)
2. 기존 팀과 조합 검토 (탱크/힐러/딜러 밸런스)
3. 토핑 세팅 → 즉시 스테이지 투입

**"강해졌다" 체감 방법:**
- 쿠키 승급 시 비주얼 변화 (별 이펙트, 테두리 색 변경)
- 팀 전투력 수치가 스테이지 입장 화면에서 적 전투력과 비교 표시
- 쿠키마다 고유 스킬 연출 → 새 쿠키 획득의 시각적 만족감

**벽과 해결:** 마법사탕/초월 시스템이 "성장 부담 과다"로 비판받음. 과금 유저도 피로를 느낄 정도의 재화 요구량 → mkLike에서 피해야 할 패턴.

**mkLike 교훈:**
- 초월/마법사탕처럼 "기존 시스템 위에 시스템을 얹는" 방식은 신규 유저 진입 장벽을 높임
- 쿠키의 시각적 개성이 가챠 만족도를 크게 좌우 → mkLike 동료/코스튬 비주얼 중요
- 팀 조합의 중요성을 강조하는 것이 "단순 숫자 올리기"보다 재미있음

### 1.3 AFK Arena / AFK Journey

**AFK Arena의 성장 루프:**
```
방치 보상 수집 → 골드/EXP/장비
    ↓
영웅 레벨업 + 장비 장착 → 전투력 상승
    ↓
영웅 승천(Ascension): 동급 영웅 합성 → 등급 상승
    ↓
캠페인/탑/봉우리 3축 동시 진행 → 보상 루프
    ↓
VIP 시스템 → 방치 보상 증가(과금 포인트)
```

**AFK Journey의 혁신:**
- 장비가 캐릭터가 아닌 **클래스 아키타입에 귀속** (탱크/전사/마법사 등 6종)
- 같은 아키타입의 모든 캐릭터가 자동으로 같은 장비 사용
- 장비 관리 부담 대폭 감소 → 유저는 "어떤 캐릭터를 쓸까?"에만 집중

**가챠 직후 유저 행동 3단계:**
1. 영웅 등급/진영 확인 (승천 재료로서의 가치 판단)
2. 현재 보유 영웅과 합성 가능 여부 확인 (중복 = 승천 재료)
3. 파티 편성 → 막힌 스테이지 재도전

**"강해졌다" 체감 방법:**
- 승천(Ascension) 시 영웅 초상화 테두리가 바뀜 (은 → 금 → 빛남)
- **전투력 수치가 스테이지 입장 전에 적과 비교** → "이길 수 있겠다" 판단 가능
- 막힌 스테이지를 돌파하는 순간이 최고의 체감 포인트
- VIP 등급에 따라 방치 보상 배율 증가 → "돈을 쓰면 더 빨리 성장"

**일일 사이클:**
- AFK 보상 수집 → 속성 던전 → 캠페인/탑 도전 → 아레나 → 길드
- "빠른 보상" 버튼으로 즉시 보상 수령 (VIP 높을수록 횟수 증가)
- 전체 일일 루틴: 약 15~20분

**벽과 해결:** 캠페인 특정 스테이지에서 벽에 부딪힘 → 다른 콘텐츠(탑, 봉우리)로 우회 가능 → "메인이 막혀도 할 게 있다" → 단, 결국 승천을 위해 가챠 필요(과금 유도)

**mkLike 교훈:**
- **3축 동시 진행**(캠페인/탑/봉우리)은 "벽에 부딪혀도 할 게 있다"의 핵심 → mkLike도 스테이지/탑/챌린지 3축 구조 필요
- 중복 가챠의 가치 부여(승천 재료)가 가챠 만족도를 높임 → mkLike 동료 합성/도감과 동일 원리
- VIP/방치 보상 배율은 "과금해도 기분 좋은" 구조 — 직접적 능력치가 아닌 "시간 단축"

### 1.4 Idle Heroes

**성장 루프:**
```
방치 보상 → 골드/EXP/영웅 조각
    ↓
영웅 합성: 낮은 등급 영웅 → 높은 등급으로 합체 (최대 10성)
    ↓
장비 장착 (대장간에서 합성) → 스탯 상승
    ↓
주점(Tavern) 임무 → 보조 보상 수집
    ↓
캠페인/탑/아레나/길드 보스 → 재화 → 합성 루프
```

**$100M/년 달성 비결 (Deconstructor of Fun 분석):**
- 핵심 루프가 "영웅 수집 → 합성 → 승급"으로 극도로 명확
- 메타시스템(주점, 일일 퀘스트, 이벤트)이 모두 핵심 루프를 지원
- 일일 퀘스트 11개 전부 완료 시 보너스 보상 → 루틴 완주 동기
- 영웅 합성에 "쓸모없는 영웅"이 없음 → 모든 가챠 결과가 재료로 가치 있음

**가챠 직후 유저 행동 3단계:**
1. 영웅의 합성 경로 확인 (어떤 10성 영웅으로 가는 재료인가)
2. Creation Circle(합성소)에서 합성 가능 여부 확인
3. 합성 실행 → 즉시 전투 투입 → 막힌 스테이지 재도전

**벽과 해결:** 특정 영웅(E5 이상)이 없으면 PvP 불가능 → 이벤트 기간에 집중 투자 유도. "월간 이벤트 히어로"가 가장 강력한 과금 유도.

**mkLike 교훈:**
- **"쓸모없는 가챠 결과가 없다"**는 최고의 가챠 설계 원칙
- 11개 일일 퀘스트 + 전부 완료 보너스 = 일일 체류 시간 보장 (이미 user-cycle.md에 반영됨)
- 합성 시스템이 "중복 = 쓰레기"를 "중복 = 진화 재료"로 바꿈

## 2. 유저 심리 분석

### 2.1 방치형 RPG 유저 이탈 이유 TOP 5

| 순위 | 이유 | 비율/근거 | mkLike 대응 |
|------|------|-----------|-------------|
| 1 | **지루함 / 콘텐츠 피로** | 미국 유저 37%가 "bored"로 이탈 (Playio 2026) | 3축 동시 진행, 주간/월간 이벤트 순환 |
| 2 | **성장 벽 (Progress Wall)** | RPG 장르 특성상 특정 구간에서 성장 정체 | 벽 감지 → 우회 콘텐츠 추천 (탑→아레나→챌린지) |
| 3 | **보상 번아웃 (Reward Burnout)** | "아무리 해도 같은 보상" 느낌 | 보상 다양화 + 마일스톤 보상 (누적 보상 체계) |
| 4 | **선택 과부하 (Choice Overload)** | 시스템이 많아서 "뭘 해야 할지 모르겠다" | 가이드 퀘스트 + 추천 시스템 (UX-01~28) |
| 5 | **시스템 간 단절감** | 가챠해도 강해진 느낌 없음, 강화해도 전투 변화 없음 | **이번 리서치의 핵심 해결 과제** |

### 2.2 "성장 체감"이 없으면 벌어지는 일

학술 연구(arxiv: "Playing to Pay", 2025)와 업계 분석을 종합하면:

1. **행동-보상 연결 소멸**: 유저가 "이 행동의 결과가 뭐지?"를 인지하지 못하면, 해당 시스템 사용을 중단한다.
2. **가챠 무력감**: 10연차를 돌려도 전투에서 차이를 못 느끼면, 다음 가챠 동기가 사라진다. 이것이 가장 치명적인 이탈 패턴.
3. **숫자 마비 (Number Numbness)**: CP가 올라가도 전투에서 체감이 없으면, CP 자체가 의미 없는 숫자로 인식된다.
4. **시스템 회피**: "장비 강화해봤자 달라지는 게 없다" → 해당 탭을 아예 열지 않음 → 일일 퀘스트 미완료 → 이탈 가속

### 2.3 가챠 심리학: 왜 뽑고, 뽑은 후 뭘 기대하는가

가챠 메커니즘은 일본의 캡슐 토이(가챠폰)에서 유래하며, 다음 심리적 트리거를 활용한다:

| 트리거 | 설명 | mkLike 적용 |
|--------|------|-------------|
| **변동 비율 강화 (Variable Ratio Reinforcement)** | 슬롯머신 원리 — 언제 터질지 모르는 기대감 | 천장 시스템으로 "반드시 터진다" 보장 추가 |
| **수집 욕구 (Collection Drive)** | 도감/세트를 채우고 싶은 본능 | 도감 시스템 + 세트 효과 보너스 |
| **소유 효과 (Endowment Effect)** | 뽑은 캐릭터에 애착이 생김 | 동료 육성 + 외형 커스터마이즈 |
| **사회적 비교 (Social Comparison)** | 다른 유저보다 좋은 것을 갖고 싶음 | 아레나 랭킹 + 길드 내 파워 비교 |
| **매몰 비용 오류 (Sunk Cost Fallacy)** | 이미 투자했으니 계속해야 한다는 심리 | — (윤리적으로 과도한 악용은 지양) |

**가챠 직후 유저 기대 3가지:**
1. "뽑은 게 현재보다 강한가?" → **즉시 비교 필요**
2. "이걸 쓰면 어디가 바뀌는가?" → **장착/편성 프리뷰 필요**
3. "다음 천장까지 얼마나 남았는가?" → **진행도 표시 필요**

### 2.4 파워 판타지 (Power Fantasy)

**정의:** 게임 내에서 유저가 평소 불가능한 수준의 힘과 능력을 체험하는 것. "나는 이 세계에서 강하다"는 감각.

**파워 판타지를 만드는 5가지 요소:**

| 요소 | 설명 | 방치형 RPG 적용 |
|------|------|----------------|
| **숫자의 비약적 증가** | 처음 10 데미지 → 나중에 100,000 데미지 | 데미지 텍스트 크기/색 차등, K/M 단위 표기 |
| **시각적 임팩트 증가** | 약한 스킬 = 작은 이펙트, 강한 스킬 = 화면 가득 이펙트 | VFX 등급화 (노말→에픽→전설), 스킬 연출 강화 |
| **적의 반응 변화** | 처음엔 적이 안 죽음 → 나중엔 한 방에 몰살 | 몬스터 즉사 연출, "원킬" 이펙트 |
| **콘텐츠 해금** | 강해져야 갈 수 있는 곳이 있음 | 탑 층수, 챕터, 챌린지 난이도 |
| **다른 유저와의 비교** | "내가 상위 10%에 있다" | 아레나 랭킹, 탑 랭킹, 시즌 보상 |

## 3. 실패 사례 분석

### 3.1 "시스템은 많지만 재미없는" 게임 패턴

구체적 실패 사례와 업계 분석을 종합한 공통 패턴:

#### Endless World Idle RPG (Steam, 서비스 종료)
- 개발사 Radiance Games가 사실상 해체
- 개발자 급여 미지급 → 업데이트 중단 → 유저 이탈
- **교훈:** 라이브 서비스 게임은 지속적 콘텐츠 투입이 필수

#### Ragnarok Libre (LINE Next, 2026년 2월 종료)
- 2025년 8월 출시, 6개월 만에 서비스 종료
- 유명 IP(라그나로크) + 방치형이었지만 실패
- **교훈:** IP만으로는 부족. 핵심 루프의 재미가 없으면 IP 효과도 3주 만에 소멸

#### 방치형 게임 공통 실패 패턴 (나무위키 + 시사저널e 분석)

| 실패 패턴 | 설명 | 빈도 |
|-----------|------|------|
| **시스템 파편화** | 10개+ 성장 시스템이 있지만 서로 연결되지 않음. 장비 강화해도 전투 변화 없음. | 매우 높음 |
| **성장 속도 급변** | 초반 3일은 쾌감, 이후 성장 속도가 급감하여 "벽"을 느낌. 무과금 유저 이탈. | 높음 |
| **단조로운 전투** | 자동 전투라서 처음엔 편하지만, 변화가 없으면 "보고 있을 이유가 없음". | 높음 |
| **과금 벽** | 무과금으로 즐길 수 있는 구간이 짧고, 과금 없이는 진행 불가능. | 중간 |
| **숙제 피로** | 일일 퀘스트가 30분 이상 소요되면 "숙제"로 느껴짐. | 중간 |

### 3.2 한국 시장 특수성

- 한국에서 방치형 게임이 특히 인기인 이유: "스낵 컬처" 확산 + 짧은 플레이 시간 선호
- 고전 IP(메이플, 라그나로크, 세븐나이츠)를 활용한 방치형이 쏟아지는 중
- **차별화 필수:** IP 없는 인디 방치형은 "핵심 루프의 재미"로 승부해야 함
- 메이플 키우기 환불 사태: 확률형 시스템에 대한 한국 유저의 민감도가 매우 높음

## 4. mkLike 제안: 197개 시스템의 "성장" 중심 연결

### 4.1 핵심 원칙: "모든 행동은 CP 상승으로 귀결된다"

현재 mkLike의 문제:
- 시스템 197개가 존재하지만, 유저가 "이걸 하면 왜 강해지는가?"를 즉시 인지하기 어려움
- 시스템 간 연결이 이벤트 기반으로 구현되어 있지만, **유저에게 보이지 않음**

**해결 원칙:**
```
모든 행동 → CP 변화 → 시각적 피드백 → 전투 체감
```

이 파이프라인이 끊기는 지점이 "성장 체감 부재"의 원인이다.

### 4.2 성장 파이프라인: 가챠 → 장착 → 강화 → 전투 체감

```
[1단계: 획득]
가챠/드롭/퀘스트 보상
    │
    ▼
[2단계: 비교]  ← 현재 가장 약한 부분
"이게 지금보다 좋은가?" 즉시 비교 팝업
CP 프리뷰: "장착하면 CP 680 → 820 (+20.6%)"
    │
    ▼
[3단계: 적용]
원클릭 장착/편성/레벨업
    │
    ▼
[4단계: 확인]
CP 카운트업 애니메이션 + "장비 장착으로 CP +140!" 플로팅 텍스트
    │
    ▼
[5단계: 체감]  ← 가장 중요
다음 전투에서 데미지 증가/처치 속도 향상을 눈으로 확인
몬스터 원킬 연출, 보스 처치 시간 단축
    │
    ▼
[6단계: 욕구]
"더 강해지고 싶다" → 다음 가챠/강화/던전 동기
```

**현재 mkLike에서 끊기는 지점:** 2단계(비교)와 5단계(전투 체감)

### 4.3 끊긴 파이프라인 수리 — 구체적 방안

#### A. 비교 단계 수리 (2단계)

이미 user-cycle.md의 UX-09~11(GachaCompareSystem), UX-16~18(StatCompareView)에 기획되어 있다. 추가 제안:

| 시스템 | 비교 시점 | 필요한 데이터 | 표시 방법 |
|--------|-----------|--------------|-----------|
| 가챠 결과 | 10연차 직후 | 현재 장비/동료 vs 획득물 | "추천 장착" 팝업 + CP 프리뷰 |
| 장비 장착 | 장비 탭에서 아이템 탭 시 | 현재 장비 vs 선택 장비 | 좌우 비교 + 초록/빨강 화살표 |
| 동료 편성 | 파티 변경 시 | 현재 파티 CP vs 변경 후 CP | 실시간 CP 프리뷰 |
| 스킬 레벨업 | 스킬 레벨업 버튼 옆 | 현재 데미지 vs 다음 레벨 데미지 | 인라인 "12 → 15 (+25%)" |
| 코스튬 | 코스튬 탭 시 | 현재 세트 효과 vs 장착 시 | 세트 진행도 + 효과 미리보기 |

#### B. 전투 체감 단계 수리 (5단계) — 가장 중요

**문제:** CP가 100 올라도 전투에서 차이를 모르겠다.

**해결 방안:**

1. **킬 속도 시각화**
   - HUD에 "초당 처치 수(KPS)" 또는 "최근 10초 처치 수" 표시
   - 강화 전후 KPS 비교: "이전: 3.2 KPS → 현재: 4.1 KPS (+28%)"
   - 이것이 CP보다 훨씬 직관적인 "강해졌다" 지표

2. **데미지 텍스트 등급화**
   - 낮은 데미지: 작은 흰색 텍스트
   - 보통 데미지: 중간 노란색 텍스트
   - 높은 데미지: 큰 주황색 텍스트 + 쉐이크
   - 크리티컬: 거대한 빨간색 텍스트 + 화면 흔들림 + "CRITICAL!" 배너
   - **원킬 (오버킬)**: 특수 이펙트 + "OVERKILL!" + 골드 보너스

3. **몬스터 반응 차등화**
   - CP가 몬스터 권장보다 높으면: 몬스터가 접근하다가 "겁먹는" 애니메이션
   - CP가 압도적이면: 원킬 + 몬스터 폭발 이펙트 (일반 사망과 다른 이펙트)
   - CP가 부족하면: 몬스터 피격 시 데미지가 적게 뜸 + "장비를 강화해보세요" 팁

4. **스테이지 클리어 속도 기록**
   - 각 스테이지의 클리어 시간을 기록
   - 강화 후 같은 스테이지 재방문 시: "이전: 45초 → 현재: 12초 (-73%!)"
   - 탑에서도 적용: 이전 최고 기록 vs 현재 기록 비교

### 4.4 시스템 연결 매트릭스: "왜 이걸 해야 하는가?"

모든 시스템이 "성장"이라는 목표로 연결되는 매트릭스:

```
시스템              │ 입력(이걸 하려면)         │ 출력(하면 이걸 얻음)        │ CP 기여
────────────────────┼──────────────────────────┼───────────────────────────┼────────
자동 전투           │ 없음 (방치)              │ 골드, EXP, 드롭           │ 간접
레벨업              │ EXP                      │ 스탯 포인트 → 능력치      │ 직접
장비 장착           │ 장비 획득                │ 공/방/HP 상승             │ 직접
장비 강화(주문서)   │ 룬 조각 + 골드           │ 장비 스탯 증가            │ 직접
장비 강화(성급)     │ 별의 결정                │ 장비 등급 상승            │ 직접
잠재능력            │ 잠재의 수정              │ 특수 옵션 (크리/보스뎀)   │ 직접
동료 가챠           │ 소환권/루비              │ 동료 획득 (도감+전투)     │ 직접
동료 편성           │ 동료 보유                │ 파티 버프 + 전투 지원     │ 직접
무기 가챠           │ 소환권/루비              │ 무기 획득 (도감+장착)     │ 직접
코스튬              │ 코스튬 실/가챠           │ 외형 변경 + 세트 효과     │ 간접~직접
스킬 레벨업         │ 골드 + 스킬 포인트       │ 스킬 데미지/효과 증가     │ 직접
전직                │ 레벨 도달                │ 스탯 대폭 증가 + 신규 스킬│ 대폭
등반자의 힘         │ 등반의 증표              │ 영구 능력치 상승          │ 직접
마스터리            │ 마스터리 포인트          │ 특화 효과                │ 직접
각인                │ 각인석                   │ 추가 패시브              │ 직접
도감                │ 수집 진행                │ 도감 보너스 (영구)        │ 간접
프레스티지          │ 탑 100층+               │ 영구 보너스 + 빠른 재성장│ 간접
펫                  │ 펫 획득/육성             │ 전투 보조 + 패시브        │ 직접
```

**핵심:** 유저가 "이 시스템을 왜 해야 하는가?"를 물었을 때, 답이 항상 "CP가 올라가니까 (= 더 강해지니까)"여야 한다.

### 4.5 "빨리 성장하고 싶은 심리" 자극 방법

| 방법 | 구체적 구현 | 심리적 원리 |
|------|-------------|-------------|
| **진행도 비교** | "상위 30% 유저보다 빠른 성장 중!" | 사회적 비교 |
| **다음 보상 미리보기** | "Lv.40 달성 시: 루비 500 + 1차 전직!" | 목표 가시화 |
| **시간 제한 이벤트** | "오늘만 가챠 2배!" | 희소성 + 손실 회피 |
| **연속 보상 체인** | "연속 출석 7일: 전설 장비!" | 매몰 비용 + 목표 근접 |
| **"거의 다 왔어" 표시** | 천장 게이지 48/50, 도감 진행 98% | 목표 경사 효과 (Goal Gradient) |
| **Before/After 드라마** | 강화 전후 CP 변화를 최대한 드라마틱하게 연출 | 대비 효과 |
| **킬 카운트 마일스톤** | "10,000마리 처치! 보상: 루비 500" | 누적 성취감 |
| **새 스킬 체험** | 전직 시 새 스킬이 처음 발동되면 슬로모션 + 특수 연출 | 신선함 |

### 4.6 과금 밸런스: "무과금도 성장, 과금하면 더 빠르게"

**원칙:** 과금이 "벽을 뚫는 열쇠"가 아니라 "성장 속도 가속기"여야 한다.

| 과금 요소 | 무과금 경로 | 과금 효과 | 체감 차이 |
|-----------|-------------|-----------|-----------|
| 가챠 | 일일 무료 1회 + 퀘스트 소환권 | 추가 10연차 구매 | 2~3주 vs 1주 (같은 결과) |
| 방치 보상 | 기본 8시간 상한 | 상한 24시간 + 배율 1.5x | 시간 단축 |
| 던전 열쇠 | 일일 5개 무료 | 추가 5개 구매 | 재화 수급 2배 |
| 배틀패스 | 무료 트랙 | 프리미엄 트랙 (추가 보상) | 보상 2배 |
| 광고 제거 | 광고 시청으로 2배 보상 | 광고 없이 항상 2배 | 편의성 |
| 월간 패스 | - | 30일 매일 루비 100 | 장기 재화 축적 |

**절대 하면 안 되는 것:**
- CP를 직접 판매하는 것 ("$10 = CP +1000")
- 무과금으로 돌파 불가능한 벽을 만드는 것
- 확률을 과금으로만 보정할 수 있게 하는 것 (메이플 키우기 실패 사례)

### 4.7 즉시 실행 가능한 우선순위 액션 플랜

이미 user-cycle.md에 UX-01~28이 기획되어 있다. 그 중 **성장 체감에 가장 큰 영향을 주는 순서**로 우선순위를 재정렬한다:

**Tier 1 (즉시 효과 — 유저 이탈 방지):**
1. **가챠 후 비교 팝업** (UX-09~11): 가챠의 가치를 즉시 인지
2. **CP 카운트업 애니메이션** (UX-13): 모든 성장의 시각적 피드백
3. **가이드 퀘스트 체인** (UX-01~05): "다음 뭐 하지?" 해결

**Tier 2 (일주일 내 — 일일 체류 시간 확보):**
4. **일일 체크리스트** (UX-06~08): 매일 할 일 명확화
5. **재화 부족 → 유도 팝업** (UX-19~20): 재화 순환 완성
6. **장비/동료 비교 뷰** (UX-16~18): 장착 결정 보조

**Tier 3 (2주 내 — 장기 체류):**
7. **추천 시스템** (UX-24~28): 신규 유저 오류 방지
8. **복귀 유저 가이드** (UX-21~23): 이탈 유저 복귀 유도

**Tier S (아직 기획에 없지만 추가 필요):**
9. **킬 속도(KPS) 시각화**: 전투 체감의 핵심 지표
10. **데미지 텍스트 등급화**: 시각적 파워 판타지
11. **원킬/오버킬 이펙트**: 성장 후 압도적 전투 체감
12. **스테이지 클리어 시간 기록/비교**: 성장의 객관적 증거

## 5. 결론: mkLike의 "성장 중심 연결" 핵심 공식

```
성공 공식 = (획득 → 비교 → 적용 → 확인 → 체감 → 욕구) × 반복

실패 공식 = 획득 → ??? → 다음 획득 (비교/체감 부재)
```

**mkLike의 197개 시스템은 이미 충분하다.** 문제는 시스템의 수가 아니라, 시스템 간의 "연결 가시성"이다.

유저가 매 순간 인지해야 하는 것:
1. "지금 뭘 하면 좋은가?" → 가이드 퀘스트 + 추천
2. "이걸 하면 뭐가 바뀌는가?" → Before/After 비교
3. "바뀐 게 느껴지는가?" → CP 연출 + 전투 체감
4. "다음엔 뭘 하면 더 강해지는가?" → 다음 목표 위젯

이 4가지가 끊기지 않는 한, 유저는 "성장하는 재미"를 느끼며 계속 플레이한다.
