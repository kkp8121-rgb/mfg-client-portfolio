# 장비 시스템 기획서 v2

> 메이플 키우기 #72~78 참조. **세로 뷰(9:16) 전환**.

---

## 개요

장비 = 사냥으로 드롭. 슬롯에 장착하면 전투력 상승.
더 좋은 장비로 교체 + 슬롯 강화(주문서/스타포스)로 영구 성장.

---

| 슬롯 | 이름 | 주요 스탯 |
|------|------|----------|
| 0 | 투구 | HP, 방어력 |
| 1 | 상의 | HP, 방어력 |
| 2 | 장갑 | 공격력, 명중 |

| 5 | 목걸이 | HP, 공격력 |

## 장비 획득 방법

1. **사냥 드롭** — 자동 전투 중 확률 드롭
2. **스테이지 도전 클리어** — 보상으로 장비 획득
3. **보스 클리어** — 고등급 장비 확률
4. ~~장비 뽑기~~ — 제거 (무기 뽑기와 분리, 장비는 드롭 중심)

---

## 자동 분해

- [관리 설정]에서 "Normal 자동 분해" 등 조건 설정
- 조건에 해당하는 드롭 장비가 자동으로 분해 → 강화 재료로 변환
- 인벤토리 정리 자동화

---

## 슬롯 강화 (기존 시스템 유지)

**핵심: 장비가 아닌 "슬롯"을 강화. 장비 교체해도 강화 유지.**

### 주문서 강화
- 10회 시도 가능
- 성공 확률 30% (5번째 +10%, 10번째 +20%)
- 성공 시 ATK +3 / 회
- 비용: 5,000 골드

### 스타포스
- 0~25성
- 성공 확률: 0~4성 95%, 5~9성 80%, 10~14성 60%, 15~19성 40%, 20+ 30%
- 스탯 증폭 (1성당 ATK*2%)
- 비용: 1,000 + 성급² × 500 골드

### 잠재능력 (단순화)
- 등급: None → Rare → Epic → Unique → Legendary
- 옵션 3줄 (ATK%, HP%, CritRate 등)
- 큐브로 재설정
- 보조잠재 제거 (단순화)

---

## 중복 장비 각성

- 같은 ID + 같은 등급 장비로 각성 (0~5성)
- 각성당 기본 스탯 +10%
- 각성 재료: 인벤토리에서 같은 장비 소모
