## 1. 탑 구조 확장 기획

### 1.1 전체 구조

```

│  무한 구간 (301F+)     — 랭킹 경쟁, 끝없는 도전    │
├───────────────────────────────────────────────────┤

### 1.2 일반 구간 (1F ~ 100F)

현재 구현된 챕터-스테이지 시스템과 동일.

| 항목 | 내용 |
|------|------|
| 구조 | 챕터 1~10, 챕터당 9일반 + 1보스 (총 100층) |
| 진행 방식 | 몬스터 100마리 처치 → 미니보스 → 돌파 → 다음 층 |
| 무한 파밍 | 미니보스 실패 시 같은 층에서 무한 리스폰 사냥 |

### 1.3 엘리트 구간 (101F ~ 200F)

일반 구간을 클리어한 유저에게 제공되는 고난도 콘텐츠.

| 항목 | 내용 |
|------|------|
| 해금 조건 | 100층 클리어 |
| 구조 | 101~200층, 10층 단위로 테마 변경 |
| 기본 진행 | 일반 구간과 동일 (100마리 → 미니보스 → 돌파) |
| 차별점 | **환경 기믹** 추가, **특수 몬스터** 등장, 몬스터 스탯 추가 보정 |

#### 엘리트 몬스터 스케일링
```
eliteHP  = (30 + (floor * 15)) * 1.5    // 일반 대비 HP 50% 증가
eliteATK = (3 + (floor * 2)) * 1.3      // 일반 대비 공격력 30% 증가
eliteDEF = (2 + Round(floor * 1.5)) * 1.2  // 일반 대비 방어력 20% 증가

### 1.4 심연 구간 (201F ~ 300F)

탑의 깊은 곳. 어둠의 힘이 침식한 구간.

| 항목 | 내용 |
|------|------|
| 해금 조건 | 200층 클리어 |
| 구조 | 201~300층, 10층 단위로 테마 변경 |
| 차별점 | **어둠 디버프** 상시 적용, **조건부 클리어** 도입, 몬스터 변이 |

#### 어둠 디버프 (심연 구간 상시 효과)

심연 구간에 진입하는 순간 "심연의 침식" 디버프가 적용된다.

| 디버프 | 효과 | 해제 조건 |
|--------|------|-----------|
| 심연의 침식 Lv.1 (201~230F) | 전 스탯 -5%, HP 자연 회복 불가 | 해제 불가 (구간 상시) |
| 심연의 침식 Lv.2 (231~260F) | 전 스탯 -10%, 피격 시 2% 확률로 "공포" (1초 행동 불가) | 해제 불가 |
| 심연의 침식 Lv.3 (261~300F) | 전 스탯 -15%, 피격 시 5% 확률로 "공포", 10초마다 HP 1% 감소 | 해제 불가 |

> 심연의 침식은 **각인 효과 "심연 저항"**으로 단계를 1 낮출 수 있다 (Lv.3 → Lv.2).

#### 심연 몬스터 스케일링
```
abyssHP  = (30 + (floor * 15)) * 2.0    // 일반 대비 HP 100% 증가
abyssATK = (3 + (floor * 2)) * 1.6      // 일반 대비 공격력 60% 증가
abyssDEF = (2 + Round(floor * 1.5)) * 1.4  // 일반 대비 방어력 40% 증가
```

#### 변이 몬스터 (심연 전용)

심연 구간의 몬스터는 기존 몬스터의 **변이형**으로 등장한다.

| 변이 유형 | 출현 확률 | 특성 |
|-----------|-----------|------|
| 그림자 변이 | 20% | 반투명, 물리 피해 30% 감소 (마법 피해 취약 +20%) |
| 광폭 변이 | 15% | 이동속도 50% 증가, HP 30% 감소, 공격력 40% 증가 |
| 흡혈 변이 | 10% | 공격 시 피해량의 15% HP 회복 |
| 부활 변이 | 8% | 사망 후 3초 뒤 HP 30%로 부활 (1회) |
| 심연의 사도 | 3% | 모든 변이 특성 보유, 스탯 5배, 처치 시 확정 각인 드롭 |

### 1.5 무한 구간 (301F+)

끝이 없는 도전. 랭킹 경쟁의 핵심.

| 항목 | 내용 |
|------|------|
| 해금 조건 | 300층 클리어 |
| 구조 | 301층부터 무한, 매 층마다 난이도 지수 스케일링 |
| 차별점 | **지수적 난이도 상승**, 환경 기믹 랜덤 조합, **랭킹 경쟁** |
| 리셋 | 없음 — 도달 층수 영구 기록 |

#### 무한 구간 스케일링
```
// 301층 이후 지수적 스케일링
infiniteHP  = abyssHP(300) * (1.03 ^ (floor - 300))
infiniteATK = abyssATK(300) * (1.025 ^ (floor - 300))
infiniteDEF = abyssDEF(300) * (1.02 ^ (floor - 300))

// 300층 기준값 (floor=300 대입)
// abyssHP(300)  = (30 + 4500) * 2.0 = 9,060
// abyssATK(300) = (3 + 600) * 1.6   = 964.8
// abyssDEF(300) = (2 + 450) * 1.4   = 632.8

// 예시: 350층 몬스터
// infiniteHP(350) = 9,060 * 1.03^50 ≈ 39,724  (4.4배)
// infiniteATK(350) = 964.8 * 1.025^50 ≈ 3,297 (3.4배)
```

#### 무한 구간 환경 규칙
- **기믹 랜덤 조합**: 매 층 진입 시 엘리트/심연 기믹 풀에서 랜덤 2~3개 적용
- **10층마다 보스 강화**: 무한 구간 보스는 일반 미니보스 대비 HP x3, 패턴 2~3개
- **50층마다 초월 보스**: HP x10, 패턴 5개, 처치 시 대형 보상
- **심연의 침식 Lv.3 상시 적용**: 각인으로 Lv.2까지 감소 가능

#### 무한 구간 보상

| 매 5층 | 골드 (층수 비례), 루비 30 |

## 3. 각인 시스템 (Inscription System)

### 3.1 개요

> "탑의 벽에 새겨진 고대 룬을 해독하여 힘을 얻는다"

각인은 **영구 패시브 효과**를 부여하는 장착 시스템이다. 유물(조건부 발동)과 달리 각인은 **무조건 적용**되는 상시 능력치/특수 효과를 제공한다.

### 3.2 슬롯 시스템

| 항목 | 내용 |
|------|------|
| 최대 슬롯 | 10개 |
| 해금 조건 | 10층마다 1슬롯 (10F, 20F, 30F ... 100F) |
| 장착/해제 | 자유롭게 교체 가능 (쿨타임 없음) |
| 중복 장착 | 같은 각인 중복 장착 불가 |

**슬롯 해금 진행:**
| 슬롯 번호 | 해금 층 | 누적 슬롯 수 |
|-----------|---------|-------------|
| 1 | 10F | 1 |
| 2 | 20F | 2 |
| 3 | 30F | 3 |
| 4 | 40F | 4 |
| 5 | 50F | 5 |
| 6 | 60F | 6 |
| 7 | 70F | 7 |
| 8 | 80F | 8 |
| 9 | 90F | 9 |
| 10 | 100F | 10 |

### 3.3 각인 등급

| 등급 | 색상 | 효과 강도 | 획득처 |
|------|------|-----------|--------|
| 일반 (Normal) | 회색 | 기본 | 50F+ 몬스터 드롭, 각인 상자 |
| 희귀 (Rare) | 파란 | 일반 x1.5 | 100F+ 보스 드롭, 각인 상자 |
| 영웅 (Epic) | 보라 | 일반 x2.5 | 150F+ 보스 드롭, 합성, 이벤트 |
| 전설 (Legend) | 주황 | 일반 x4.0 | 200F+ 보스 드롭, 합성, 랭킹 보상 |

### 3.4 각인 합성

같은 각인 3개를 합성하면 상위 등급 각인 1개로 승급한다.

```
일반 x3 → 희귀 x1 (100% 성공)
희귀 x3 → 영웅 x1 (100% 성공)
영웅 x3 → 전설 x1 (100% 성공)
전설 x3 → 신화 x1 (100% 성공)
```

합성 비용:
| 합성 | 골드 비용 | 추가 재료 |
|------|-----------|-----------|
| 일반 → 희귀 | 50,000 | 각인 조각 x10 |
| 희귀 → 영웅 | 200,000 | 각인 조각 x30 |
| 영웅 → 전설 | 1,000,000 | 각인 조각 x80, 룬 조각 x50 |
| 전설 → 신화 | 5,000,000 | 각인 조각 x200, 별의 결정 x100 |

> **설계 의도**: 실패/파괴가 없는 안전한 성장 축. 장비 강화의 스트레스를 각인에서는 배제하여 유저 만족도를 유지한다.

## 5. 층 정복 랭킹 (Floor Conquest Ranking)

### 5.1 개요

플레이어의 탑 진행도를 기준으로 경쟁하는 랭킹 시스템. 유저 간 경쟁심을 유발하고 장기 목표를 제공한다.

### 5.2 랭킹 유형

#### 5.2.1 전체 랭킹 (All-Time)

| 항목 | 내용 |
|------|------|
| 기준 | 최고 도달 층수 |
| 리셋 | 없음 (영구) |
| 동률 처리 | 도달 시각이 빠른 유저 우선 |
| 보상 | 없음 (명예 + 프로필 표시) |
| 표시 정보 | 순위, 닉네임, 직업, 레벨, 최고 층, 전투력(CP) |

#### 5.2.2 주간 랭킹 (Weekly Progress)

| 항목 | 내용 |
|------|------|
| 기준 | 이번 주 동안 오른 층수 (시작 층 → 현재 층 차이) |
| 리셋 | 매주 월요일 00:00 |
| 동률 처리 | 먼저 도달한 유저 우선 |
| 최소 참여 조건 | 주간 1층 이상 돌파 |
| 보상 | 매주 월요일 우편함으로 지급 |

**주간 랭킹 보상:**
| 순위 | 루비 | 소환권 | 추가 보상 |
|------|------|--------|-----------|
| 1위 | 3,000 | 무기 10 + 동료 10 | 한정 프로필 프레임 (1주일) |
| 2~3위 | 2,000 | 무기 7 + 동료 7 | - |
| 4~10위 | 1,500 | 무기 5 + 동료 5 | - |
| 11~50위 | 800 | 무기 3 + 동료 3 | - |
| 51~100위 | 500 | 무기 2 + 동료 2 | - |
| 101~500위 | 300 | 무기 1 + 동료 1 | - |
| 501~1000위 | 150 | - | 골드 100,000 |
| 참여 | 50 | - | 골드 30,000 |

#### 5.2.3 시즌 랭킹 (Season)

| 항목 | 내용 |
|------|------|
| 기준 | 시즌 기간 중 최고 도달 층수 |
| 기간 | 배틀패스 시즌과 연동 (6주) |
| 리셋 | 매 시즌 시작 시 |
| 보상 | 시즌 종료 후 우편함으로 지급 |

**시즌 랭킹 보상:**
| 순위 | 루비 | 소환권 | 추가 보상 |
|------|------|--------|-----------|
| 1위 | 10,000 | 무기 30 + 동료 30 | 시즌 한정 칭호 + 프로필 프레임 (영구) |
| 2~3위 | 7,000 | 무기 20 + 동료 20 | 시즌 한정 칭호 (영구) |
| 4~10위 | 5,000 | 무기 15 + 동료 15 | - |
| 11~50위 | 3,000 | 무기 10 + 동료 10 | - |
| 51~100위 | 2,000 | 무기 5 + 동료 5 | - |
| 101~500위 | 1,000 | 무기 3 + 동료 3 | - |
| 501~1000위 | 500 | 무기 1 + 동료 1 | - |
| 참여 | 200 | - | 골드 200,000 |

#### 5.2.4 직업별 랭킹

| 항목 | 내용 |
|------|------|
| 기준 | 직업별 최고 도달 층수 |
| 직업 구분 | 전사 / 궁수 / 마법사 (각 Top 100) |
| 리셋 | 시즌과 연동 |
| 보상 | 시즌 랭킹 보상의 50% |
| 목적 | 직업 간 밸런스 가시화, 소수 직업 유저 동기 부여 |

### 5.3 랭킹 포인트 시스템

무한 구간(301F+)에서 추가적인 경쟁 지표.

```
랭킹 포인트 = (도달 층 - 300) * 100 + 타임 보너스 + 조건 보너스

타임 보너스: 해당 층을 60초 내 클리어 시 +50 포인트
조건 보너스: 무피격 클리어 +30, 무사망 클리어 +20
```

### 5.4 프로필 표시

모든 유저의 프로필에 다음 정보가 표시된다:

```
┌─────────────────────────────┐
│  [프로필 프레임]              │
│  닉네임: 타이탄마스터         │
│  직업: 전사 (타이탄)          │
│  레벨: 142                   │
│  전투력: 1,284,500            │
│  ─────────────────────────   │
│  최고 층수: 347F              │
│  시즌 최고: 285F              │
│  칭호: "한계의 도전자"         │
│  주간 순위: #23               │
│  시즌 순위: #45               │
└─────────────────────────────┘
```

### 5.5 랭킹 유저 플로우

```
[메인 화면 > 랭킹 아이콘 (상단 HUD)]
     ↓
[랭킹 팝업]
  ├── [전체 랭킹 탭] — 역대 최고 층수
  ├── [주간 랭킹 탭] — 이번 주 진행량
  ├── [시즌 랭킹 탭] — 이번 시즌 최고 층수
  └── [직업별 랭킹 탭] — 전사/궁수/마법사 분리
     ↓
[내 순위 하이라이트 + 근접 유저 목록]
     ↓
[유저 탭 → 프로필 보기 (장비/각인/동료 구경)]
     ↓
[보상 확인 탭: 이번 주/시즌 예상 보상 표시]
```

### 5.6 안티치트 및 공정성

| 항목 | 대책 |
|------|------|
| 비정상 진행 | 층 클리어 시 서버에 클리어 데이터 전송 (전투 로그 해시) |
| 스탯 위변조 | CP 상한 기반 필터링 (해당 층 대비 비현실적 CP는 검증 대상) |
| 매크로 방지 | CAPTCHA는 사용하지 않음 (방치형이므로), 단 비정상적 진행 속도 모니터링 |
| 보상 악용 | 랭킹 보상은 시즌/주간 종료 후 일괄 지급 (실시간 아님) |

## 6. 기술 구현 고려사항

### 6.1 데이터 구조 (SO)

```
// TowerFloorDataSO — 층별 설정
- floorNumber: int
- section: TowerSection (Normal, Elite, Abyss, Infinite)
- themeId: string
- environmentGimmicks: EnvironmentGimmick[]
- clearCondition: ClearConditionType (None, TimeLimit, KillCount, NoDamage, DualBoss)
- clearConditionValue: float (시간/처치수 등)
- monsterStatMultiplier: float
- bossStatMultiplier: float
- milestoneRewards: LootTableSO
- specialMonsterPool: SpecialMonsterType[]

// InscriptionDataSO — 각인 데이터
- inscriptionId: string
- displayName: string
- description: string
- category: InscriptionCategory (Attack, Defense, Utility, Special)
- grade: InscriptionGrade (Normal, Rare, Epic, Legend, Mythic)
- effectType: InscriptionEffect (enum)
- baseValue: float
- gradeMultiplier: float[] // 등급별 배율

// BlessingDataSO — 축복 데이터
- blessingId: string
- displayName: string
- description: string
- tier: BlessingTier (Basic, Advanced, Special)
- requiredFloor: int
- probability: float
- effects: BlessingEffect[] // 여러 효과 동시 적용 가능

// RankingEntry — 랭킹 엔트리 (런타임/서버)
- playerId: string
- playerName: string
- jobType: JobType
- level: int
- combatPower: long
- highestFloor: int
- seasonHighestFloor: int
- weeklyProgress: int
- achievedAt: DateTime
```

### 6.2 이벤트 연동

```
// 탑 관련 이벤트
FloorClearedEvent { int floor, float clearTime, bool noDamage }
SectionUnlockedEvent { TowerSection section }
InscriptionObtainedEvent { InscriptionDataSO inscription }
InscriptionEquippedEvent { InscriptionDataSO inscription, int slotIndex }
InscriptionSynthesizedEvent { InscriptionGrade fromGrade, InscriptionGrade toGrade }
BlessingReceivedEvent { BlessingDataSO blessing }
BlessingRerolledEvent { BlessingDataSO oldBlessing, BlessingDataSO newBlessing }
RankingUpdatedEvent { RankingType type, int newRank }
```

### 6.3 성능 고려

| 항목 | 대책 |
|------|------|
| 환경 기믹 연산 | 매 프레임 X, 0.2~1초 간격 타이머 기반 |
| 특수 몬스터 AI | 기존 MonsterController 확장, 상태 머신에 특수 상태 추가 |
| 랭킹 데이터 | 로컬 캐시 + 5분 주기 서버 동기화 (오프라인 모드에서는 로컬만) |
| 각인 효과 적용 | CombatStats 계산 시 한 번에 적용 (매 프레임 재계산 X) |
| 축복 효과 적용 | 일일 1회 계산, CombatStats에 곱연산으로 반영 |

## 7. 밸런스 시뮬레이션

### 7.1 구간별 예상 플레이 시간

| 구간 | 층수 | 예상 소요 시간 | 비고 |
|------|------|---------------|------|
| 일반 전반 | 1~50F | 3~5일 | 튜토리얼 + 초기 성장 |
| 일반 후반 | 51~100F | 1~2주 | 강화/장비 시스템 활용 필요 |
| 엘리트 전반 | 101~150F | 2~3주 | 환경 기믹 학습 + 각인 수집 |
| 엘리트 후반 | 151~200F | 3~4주 | 전략적 빌드 필요 |
| 심연 | 201~300F | 1~2개월 | 장기 목표, 매일 1~3층씩 진행 |

### 7.3 재화 투입-산출 밸런스

| 구간 | 주요 투입 (플레이어 → 시스템) | 주요 산출 (시스템 → 플레이어) |
|------|------------------------------|------------------------------|
| 일반 | 시간 투자, 기본 강화 | 골드, EXP, 장비, 스킬 해금 |
| 엘리트 | 강화 재료 소비, 각인 합성 비용 | 상급 각인, 유물, 소환권 |
| 심연 | 고급 재료 대량 소비 | 전설/신화 각인, 대형 보상 |
| 무한 | 시간 + 전략 (빌드 최적화) | 랭킹 보상, 명예, 칭호 |
