## 흐름 요약

### 아웃게임
```
타이틀 → 로그인 → 약관 → 다운로드(1.9GB) → 로딩팁 → 게임 진입
```
- 직업 선택 없음. "모험가" 기본 시작.

### 튜토리얼 (09~19)
```
스토리 구간(6탭) → 첫 전투(스킬 하이라이트) → 퀘스트 3킬 → 레벨업 → 스탯 배분 유도
```
- **패턴**: NPC 안내 → 하이라이트 → 유저 행동 → 보상 → 다음 유도
- 전투 시작까지 ~30초, 레벨업까지 ~1분

## 시스템 분류

### 가져갈 것
- 자동전투 + 스테이지 진행
- 가이드 퀘스트 (단계별 유도)
- 레벨업 → 스탯 배분
- 하단 탭바 (소환/캐릭터/장비/스킬/무기/동료)
- 킬카운트 + EXP바 + HP/MP
- Full Auto 버튼
- 로딩 팁

### 버릴 것
- 아레나/PvP, 길드, 코스튬 (이미 삭제)
- (추가 분석 후 확정)

### 미정
- 동료 시스템 규모
- 배틀패스
- 랭킹 (서버 필요)
- 월드 부흥 시스템
- 포션 시스템 (HP/MP 강화 + 자동 사용)
- 엘리트 몬스터 (주기적 소환, 강화 드롭)

## 핵심 발견 (20~48)

### 물약 시스템 [#21]
- HP 물약: 발동 시 HP 회복+ 200(+100), 재사용 대기시간
- MP 물약: 발동 시 MP 회복+ 250(+5), 재사용 12초
- 골드로 강화 (300G/100G), 단계별 성장
- **자동 사용 설정**: HP 80% 이하 시 자동, MP 80% 이하 시 자동
- **mkLike**: 간단한 포션 자동 사용만 유지, 강화는 선택

### 스테이지 도전 시스템 [#22~25]
- 일반 사냥과 별도로 **[도전] 버튼** → 스테이지 도전 모드
- "몰려오는 적을 처치하세요!" — 웨이브 방어
- 클리어 보상: 다이아+골드+소환포인트+EXP
- 클리어 시간 기록 (00:10.60)
- **mkLike**: 우리 던전 전투와 유사. 이미 DungeonBattleController 구현됨.

### 가이드 퀘스트 흐름 [#27, #30]
- 가이드 퀘스트가 **시스템 해금 순서를 제어**
- 퀘스트 완료 → 다음 시스템 해금 → 해금 알림 → NPC 안내 → 사용 유도
- 레드닷(!) 알림으로 어디를 눌러야 하는지 명확히 표시
- **핵심**: 이 촘촘한 퀘스트 체인이 초반 리텐션의 핵심

### 무기 시스템 해금 [#31~42]
- 레벨 7~8에서 "무기" 시스템 해금
- **소환 화면** [#33]: 직업별 캐릭터 일러스트 + 소환 레벨 + 일괄 소환
- **일괄 소환** [#34]: 슬라이더 10~Max, 하트 비용 표시
- **소환 결과** [#36]: 무기 카드 나열 (NEW 뱃지, 수량 표시)
- **소환 레벨**: Lv.1 → 프로그레스바 (20/100)
- 소환 후 → 무기 탭 열기 유도 → 장착 유도
- **무기 탭** [#42]: 좌=상세(이름+등급+각성+효과), 우=그리드, 하단=[무기 마스터리][일괄 각성]

### 엘리트 몬스터 [#44~47]
- 가이드 퀘스트에서 "엘리트 몬스터 소환 및 처치하기 0/3"
- 자동 소환 + 강력한 몬스터 + 좋은 드롭
- 전투력 표시 212↑ (성장 체감)
- **mkLike**: EliteSummonManager 이미 구현됨

### 보스전 시스템 [#53~62]
- 챕터 마지막 스테이지 = 보스전
- **보스 HP바** 상단 중앙 (노란색+빨간색 2줄)
- **패턴 메카닉**: "보스가 강한 공격 → 점프로 피하세요" 경고 텍스트
- **무력화**: 패턴 피하면 "보스가 무력화! 지금 공격하세요!" → 반격 타이밍
- **실패 가능**: TIME OVER → FAILED ([나가기] [다시하기])
- **클리어 보상**: 다이아500 + 소환포인트300 + **장비 슬롯 개방**
- **핵심**: 방치형인데 보스만 반자동 (점프 조작 필요) → 긴장감 부여

### 스킬 탭 [#65~67]
- **서브탭 3개**: 스킬 목록 / 스킬 강화 / 마스터리
- **좌측**: 스킬 상세 (아이콘+이름+설명+[배우기] 버튼)
- **우측 상단**: 액티브 스킬 그리드 (2행, 레벨+잠금 표시)
- **우측 하단**: 패시브 스킬 그리드 (2행, 레벨 해금 조건)
- 챕터2 진입 시 해금 (가이드 퀘스트로 유도)

### 잠금 화면 (방치 모드) [#49]
- 화면 끄면 자동으로 방치 모드 진입
- 캐릭터 일러스트 2개 + 시계 표시
- "화면을 밀어서 잠금 모드 해제"

### 해금 순서 업데이트
```
전투→스탯→물약→스테이지도전→무기소환→엘리트→보스전→장비슬롯→챕터2→스킬→(장비?동료?)
```
