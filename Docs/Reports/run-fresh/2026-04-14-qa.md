## 3. Critical Findings (P1)

### P1-0. Unity Editor OOM 크래시 (최우선)
- **증상**: /run fresh 장기 실행 후 Editor.log가 **34.6GB**까지 폭주 → `malloc_internal` 실패 → 크래시.
- **원인**: `Library/PackageCache/com.coplaydev.unity-mcp@.../StdioBridgeHost.cs:652`의 `McpLog.Info("Client handler exited...")`가 MCP 클라이언트 접속/해제마다 호출됨. 매 호출마다 풀 스택트레이스가 붙어 수만 번 반복 누적.
- **영향**: 12,245 tick 완주 직후 Unity 강제 종료. Editor 상태 소실 (세이브는 SaveManager 회전 백업으로 보전됨).
- **조치 (이 세션 완료)**:
  - `Assets/Scripts/Editor/LogStackTraceSuppressor.cs` 신규 — `[InitializeOnLoad]`로 `Application.SetStackTraceLogType(LogType.Log, StackTraceLogType.None)` 적용.
  - Log 한 번당 ~30줄 → ~1줄. 장기 세션 안전성 확보.
  - Warning/Error는 스택트레이스 유지 (디버깅 정보 보존).


### P1-1. Quest 카탈로그 인스펙터 동기화 누락
- **증상**: 디스크에 `Quest_Guide_001.asset ~ Quest_Guide_350.asset` 350개 존재. 런타임 `_questDataMap` 에는 293개만 로드됨.
- **원인**: `QuestManager._questCatalog`는 `[SerializeField]` 배열. Phase2SetupEditor의 `ConnectCatalog`가 **매니저 신규 생성 시에만** 호출됨. 기존 씬에 QuestManager가 이미 있으면 catalog 갱신 안 됨.
- **영향**: 1~350 범위에서 57개 idx 누락 → 해당 인덱스 퀘스트 활성화 불가. 가이드 체인이 건너뛴 idx에서 next id를 못 찾고 종료될 잠재 리스크.
- **조치 (이 세션 완료)**:
  - `Phase2SetupEditor.cs` — 기존 매니저에도 `ConnectCatalog` 무조건 재호출 (line 899~912).
  - `[MenuItem("mkLike/Quest/Sync Catalog")]` 추가 (line 2559~) — 원클릭 동기화 메뉴.
  - 다음 fresh 실행 시 이 이슈 재발하지 않음.

### P1-2. 상태 기반 퀘스트 조건의 초기 동기화 미흡
- **증상**: `WeaponSummonLevelReach req=19` 퀘스트가 유저 WeaponLv가 이미 20인 상태에서 활성화되면 progress=0에서 시작. 다음 레벨업 이벤트까지 완료 불가. 신규 퀘스트가 "이미 만족된 상태"여도 0부터 카운트.
- **원인**: `QuestManager.ActivateNextGuideQuest`에서 `QuestStateRefreshEvent`를 발행하지만 다음 5개 조건의 핸들러가 없었음:
  - `WeaponSummonLevelReach` (GachaManager 미구독)
  - `EliteSummonLevelReach` (EliteSummonManager 미구독)
  - `StarForceReach` (EquipmentManager 미구독)
  - `HeroPowerMilestone` (HeroPowerManager 미구독)
  - `UnlockAbility` (AbilityManager 미구독)
- **영향**: 실유저가 해당 조건의 퀘스트에 도달 시 진행도가 즉시 반영되지 않고 다음 이벤트 대기. 체감상 "버그"로 보일 수 있음.
- **조치 (이 세션 완료)**:
  - `GachaManager.cs:85-112` — OnEnable/OnDisable + OnQuestStateRefresh (WeaponSummonLevelReach).
  - `EliteSummonManager.cs:76-105` — Subscribe + Refresh (EliteSummonLevelReach).
  - `EquipmentManager.cs:60-103` — Subscribe + Refresh (StarForceReach, 슬롯별 최댓값 재발행).
  - `HeroPowerManager.cs:42-78` — Subscribe + Refresh (HeroPowerMilestone).
  - `AbilityManager.cs:49-86` — Subscribe + Refresh (UnlockAbility, TotalUnlocked 재발행).
  - null 안전: 기본값/0인 경우 미발행.

### P1-3. 밸런스 검증 파이프라인 부재
- **증상**: GuideQuestGenerator가 `req > 시스템 상한` 퀘스트를 생성. 예: WeaponPool.MaxSummonLevel=17 인데 `WeaponSummonLevelReach req=19~43` 13건 발생.
- **원인**: 제너레이터의 `GetRequirement()` 스케일링 공식이 시스템 상한을 모름. 검증 루틴 없음.
- **영향**: 빌드 시점에도 돌파 불가 퀘스트가 카탈로그에 포함됨. 유저 도달 시 실질 게임오버.
- **조치 (이 세션 완료)**:
  - `GuideQuestGenerator.cs` — `ValidateAll()` 추가, `[MenuItem("mkLike/Quest/Validate Catalog")]` 등록, `GenerateAll()` 말미 자동 호출.
  - 검증 대상: WeaponSummonLevelReach, EliteSummonLevelReach, StarForceReach(<=30), HeroPowerMilestone(<=10), JobAdvance(<=3), ClearStage(<=9999), KillMonsters(<=100000).
  - 현재 카탈로그 실행 시 **예상 경고 ~28건** (Weapon 13, Elite 15).
  - 경고는 로그만 — **자동 수정 없음**. 밸런스 튜닝은 수동 판단.
