# mkLike WebGL 테스트 가이드

> 이 문서는 **Claude Code(개발자)**와 **크롬 익스텐션 Claude(테스터)** 사이의 협업 채널입니다.
> 두 Claude는 이 문서를 통해 테스트 요청과 결과를 주고받습니다.

---

## 1. 테스트 시스템 개요

### 왜 크롬 익스텐션 Claude를 쓰는가

Claude Code는 **코드만 읽고 쓸 수 있다**. 실제 화면이 어떻게 보이는지는 알 수 없다.
크롬 익스텐션 Claude는 **브라우저에서 실제 렌더링 결과를 볼 수 있다**.

따라서 크롬 Claude는 **시각적 검증 전문 테스터** 역할을 한다:

| 크롬 Claude가 잘하는 것 | 예시 |
|-------------------------|------|
| UI 생김새 판단 | 버튼이 진짜 버튼처럼 생겼는지, 배경이 밋밋한지 |
| 리소스 사용 확인 | Stone Kit 텍스처가 적용됐는지, 아이콘이 placeholder인지 |
| 버튼 클릭 반응 | 클릭 시 시각적 피드백(색상 변화, 펀치 애니메이션) |
| 보편적 시선 | 일반 유저가 봤을 때 어색하거나 이상한 부분 |
| 텍스트 확인 | 깨짐, 겹침, 잘림, 빈 값, 미번역 |
| 레이아웃/정렬 | 요소 겹침, 화면 밖 나감, Z-order 문제 |
| 이펙트/애니메이션 | 공격/스킬 이펙트, UI 전환 연출 |

### 테스트 플로우 (반복 루프)

```
① Claude Code: 코드 수정
② Claude Code: chrome-test-request.md를 최신 테스트 항목으로 갱신
③ Claude Code: 이 문서(webgl-test-guide.md)에 개발자 노트 추가
④ 사용자: Unity 에디터에서 WebGL 빌드
⑤ 사용자: chrome-test-request.md 내용을 Ctrl+A → Ctrl+C 복사
⑥ 사용자: 크롬 익스텐션 Claude에게 붙여넣기 (텍스트로 전달)
⑦ 크롬 Claude: 브라우저에서 게임 테스트 + 대화에 리포트 작성
⑧ 사용자: 크롬 Claude의 리포트를 Claude Code에게 붙여넣기
⑨ Claude Code: 리포트를 이 문서에 기록 + 이슈 수정 → ①번으로 반복
```

### 역할 분담

| 역할 | 누가 | 하는 일 |
|------|------|---------|
| 개발자 | Claude Code | 코드 수정 + 이 문서에 "개발자 노트" 작성 + chrome-test-request.md 갱신 |
| 테스터 | 크롬 익스텐션 Claude | 브라우저에서 테스트 + 대화에 리포트 작성 (로컬 파일 접근 불가) |
| 중개 | 사용자 | 빌드 + 리퀘스트/리포트 복사 붙여넣기로 두 Claude 연결 |

### 파일 구조

| 파일 | 역할 |
|------|------|
| 이 문서 (webgl-test-guide.md) | 가이드 — 테스트 방법, 게임 정보, 기본 항목 |
| webgl-test-history-NN.md | 히스토리 — 개발자 노트 + 테스트 리포트 누적 (넘버링) |
| chrome-test-request.md | 크롬 Claude용 복사 파일 — 매 라운드 최신 항목으로 덮어씀 |

### 문서 규칙

- 개발자 노트는 Claude Code만 작성
- 테스트 리포트는 사용자가 크롬 Claude 결과를 전달하면 Claude Code가 이 문서에 기록
- 리포트/노트 번호는 순서대로 증가
- 이전 리포트/노트는 삭제하지 않고 누적 (히스토리 추적용)

### chrome-test-request.md 작성 규칙 (Claude Code 필독)

- 사용자가 Ctrl+A → Ctrl+C로 복사해서 크롬 Claude에 텍스트로 전달하는 파일
- **URL, 파일 경로, 링크를 절대 적지 않는다** (크롬 Claude가 열려고 시도하면 새 브라우저가 열림)
- **마크다운 링크 문법도 금지** (백틱 코드블록 내 경로도 금지)
- 자기완결적이어야 함 (이 파일 하나만으로 뭘 해야 하는지 완전 파악)
- **"상용화 수준의 게임과 비교해서 까다롭게 평가"** 문구 항상 포함
- **"항목 외에도 게임으로서 미흡하거나 어울리지 않거나 부족한 건 전부 적어줘"** 문구 항상 포함

### 세션 간 연속성

이 문서는 세션이 바뀌어도 유지된다.
- 새 Claude Code 세션 시작 시: 이 문서의 최신 테스트 리포트를 읽고 이슈 수정
- 리포트가 없으면: 사용자에게 빌드 → 테스트 요청

## 2. 크롬 Claude 테스트 매뉴얼

### 테스트 시 주의사항

- **세션 만료 전에 반드시 리포트를 작성하세요.** 테스트 중간이라도 세션이 끝나기 전에 그때까지 확인한 내용을 리포트에 기록해주세요. 리포트 없이 세션이 종료되면 테스트 결과가 유실됩니다.
- 모든 항목을 다 테스트할 필요 없습니다. **시간 내에 확인 가능한 항목만** 테스트하고, 나머지는 "미확인"으로 표시하세요.
- 스크린샷보다 **텍스트 설명이 더 중요합니다.** "어떤 버튼을 눌렀을 때 어떤 결과가 나왔는지"를 구체적으로 적어주세요.
- 브라우저 콘솔(F12)에 에러가 나오면 **에러 메시지의 첫 3줄만** 복사해주세요. 전체 로그는 필요 없습니다.
- **개발자 노트에 "확인 요청"이 있으면 해당 항목을 최우선으로 테스트하세요.**

### 테스트 우선순위

1. **개발자 노트의 확인 요청 항목** (수정이 실제로 동작하는지)
2. **이전 리포트의 미수정 항목** (재확인 또는 변화 있는지)
3. **기본 테스트 항목** (아래 A~D)
4. **새로 발견한 이슈**

### 리포트 작성 형식

```markdown
### 리포트 #N (날짜: YYYY-MM-DD)
테스트 환경: Chrome, WebGL, localhost:8080
콘솔 에러: (있으면 첫 3줄)

#### 개발자 노트 확인 결과
1. [이슈명]: ✅ 수정됨 / ❌ 여전히 발생 / ⚠️ 부분 수정 — 상세 설명

#### 새로 발견된 이슈
- [우선순위] 설명

#### 기본 테스트 (변화 있는 항목만)
- A2. 하단 탭 전환: ✅/❌ 상세
- ...
```

## 3. 게임 정보 (테스터 참고용)

### 게임 개요

- **장르**: 2D 탑다운 방치형 RPG (키우기류)
- **전투**: 뱀서라이크 스타일 — 플레이어가 중앙, 몬스터가 사방에서 몰려옴
- **핵심 루프**: 전투 → 성장 → 더 강한 전투 → 반복
- **URL**: `http://localhost:8080`

### 조작법

- **이동**: 자동 (플레이어가 가장 가까운 몬스터를 향해 이동)
- **공격**: 자동 (사거리 내 몬스터 자동 공격)
- **스킬**: 화면 하단 스킬 슬롯 (자동 발동 또는 터치)
- **UI**: 화면 하단 탭 버튼 (캐릭터 / 던전 / 상점)

### 화면 구성

```
┌─────────────────────────────┐
│  처치수    1-1 스테이지    설정 │  ← 상단 HUD
│  Lv HP바  골드  루비  키      │
├─────────────────────────────┤
│                             │
│     (전투 영역)              │
│     몬스터들 + 플레이어       │
│     데미지 텍스트 표시        │
│                             │
├─────────────────────────────┤
│  콤보 로그 (좌하단)          │
│  가이드 퀘스트 위젯 (우측)    │
├─────────────────────────────┤
│  [스킬1] [스킬2] [스킬3] [스킬4] │  ← 스킬 슬롯
│  ████████ EXP 23% ████████  │  ← 경험치 바
│  [캐릭터]  [던전]  [상점]    │  ← 하단 탭
└─────────────────────────────┘
```

### 패널 목록 (하단 탭에서 접근)

| 탭 | 서브탭 | 기능 |
|---|--------|------|
| 캐릭터 | 스텟 | 공격력/HP/방어력 등 스탯 분배 (+1, +10, MAX 버튼) |
| 캐릭터 | 장비 | 장착 장비 3슬롯 + 보유 장비 목록 |
| 캐릭터 | 스킬 | 스킬 목록 + 레벨업 |
| 캐릭터 | 전직 | 직업 승급 (워리어→나이트/타이탄 등) |
| 캐릭터 | 유물 | 유물 장착 |
| 캐릭터 | 동반자의 힘 | 동반자 시너지 버프 |
| 캐릭터 | 어빌리티 | 특수 능력치 |
| 던전 | 성장 던전 | 골드/경험치/재료/장비/스타 던전 입장 |
| 던전 | 월드보스 | 월드보스 전투 |
| 던전 | 보스 레이드 | 보스 레이드 |
| 던전 | 타워 | 무한 타워 등반 |
| 던전 | 챌린지 | 도전 과제 |
| 상점 | 동료 소환 | 동료 가챠 (1회/10연차) |
| 상점 | 장비 소환 | 장비 가챠 |
| 상점 | 무기 소환 | 무기 가챠 |

## 4. 기본 테스트 항목

> 크롬 Claude는 매 테스트마다 전체를 반복할 필요 없습니다.
> 개발자 노트 확인 후, 변화가 예상되는 항목 + 이전에 실패한 항목만 재확인하세요.

### A. UI 완성도 (최우선)

1. **HUD 요소**: HP바, 레벨, 골드, 루비, 처치수, 스테이지 표시가 정상인가?
2. **하단 탭 전환**: 캐릭터/던전/상점 탭을 눌러서 패널이 열리는가?
3. **패널 열림/닫힘**: 각 패널이 열리고 X 버튼으로 닫히는가?
4. **서브탭 전환**: 캐릭터 패널의 스텟→장비→스킬 등 서브탭이 전환되는가?
5. **텍스트**: 한국어 텍스트가 깨지거나 겹치는 곳이 있는가?
6. **빈 아이콘**: 회색 사각형, 빈 카메라 아이콘, 분홍색(missing) 텍스처가 있는가?
7. **버튼 반응**: 모든 버튼이 클릭 시 반응하는가? (색상 변화/효과)
8. **팝업/오버레이**: 팝업이 뜰 때 뒤에 있는 UI가 비정상적으로 보이는가?
9. **레이아웃**: 요소가 겹치거나, 화면 밖으로 나가거나, 정렬이 안 되는 곳?
10. **스크롤**: 목록이 긴 패널에서 스크롤이 되는가?

### B. 리소스 활용 (시각적 품질)

1. **패널 배경**: 어두운 단색이 아닌 Stone Kit 텍스처(돌/중세 느낌)가 적용되어 있는가?
2. **버튼 스타일**: 기본 흰색 사각형이 아닌 스타일링된 버튼인가?
3. **아이콘**: 스킬/장비/던전에 고유 아이콘이 있는가, 아니면 빈칸/기본 아이콘인가?
4. **이펙트**: 공격 시 슬래시/마법 이펙트가 보이는가? 이펙트가 이상한 위치/크기/색으로 표시되지는 않는가?
5. **몬스터**: 몬스터 스프라이트가 정상적으로 보이는가?
6. **캐릭터**: 플레이어 캐릭터가 정상적으로 보이고 애니메이션이 있는가?

### B-2. 미완성/이상 감지 (크롬 Claude 핵심 역할)

> **코드에서는 발견할 수 없고, 실제 화면을 봐야만 알 수 있는 문제들입니다.**
> 아래 항목에 해당하는 것이 보이면 반드시 보고해주세요.

1. **유령 오브젝트**: 아무 스프라이트/애니메이션 없이 투명하거나 기본 흰색 사각형으로 보이는 캐릭터/오브젝트가 있는가? (예: 동료 캐릭터가 벌거벗은 모습으로 플레이어에 붙어있음)
2. **멈춘 오브젝트**: 화면에 있지만 아무 동작(이동/공격/애니메이션)을 하지 않고 가만히 있는 캐릭터/몬스터가 있는가?
3. **이상한 이펙트**: 이펙트가 엉뚱한 위치에 표시되거나, 크기가 비정상적이거나, 사라지지 않고 화면에 남아있는가?
4. **잘못된 스프라이트**: 캐릭터/아이콘/배경에 전혀 다른 이미지가 사용되고 있는가?
5. **Z-order 이상**: 앞에 있어야 할 것이 뒤에 가려지거나, 뒤에 있어야 할 것이 앞에 나오는가?
6. **기능 없는 UI**: 클릭할 수 있게 생겼지만 아무 반응이 없는 버튼/영역이 있는가?
7. **의미 없는 숫자/텍스트**: "0", "---", "NaN", "null", 빈 문자열 등 의미 없는 값이 표시되는 곳이 있는가?

### C. 기능 동작 체크

1. **스탯 분배**: 캐릭터 > 스텟 탭에서 +1 버튼 클릭 → 수치가 올라가는가?
2. **장비 장착**: 캐릭터 > 장비 탭에서 장비를 장착할 수 있는가?
3. **스킬 레벨업**: 캐릭터 > 스킬 탭에서 스킬을 레벨업할 수 있는가?
4. **던전 입장**: 던전 > 성장 던전에서 입장 버튼 → 던전에 들어가는가?
5. **가챠 뽑기**: 상점 > 동료 소환에서 1회 뽑기 → 결과가 나오는가?
6. **전직**: 캐릭터 > 전직 탭에서 조건 충족 시 전직이 되는가?
7. **퀘스트**: 우측 가이드 퀘스트 위젯 → 진행률이 올라가고 완료 가능한가?
8. **스테이지 진행**: 몬스터를 계속 잡으면 1-1 → 1-2로 넘어가는가?

### D. 보편적 시선 (일반 유저 관점)

1. **첫인상**: 게임을 처음 열었을 때 뭘 해야 할지 자연스럽게 알 수 있는가?
2. **이상한 점**: 일반 모바일 게임과 비교해서 어색하거나 이상하게 느껴지는 부분?
3. **게임 느낌**: 진짜 게임처럼 느껴지는가, 아니면 프로토타입/목업 느낌인가?
4. **만족스러운 점**: 잘 되어있다고 느껴지는 부분이 있다면?

## 5. 히스토리 (별도 파일로 분리)

히스토리 파일은 넘버링되어 누적됩니다. 파일이 너무 길어지면 새 번호로 생성.
