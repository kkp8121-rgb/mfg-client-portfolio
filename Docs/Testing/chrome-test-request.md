# mkLike WebGL 테스트 요청 (세션 B)

테스트 결과는 이 대화에 직접 작성해줘.

## 중요: 이미지 제한
- **스크린샷은 꼭 필요할 때만.** zoom 금지.
- 뽑기 반복 클릭 중에는 스크린샷 찍지 마. 결과만 확인.

## 게임 정보
- 2D 탑다운 방치형 RPG. 하단 탭: 캐릭터/던전/상점. 초기 루비 10,000.

## 테스트 1: WebGL 안정성 (5분 크래시 수정 확인)

### 1-1. 장시간 전투 안정성
- 게임 시작 후 **최소 7분간** 전투 방치
- 5분 이후에도 크래시(function signature mismatch) 없이 동작하는지
- 콘솔에 WASM 에러가 발생하지 않는지

### 1-2. 색상 트윈 동작 확인
- 몬스터 피격 시 흰색 플래시가 보이는지 (HitFlashEffect)
- 몬스터 사망 시 빨간색 플래시 + 축소 연출이 보이는지 (DeathEffect)
- CP가 변할 때 CP 텍스트 색상 플래시가 보이는지 (CpCounterWidget)

## 테스트 2: 기존 UI 유지 확인

### 2-1. Stone Kit UI
- HUD 바가 Stone Kit 스프라이트로 표시
- 패널 배경이 Stone Kit 텍스처
- 탭 전환 시 tab_normal → tab_selected 스프라이트 전환

### 2-2. 가챠 + 장비
- 상점 탭 → 10연차 뽑기 → 카드 연출 정상
- 등급별 프레임 색상 구분 (은색/파랑/보라/빨강/노랑)

### 2-3. 던전
- 던전 탭 → 입장 → 열쇠 소진 시 빨간색 경고

## 테스트 3: 콘솔 에러 확인

### 3-1. 시작 시 에러
- 게임 시작 직후 콘솔의 에러/경고 확인
- 이전 이슈: NullReferenceException, serialization mismatch → 수정 확인

### 3-2. 7분 경과 후 에러
- requestAnimationFrame 경고가 사라졌는지 확인
