## 중요: 이미지 제한

## 게임 정보
- 2D 탑다운 방치형 RPG. 하단 탭: 캐릭터/던전/상점. 초기 루비 10,000.

## 테스트 항목

### 1. 10연차 카드 밝기 + 스케일
- 상점 → 동료 10연차 뽑기 (2700 루비)
- 확인 항목:
  1. **카드 배경이 밝게 보이는가** — 노트 #18에서 배경 밝기 상향 (0.2+0.08 → 0.4+0.3)
  2. **카드 10장이 균일한 크기로 표시되는가** — scale 애니메이션 제거됨 (즉시 1.0)
  3. 팝업 배경도 밝게 보이는가
  4. 5x2 그리드에 빈 카드 없이 10장 모두 보이는가
  5. 콘솔에 에러 없는지 확인

### 2. 이전 수정 유지
- 무기 소환 천장 카운터, 상점 3탭, 스탯 분배, 던전 닫기
