## 3. 전체 관찰 — 상용화 수준 평가

### 기존 에러 (콘솔)

- **NullReferenceException** — 로드 직후 발생 (`ThrowNullReferenceException`). 원인 객체 불명확하나 게임 진행에는 영향 없어 보임
- **CombatDebugLogger serialization mismatch** — Read 32 bytes / expected 60 bytes. 에디터 전용 코드가 빌드에 포함된 것으로 추정
- **DungeonPanel `_recommendDungeonText` is NULL** — 던전 패널 첫 표시 시 추천 던전 텍스트 누락
- **requestAnimationFrame 미사용 경고** — 프레임 레이트 최적화 미비

### UI/UX 미흡 사항

1. **10연차 결과 카드 미표시** — 가장 치명적. 유저가 뽑기 결과를 볼 수 없으면 과금 동기가 사라짐. 즉시 수정 필요
2. **루비 잔액 표기 불일치** — 10K에서 2700 차감이면 7,300이어야 하나 7.4K로 표시. 반올림 표기인지 계산 오류인지 확인 필요
3. **사용 가능 포인트 수치 미표시** — 캐릭터 스탯 화면에서 "사용 가능 포인트" 영역에 숫자가 보이지 않음 (혹은 0인데 표시 안 됨)
4. **전투력 미갱신** — 공격력 +1 투자 후에도 전투력이 630으로 동일하게 표시됨. 즉시 반영되어야 함
5. **자동분배 기능 불투명** — "자동분배" 버튼이 있으나 어떤 비율로 배분되는지 설명 없음
6. **캐릭터 등급 시스템 설명 부재** — "등급 F"가 무엇을 의미하는지, 어떻게 올리는지 안내 없음
7. **동료 획득 피드백 부재** — 10연차 후 "새로운 동료 획득!" 같은 알림이나 신규/중복 구분이 없음
8. **가챠 확률 미공시** — 등급별(Normal/Rare/Epic/Unique/Legendary) 확률 표시 없음. 한국 게임법상 확률 공시 의무 위반
9. **천장 시스템 설명 부재** — "천장까지 30회"만 표시되고, 천장 도달 시 무엇을 보장하는지 안내 없음
10. **스테이지 진행 피드백 부족** — 1-2 → 2-1 등 스테이지 전환 시 클리어 보상·연출이 없음
11. **보스 클리어 UI 미흡** — 우상단 "보스 플레이어" 영역의 정보가 작고 읽기 어려움
12. **전투 로그 가독성** — 좌측 전투 로그(+공격력, +경험치 등)가 작고 빠르게 사라져 읽기 어려움
13. **경험치 바 위치** — 하단 경험치 바가 너무 얇고 수치만 표시. 레벨업까지 남은 양 직관적으로 파악 어려움
14. **설정/옵션 메뉴 없음** — 사운드, 그래픽, 게임 속도 조절 등 기본 설정 메뉴 미확인
15. **튜토리얼 없음** — 신규 유저 안내가 전혀 없어 각 시스템 접근이 직관적이지 않음
16. **빈 서브탭** — 캐릭터 패널의 칭호/유물/이벤트패스 탭에 콘텐츠가 있는지 불확실
17. **던전 입장 비용/보상 정보 부족** — "던전 열쇠 10/10"은 있지만, 각 던전의 난이도·보상·소모 열쇠 수가 명확하지 않음

### 긍정적 요소

- 방치형 전투 루프가 자연스럽게 작동하며 자동 진행됨
- 상점 3탭 구조와 천장 시스템의 기본 설계가 건전함
- 스탯 분배 UI가 직관적이고 +1/+10/최대 3단계 제공
- 동료가 필드에 실제 나타나 함께 전투하는 시각적 표현이 있음
- 던전 종류가 다양하고(성장/월드보스/레이드/매일/월별) 확장 가능성 있음
